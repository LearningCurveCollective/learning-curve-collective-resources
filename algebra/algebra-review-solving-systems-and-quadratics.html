One Thread Runs Through This Whole Packet

This packet covers two big topics — systems of equations and parabolas — but there is really just one idea underneath both of them:

Every unknown you want to pin down costs you one independent piece of information.

In the first half of the packet, the unknowns are variables ($x$, $y$, $z$) and the pieces of information are equations. In the second half, the unknowns are parameters ($a$, $b$, $c$ in $y = ax^2 + bx + c$) and the pieces of information are points the parabola must pass through. Same idea, new costume.

2 unknowns → 2 equations

One equation in $x$ and $y$ is a line — infinitely many points satisfy it. A second (independent) equation cuts that freedom down to a single point. Two unknowns, two equations, one answer.

3 unknowns → 3 equations

Add a third unknown $z$ and each equation becomes a plane in 3D. You now need three independent equations to nail down one point. The pattern: a new variable costs a new equation.

3 parameters → 3 points

A parabola $y = ax^2 + bx + c$ has three parameters: $a$, $b$, $c$. Each known point the parabola passes through generates one equation in $a$, $b$, $c$. Three points → a 3×3 system → one specific parabola. The two halves of this packet are the same math!

2

Variables vs. Parameters — Know Which Hat You're Wearing

These two words get used loosely, but the distinction is the key to the second half of this packet. Take $y = ax^2 + bx + c$:

Variables: $x$ and $y$

The moving parts. As $x$ sweeps through all real numbers, $(x, y)$ traces out the whole curve. Variables stay unknown even after you know which parabola you have.

Parameters: $a$, $b$, $c$

The dials that choose which parabola you have. Once set, they are fixed numbers. "Find the parabola through these points" means: solve for the parameters.

The role-swap trick. When you plug a known point like $(2, 5)$ into $y = ax^2 + bx + c$, something great happens: $x$ and $y$ become known numbers, and the equation $5 = 4a + 2b + c$ is now a linear equation in the unknowns $a$, $b$, $c$. The parameters have become the variables. That is why systems of equations (Tabs 2–4) are exactly the tool you need for fitting parabolas (Tab 7).

What a System Is & What "Solving" Means

A system of equations is a set of equations that must all be true at the same time. A solution is a value for every unknown that makes every equation true simultaneously — graphically, it's the point where the lines cross.

The information-counting rule:

One equation in two unknowns has infinitely many solutions (a whole line of them). To pin down a single answer, you need as many independent equations as unknowns: 2 unknowns → 2 equations. Later: 3 unknowns → 3 equations, and (in the parabola half of this packet) 3 parameters → 3 points.

"Independent" matters: $x + y = 5$ and $2x + 2y = 10$ look like two equations, but the second is just the first in disguise — it adds no new information. You still have a whole line of solutions.

2

Method 1: Substitution

The Procedure

Concept

Use one equation to express one variable in terms of the other, then substitute that expression into the second equation. This collapses the system into one equation in one unknown — something you already know how to solve.

Step 1. Solve one equation for one variable (pick the one with coefficient $1$ if you can).

Step 2. Substitute that expression into the other equation.

Step 3. Solve the resulting one-variable equation.

Step 4. Back-substitute to find the other variable.

Step 5. Check the pair in both original equations.

Worked Example

Solve the system:

$$\begin{cases} y = 3x - 5 \\ 2x + y = 10 \end{cases}$$

Givens: two equations; $y$ is already isolated in the first — substitution is the natural choice.

Step 1 is already done for us: $y = 3x - 5$.

Step 2. Replace $y$ in the second equation with $(3x-5)$:

$$2x + (3x - 5) = 10$$

Step 3. Solve: $5x - 5 = 10 \;\Rightarrow\; 5x = 15 \;\Rightarrow\; x = 3$.

Step 4. Back-substitute: $y = 3(3) - 5 = 4$.

Step 5. Check in both: $y = 3x-5$: $\;4 = 9 - 5$ ✓   and   $2(3) + 4 = 10$ ✓

$$\boxed{(x, y) = (3, 4)}$$

3

Method 2: Elimination

The Procedure

Concept

If two equations are both true, then their sum (or difference) is also true. Scale the equations so one variable has opposite coefficients, then add the equations — that variable is eliminated, again leaving one equation in one unknown.

Step 1. Line up both equations in $Ax + By = C$ form.

Step 2. Multiply one (or both) equations so the coefficients of one variable are opposites.

Step 3. Add the equations — one variable cancels.

Step 4. Solve, then back-substitute into either original equation.

Step 5. Check the pair in both original equations.

Worked Example

Solve the system:

$$\begin{cases} 3x + 4y = 25 \\ 5x - 2y = 7 \end{cases}$$

Givens: both equations are already in $Ax + By = C$ form; no variable has coefficient $1$, so elimination beats substitution here.

Step 2. The $y$ coefficients are $4$ and $-2$. Multiply the second equation by $2$ so they become $4$ and $-4$:

$$\begin{cases} 3x + 4y = 25 \\ 10x - 4y = 14 \end{cases}$$

Step 3. Add the equations — the $y$ terms cancel:

$$13x = 39 \;\Rightarrow\; x = 3$$

Step 4. Back-substitute into $3x + 4y = 25$: $\;9 + 4y = 25 \Rightarrow y = 4$.

Step 5. Check: $3(3)+4(4) = 25$ ✓   and   $5(3)-2(4) = 7$ ✓

$$\boxed{(x, y) = (3, 4)}$$

Which method? If a variable is already isolated (or has coefficient $1$), substitution is fast. If both equations are in $Ax + By = C$ form with messy coefficients, elimination avoids fractions. Both always work — this is a choice of convenience, not correctness.

4

Special Cases: No Solution & Infinitely Many

Sometimes the algebra makes both variables vanish. What's left tells you which special case you're in:

False statement → No solution

If you end with something like $0 = 7$, the lines are parallel — same slope, different intercepts. No point satisfies both.

Example: $2x - y = 5$ and $4x - 2y = 7$.

True statement → Infinitely many

If you end with $0 = 0$, the two equations are the same line — the second equation added no new information. Every point on the line works.

Example: $x + 2y = 3$ and $3x + 6y = 9$.

Common mistake: writing "$x = 0$, $y = 0$" when everything cancels. The variables didn't equal zero — they disappeared. Read the leftover statement ($0=7$ false, or $0=0$ true) to classify the system.

A New Variable Costs a New Equation

Everything you did with 2×2 systems scales up. The only new thing is the bookkeeping:

3 unknowns $\;(x, y, z)\;$ require 3 independent equations.

Why? Start with one equation in three unknowns, say $x + y + z = 6$. You can pick $x$ and $y$ freely and $z$ adjusts — two whole degrees of freedom. A second equation removes one degree of freedom (you're down to a line's worth of solutions). Only a third independent equation pins down a single point $(x, y, z)$.

Keep this scoreboard in your head: each new unknown adds a degree of freedom; each new independent equation removes one. You have a unique solution exactly when they balance. This same scoreboard will run the parabola half of the packet — with parameters playing the role of unknowns and points playing the role of equations.

Warm-Up: Triangular Systems & Back-Substitution

The easiest 3×3 you'll ever meet

Concept

A triangular system has one equation with all three unknowns, one with two, and one with just one. You solve the simplest equation first and substitute backwards up the chain. Every elimination strategy is secretly an attempt to create this shape.

Worked Example

$$\begin{cases} x + y + z = 12 \\ \phantom{x + {}} y + z = 5 \\ \phantom{x + y + {}} z = 2 \end{cases}$$

The third equation hands us $z = 2$.

Substitute into the second: $y + 2 = 5 \Rightarrow y = 3$.

Substitute both into the first: $x + 3 + 2 = 12 \Rightarrow x = 7$.

$$\boxed{(x, y, z) = (7,\;3,\;2)}$$

Notice the shape: each equation had exactly one new unknown, so each step was a one-variable problem. That's the shape elimination aims for.

The Full Procedure: 3×3 Elimination

Shrink 3×3 → 2×2 → 1×1

Concept

The strategy is reduction: use elimination on two different pairs of equations to kill the same variable twice. That leaves a 2×2 system — which you already know how to solve. Then back-substitute your way home.

Step 1. Choose a variable to eliminate (pick the one with the friendliest coefficients).

Step 2. Eliminate it from one pair of equations (say, Eq. 1 & Eq. 2).

Step 3. Eliminate the same variable from a different pair (say, Eq. 1 & Eq. 3).

Step 4. Solve the resulting 2×2 system in the two surviving variables.

Step 5. Back-substitute into any original equation to recover the eliminated variable.

Step 6. Check the triple in all three original equations.

Worked Example

$$\begin{cases} x + y + z = 6 \\ 2x - y + z = 3 \\ x + 2y - z = 2 \end{cases}$$

Step 1. Eliminate $z$ — its coefficients are $+1, +1, -1$, the friendliest on the board.

Step 2. Subtract Eq. 2 from Eq. 1 (their $z$ coefficients match):

$$(x - 2x) + (y - (-y)) + (z - z) = 6 - 3 \;\Rightarrow\; -x + 2y = 3 \quad (\ast)$$

Step 3. Add Eq. 1 and Eq. 3 (their $z$ coefficients are opposites):

$$2x + 3y = 8 \quad (\ast\ast)$$

Step 4. Solve the 2×2 system $(\ast), (\ast\ast)$. From $(\ast)$: $x = 2y - 3$. Substitute into $(\ast\ast)$:

$$2(2y - 3) + 3y = 8 \;\Rightarrow\; 7y = 14 \;\Rightarrow\; y = 2, \quad x = 2(2) - 3 = 1$$

Step 5. Back-substitute into Eq. 1: $1 + 2 + z = 6 \Rightarrow z = 3$.

Step 6. Check all three: $1+2+3=6$ ✓, $\;2-2+3=3$ ✓, $\;1+4-3=2$ ✓

$$\boxed{(x, y, z) = (1,\;2,\;3)}$$

The classic 3×3 error: eliminating $z$ from one pair and then eliminating a different variable from another pair. You end up with two equations in three leftover unknowns — no progress. Both eliminations must target the same variable so the surviving 2×2 involves the same two unknowns.

From Story to System: The Translation Procedure

The solving is review now — the new skill is setup. Every solution below follows the same template, and you should too:

Step 1 — List the givens. Pull every number and relationship out of the story before touching algebra.

Step 2 — Define your variables. Write a sentence for each: "let $a$ = number of adult tickets." Units included.

Step 3 — Count. $n$ unknowns need $n$ independent equations. Find one equation per given relationship; if you're short, re-read the problem — a given is hiding.

Step 4 — Solve with substitution or elimination.

Step 5 — Answer the actual question, with units, and sanity-check it against the story.

Spotting the equations: word problems almost always hide one count equation ("250 tickets were sold") and one value equation ("for a total of \$2,560"). Three-variable problems add a third relationship ("twice as many dimes as nickels"). Three unknowns and only two relationships? The problem is unsolvable — which is exactly the "equation per unknown" scoreboard at work.

Practice: Word Problems (2 and 3 Unknowns)

1

Tickets. A school play sells 250 tickets for a total of \$2,560. Adult tickets cost \$12 and student tickets cost \$8. How many of each were sold?

Givens: 250 total tickets; \$2,560 total revenue; \$12 per adult ticket; \$8 per student ticket.

Variables: let $a$ = adult tickets sold, $s$ = student tickets sold. Two unknowns → we need two equations.

$$\begin{cases} a + s = 250 & \text{(count)} \\ 12a + 8s = 2560 & \text{(value)} \end{cases}$$

Substitute $s = 250 - a$: $\;12a + 8(250 - a) = 2560 \Rightarrow 4a + 2000 = 2560 \Rightarrow a = 140$, so $s = 110$.

$$\boxed{140 \text{ adult and } 110 \text{ student tickets}}$$

2

Two numbers. The sum of two numbers is 27 and their difference is 5. Find the numbers.

Givens: sum $= 27$; difference $= 5$.

Variables: let $x$ = larger number, $y$ = smaller number.

$$\begin{cases} x + y = 27 \\ x - y = 5 \end{cases}$$

Add: $2x = 32 \Rightarrow x = 16$, so $y = 11$.

$$\boxed{16 \text{ and } 11}$$

3

Coffee blend. A café mixes beans worth \$9/lb with beans worth \$14/lb to make 20 lb of a blend worth \$11/lb. How many pounds of each?

Givens: prices \$9/lb and \$14/lb; blend totals 20 lb; blend price \$11/lb, so total value $= 20 \times 11 = \$220$.

Variables: let $x$ = pounds of \$9 beans, $y$ = pounds of \$14 beans.

$$\begin{cases} x + y = 20 & \text{(weight)} \\ 9x + 14y = 220 & \text{(value)} \end{cases}$$

Substitute $y = 20 - x$: $\;9x + 280 - 14x = 220 \Rightarrow -5x = -60 \Rightarrow x = 12$, so $y = 8$.

$$\boxed{12 \text{ lb of the \$9 beans, } 8 \text{ lb of the \$14 beans}}$$

4

River current. A boat travels 36 miles downstream in 2 hours, and the same 36 miles back upstream in 3 hours. Find the boat's speed in still water and the speed of the current.

Givens: downstream: 36 mi in 2 h $\Rightarrow$ effective speed $18$ mph; upstream: 36 mi in 3 h $\Rightarrow$ effective speed $12$ mph. Current helps downstream, hurts upstream.

Variables: let $b$ = boat speed in still water (mph), $c$ = current speed (mph).

$$\begin{cases} b + c = 18 & \text{(downstream)} \\ b - c = 12 & \text{(upstream)} \end{cases}$$

Add: $2b = 30 \Rightarrow b = 15$, so $c = 3$.

$$\boxed{b = 15 \text{ mph}, \quad c = 3 \text{ mph}}$$

5

Gym memberships. Gym A charges a \$60 joining fee plus \$25 per month. Gym B has no joining fee but charges \$40 per month. After how many months do the two gyms cost the same — and which is cheaper before that?

Givens: Gym A: \$60 fee $+ \$25$/month; Gym B: \$40/month, no fee.

Variables: let $m$ = number of months, $C$ = total cost (\$).

$$\begin{cases} C = 60 + 25m & \text{(Gym A)} \\ C = 40m & \text{(Gym B)} \end{cases}$$

Set equal (substitution!): $60 + 25m = 40m \Rightarrow 15m = 60 \Rightarrow m = 4$, with $C = 160$.

Before month 4, Gym B is cheaper (e.g. at $m=2$: \$110 vs. \$80); after, Gym A wins.

$$\boxed{\text{Equal at } 4 \text{ months } (\$160); \text{ Gym B cheaper before that}}$$

Investments. You split \$10,000 between an account earning 3% per year and one earning 5% per year. After one year the total interest is \$380. How much went into each account?

Givens: total invested \$10,000; rates 3% and 5%; total interest \$380.

Variables: let $x$ = dollars at 3%, $y$ = dollars at 5%.

$$\begin{cases} x + y = 10000 \\ 0.03x + 0.05y = 380 \end{cases}$$

Substitute $y = 10000 - x$: $\;0.03x + 500 - 0.05x = 380 \Rightarrow -0.02x = -120 \Rightarrow x = 6000$, so $y = 4000$.

$$\boxed{\$6{,}000 \text{ at } 3\%, \quad \$4{,}000 \text{ at } 5\%}$$

Snack stand (3 unknowns). Two pretzels, one soda, and one candy bar cost \$7.00. One pretzel, two sodas, and one candy bar cost \$7.50. One pretzel, one soda, and two candy bars cost \$7.50. Find the price of each item.

Givens: three purchase combinations with three totals. Three unknowns — and the story hands us exactly three equations. The scoreboard balances.

Variables: let $p$, $s$, $c$ = price (\$) of a pretzel, soda, candy bar.

Three Forms, One Parabola

Every quadratic function can be dressed in three different outfits. They describe the same curve — each form just makes different features visible at a glance. And notice: every form has exactly three parameters. That number 3 is a property of the parabola itself, not of the notation — and it's why three pieces of information will always be the price of pinning one down.

Standard Form

$$y = ax^2 + bx + c$$

Parameters $a, b, c$. Shows the $y$-intercept instantly: at $x=0$, $y=c$ (gold dot). Best form for the quadratic formula and for polynomial arithmetic.

Vertex Form

$$y = a(x - h)^2 + k$$

Parameters $a, h, k$. Shows the vertex $(h, k)$ and axis of symmetry $x = h$ (dashed line) instantly. Best form for max/min questions and transformations.

Factored Form

$$y = a(x - p)(x - q)$$

Parameters $a, p, q$. Shows the roots $x = p$ and $x = q$ (gold dots) instantly. Best form for intercept questions. Only exists over the reals when the parabola actually crosses the $x$-axis.

The shared parameter: $a$

The same $a$ appears in all three forms.

It controls opening direction ($a > 0$ up, $a < 0$ down) and width (bigger $|a|$ = narrower). Converting between forms never changes $a$ — a useful sanity check on your algebra.

Variables vs. parameters, again: in all three forms, $x$ and $y$ are the variables — they trace the curve. The three letters that differ between forms ($b, c$ vs. $h, k$ vs. $p, q$) are parameters: fixed numbers that select which parabola. When a problem says "find the equation of the parabola," it is asking for the values of the three parameters.

Converting Between Forms

Standard form is the hub. Going to standard form is always easy — just expand. Going from standard form takes real technique: completing the square (to vertex) or factoring / the quadratic formula (to factored). To travel between vertex and factored form, you can route through standard — though a couple of direct shortcuts exist.

Conversion 1: Anything → Standard (Expand)

Concept

Multiply everything out and collect like terms. No cleverness required — this direction is pure mechanics.

Worked Example

Convert $y = 2(x - 3)^2 + 1$ and $y = -3(x - 1)(x - 5)$ to standard form.

Vertex → standard. Square first, then distribute $a$, then add $k$:

$$y = 2(x^2 - 6x + 9) + 1 = 2x^2 - 12x + 18 + 1 = 2x^2 - 12x + 19$$

Factored → standard. FOIL first, then distribute $a$:

$$y = -3(x^2 - 6x + 5) = -3x^2 + 18x - 15$$

Sanity check: $a$ stayed $2$ and $-3$ respectively — the leading coefficient never changes under conversion.

Conversion 2: Standard → Vertex (Complete the Square)

Concept

Force a perfect square trinomial to appear, then compensate for what you added. This is the one conversion students lose points on — go slowly with the $a \neq 1$ case.

0

The plan. We'll rewrite $y = 2x^2 + 8x + 3$ so that all the $x$'s live inside one squared bundle $(x - h)^2$. Strategy: factor $a$ out of the $x$-terms only, build the perfect square inside the parentheses, and carefully track what we've really added.

1

Factor $a$ out of the $x$-terms only. Leave the constant alone:

$$y = 2(x^2 + 4x) + 3$$

2

Complete the square inside. Half of $4$ is $2$; squaring gives $4$. Add and subtract it inside the parentheses so we've changed nothing:

$$y = 2(x^2 + 4x + 4 - 4) + 3 = 2\left((x + 2)^2 - 4\right) + 3$$

3

Distribute and combine constants. The $-4$ inside is multiplied by the $2$ outside — this is where the classic error lives:

$$y = 2(x + 2)^2 - 8 + 3 = 2(x + 2)^2 - 5$$

$$\boxed{y = 2(x + 2)^2 - 5}, \qquad \text{vertex } (-2, -5)$$

Check with the vertex shortcut: $h = -\dfrac{b}{2a} = -\dfrac{8}{4} = -2$ ✓ and $k = y(-2) = 8 - 16 + 3 = -5$ ✓

Shortcut worth memorizing: $h = -\dfrac{b}{2a}$, then $k = y(h)$ by plugging in. Completing the square derives this; the shortcut is what you'll use under time pressure. Use each to check the other.

Conversion 3: Standard → Factored (Factor, or Quadratic Formula)

Concept

The roots are the parameters $p$ and $q$. Find them by factoring when the numbers are friendly, or by the quadratic formula when they're not — then reassemble as $a(x-p)(x-q)$, keeping the same $a$.

$$x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a} \qquad\qquad \text{discriminant } D = b^2 - 4ac$$

Worked Example

Convert $y = 3x^2 - 12x + 9$ to factored form.

Step 1. Factor out $a = 3$ first: $\;y = 3(x^2 - 4x + 3)$.

Step 2. Factor the inside: two numbers that multiply to $3$ and add to $-4$ are $-1$ and $-3$:

$$y = 3(x - 1)(x - 3)$$

Check: roots at $x = 1, 3$; plug $x=1$ into the original: $3 - 12 + 9 = 0$ ✓

If the inside hadn't factored nicely, the quadratic formula on $x^2 - 4x + 3 = 0$ would deliver the same $p$ and $q$.

When factored form doesn't exist (over the reals): if the discriminant $b^2 - 4ac < 0$, the parabola never touches the $x$-axis — there are no real roots, so no real factored form. If $b^2 - 4ac = 0$, the two roots merge: $y = a(x - p)^2$, and the vertex sits on the $x$-axis.

Conversion 4: The Direct Shortcuts (Vertex ↔ Factored)

Concept

Factored → vertex: by symmetry, the vertex sits halfway between the roots: $h = \dfrac{p + q}{2}$, then $k = y(h)$. Vertex → factored: set $y = 0$ and solve $a(x-h)^2 + k = 0$ for the roots directly — no need to expand first.

Worked Example

Convert $y = (x-1)(x-7)$ to vertex form, and $y = (x - 2)^2 - 9$ to factored form.

Factored → vertex. Roots are $1$ and $7$, so $h = \dfrac{1 + 7}{2} = 4$ and $k = (4-1)(4-7) = -9$:

$$y = (x - 4)^2 - 9$$

Vertex → factored. Solve $(x-2)^2 - 9 = 0$: $\;(x-2)^2 = 9 \Rightarrow x - 2 = \pm 3 \Rightarrow x = 5 \text{ or } -1$:

$$y = (x - 5)(x + 1)$$

Check both by expanding: $(x-4)^2 - 9 = x^2 - 8x + 7 = (x-1)(x-7)$ ✓ and $(x-5)(x+1) = x^2 - 4x - 5 = (x-2)^2 - 9$ ✓

One Point per Parameter

Here's where the packet's two halves snap together. A parabola has three parameters — so pinning one down costs three pieces of information. The most common piece of information is a point:

Plug a known point $(x_0, y_0)$ into $y = ax^2 + bx + c$, and $x$ and $y$ stop being variables — they become numbers. What's left is one linear equation in the parameters $a$, $b$, $c$. Three points → three equations → a 3×3 system — exactly the kind you drilled in the first half of the packet. Where a new variable cost you a new equation, a new parameter costs you a new point.

Some givens are worth more than one unit of information. Keep score:

An ordinary point — worth 1

"Passes through $(2, 5)$" gives one equation: $\,5 = 4a + 2b + c$.

A root or the y-intercept — worth 1 (but a nice one)

A root is a point whose $y$-value is $0$; the $y$-intercept is a point whose $x$-value is $0$ (it hands you $c$ directly). Still one unit each — just conveniently placed.

The vertex — worth 2!

"Vertex at $(3, -1)$" tells you a point on the curve and where the axis of symmetry is. In vertex form it sets $h$ and $k$ at once — two of the three parameters. One more point finishes the job.

Strategy rule: let the givens choose the form. Given the vertex? Start from vertex form. Given the roots? Start from factored form. Given three ordinary points? Standard form + a 3×3 system. You'll finish with whichever form the question asks for by converting (Quadratic Forms tab).

Case 1: Three Ordinary Points (the 3×3 Reunion)

Fit $y = ax^2 + bx + c$ through $(1, 2)$, $(2, 3)$, $(3, 6)$

Concept

Three unknown parameters, three points, three equations. Each substitution manufactures one equation; then it's the 3×3 elimination procedure from the first half of the packet.

Worked Example

Givens: the parabola passes through $(1,2)$, $(2,3)$, $(3,6)$.

Unknowns: the parameters $a$, $b$, $c$ — the variables of our system.

Step 1 — one equation per point. Substitute each point into $y = ax^2 + bx + c$:

$$\begin{cases} a + b + c = 2 & \text{from } (1,2) \\ 4a + 2b + c = 3 & \text{from } (2,3) \\ 9a + 3b + c = 6 & \text{from } (3,6) \end{cases}$$

Step 2 — eliminate $c$ (it has coefficient $1$ everywhere — subtract consecutive equations):

$$\text{Eq2} - \text{Eq1}: \; 3a + b = 1 \qquad \text{Eq3} - \text{Eq2}: \; 5a + b = 3$$

Step 3 — solve the 2×2. Subtract again: $2a = 2 \Rightarrow a = 1$, then $b = 1 - 3 = -2$, and from Eq1: $c = 2 - 1 + 2 = 3$.

Step 4 — check in all three points: $1 - 2 + 3 = 2$ ✓, $\;4 - 4 + 3 = 3$ ✓, $\;9 - 6 + 3 = 6$ ✓

$$\boxed{y = x^2 - 2x + 3}$$

Notice the rhythm: points became equations, parameters became the unknowns. That's the whole trick.

Case 3: Two Roots + One Point

Initial-Value Problems: Parameters With Day Jobs

In applications, the three parameters of a quadratic stop being abstract dials — they get physical meanings. The star example is projectile motion (height in feet, time in seconds):

$$h(t) = -16t^2 + v_0 t + h_0$$

$h_0$ — the initial height (this is the "initial value")

It's just $c$ in disguise: $h(0) = h_0$. Given as "launched from a 6-ft platform" — which is really the point $(0, 6)$.

$v_0$ — the initial (launch) velocity

It's $b$. "Thrown upward at 32 ft/s" sets $v_0 = 32$. Negative $v_0$ means thrown downward.

$-16$ — gravity's contribution (fixed!)

It's $a$, and physics pays for it: $-16$ ft/s² (or $-4.9$ in meters) is half the acceleration of gravity. When gravity fixes $a$, you only owe two more pieces of information for the remaining parameters.

Translating story → points & features:

"launched from height $H$" → point $(0, H)$  •  "reaches maximum $M$ at time $T$" → vertex $(T, M)$  •  "hits the ground at time $T$" → root $t = T$  •  "at time $t_1$ its height is $H_1$" → point $(t_1, H_1)$.

Then run the information budget from the Fitting Parabolas tab and let the givens choose the form. Same game, physical costume.

Worked Example: The Full Story of One Throw

A ball is thrown upward at 32 ft/s from a 6-ft platform.

Find: (a) the height function, (b) the maximum height, (c) when it lands.

Givens: $v_0 = 32$ ft/s (thrown upward); $h_0 = 6$ ft; gravity fixes $a = -16$ ft/s².

Variables: $t$ = time (s) since the throw; $h$ = height (ft). Parameters all paid for — no fitting needed here.

(a) $$h(t) = -16t^2 + 32t + 6$$

(b) The maximum lives at the vertex: $t = -\dfrac{b}{2a} = -\dfrac{32}{2(-16)} = 1$ s, and

$$h(1) = -16 + 32 + 6 = 22 \text{ ft}$$

(c) Landing means $h = 0$ — a root question, so use the quadratic formula on $-16t^2 + 32t + 6 = 0$:

$$t = \frac{-32 \pm \sqrt{32^2 - 4(-16)(6)}}{2(-16)} = \frac{-32 \pm \sqrt{1408}}{-32} = 1 \pm \frac{\sqrt{22}}{4}$$

The two roots are $t \approx -0.17$ and $t \approx 2.17$. Time can't be negative — the negative root is where the parabola would have started from the ground if it had been launched earlier. Keep the physical one:

$$\boxed{h(t) = -16t^2 + 32t + 6, \quad \text{max } 22 \text{ ft at } t = 1\text{ s}, \quad \text{lands at } t \approx 2.17 \text{ s}}$$

A rocket's height is $h(t) = -16t^2 + 96t + 112$ (feet, seconds). Read off the initial height and launch velocity; then find the maximum height and the landing time.

Reading the parameters

Givens: the full height function. Read directly: $h_0 = 112$ ft (the constant term), $v_0 = 96$ ft/s (the $t$ coefficient).

Maximum: $t = -\dfrac{96}{2(-16)} = 3$ s; $\;h(3) = -144 + 288 + 112 = 256$ ft.

Landing: $-16t^2 + 96t + 112 = 0$. Divide by $-16$: $\;t^2 - 6t - 7 = 0 \Rightarrow (t-7)(t+1) = 0$. Reject $t = -1$ (before launch).

$$\boxed{h_0 = 112 \text{ ft}, \; v_0 = 96 \text{ ft/s}, \; \text{max } 256 \text{ ft at } t=3, \; \text{lands } t = 7 \text{ s}}$$

An object is dropped (not thrown) from a 144-ft bridge. Write $h(t)$ and find when it hits the water.

Dropped = zero initial velocity

Givens: $h_0 = 144$; "dropped" means $v_0 = 0$; $a = -16$.

$$h(t) = -16t^2 + 144$$

Set $h = 0$: $\;16t^2 = 144 \Rightarrow t^2 = 9 \Rightarrow t = 3$ (reject $-3$).

$$\boxed{h(t) = -16t^2 + 144; \quad \text{hits water at } t = 3 \text{ s}}$$

A ball is launched from a 5-ft tee and reaches its maximum height of 69 ft at $t = 2$ s. Find $h(t)$ and the launch velocity $v_0$. (Don't assume $a = -16$ — let the data tell you.)

Vertex + initial value

Givens: max 69 ft at $t=2$ → vertex $(2, 69)$, worth 2; launched from 5 ft → point $(0, 5)$, worth 1. Budget: 3 ✓

Vertex form: $h(t) = a(t - 2)^2 + 69$. Substitute $(0, 5)$: $\;5 = 4a + 69 \Rightarrow a = -16$.

The data recovered gravity on its own! Expand for $v_0$:

$$h(t) = -16(t-2)^2 + 69 = -16t^2 + 64t + 5$$

$$\boxed{h(t) = -16t^2 + 64t + 5, \quad v_0 = 64 \text{ ft/s}}$$

A ball is thrown from a 4-ft height; one second later it is 52 ft up. Using $a = -16$, find $v_0$, then the maximum height.

Physics pays for a; two givens finish it

Givens: $a = -16$ (physics); $(0, 4)$ so $h_0 = 4$; point $(1, 52)$. Budget: $1 + 1 + 1 = 3$ ✓

$h(t) = -16t^2 + v_0 t + 4$. Substitute $(1, 52)$: $\;52 = -16 + v_0 + 4 \Rightarrow v_0 = 64$.

Maximum: $t = \dfrac{64}{32} = 2$ s; $\;h(2) = -64 + 128 + 4 = 68$ ft.

$$\boxed{v_0 = 64 \text{ ft/s}; \quad \text{max height } 68 \text{ ft at } t = 2 \text{ s}}$$

Recover everything from data. A sensor records a projectile's height three times: $h(1) = 48$, $h(2) = 64$, $h(3) = 48$. Fit $h(t) = at^2 + bt + c$, then interpret each parameter physically.

Three points → 3×3 system

Givens: points $(1, 48)$, $(2, 64)$, $(3, 48)$. Budget: 3 ✓ (Symmetry bonus: equal heights at $t = 1, 3$ put the vertex at $t = 2$.)

$$\begin{cases} a + b + c = 48 \\ 4a + 2b + c = 64 \\ 9a + 3b + c = 48 \end{cases}$$

Eq2 $-$ Eq1: $3a + b = 16$.   Eq3 $-$ Eq2: $5a + b = -16$. Subtract: $2a = -32 \Rightarrow a = -16$, $\;b = 64$, $\;c = 48 - (-16) - 64 = 0$.

Interpretation: $a = -16$: earth's gravity, recovered from data. $c = 0$: launched from the ground. $b = 64$: launch velocity 64 ft/s. Max height $h(2) = 64$ ft.

$$\boxed{h(t) = -16t^2 + 64t \;-\; \text{ground launch at } 64 \text{ ft/s}}$$

Soccer kick (horizontal version). A ball kicked from the ground lands 60 m away, reaching a maximum height of 15 m. With $x$ = horizontal distance and $y$ = height, find $y(x)$ and the height when $x = 10$ m.

Roots + vertex height

Givens: roots $x = 0$ and $x = 60$ (kicked from and lands on the ground) — worth 2; max height 15 m — the vertex $y$-value, worth 1. Budget: 3 ✓

Factored form: $y = ax(x - 60)$. By symmetry the vertex is at $x = 30$:

$$15 = a(30)(-30) = -900a \;\Rightarrow\; a = -\tfrac{1}{60}$$

At $x = 10$: $\;y = -\tfrac{1}{60}(10)(-50) = \tfrac{500}{60} \approx 8.3$ m.

$$\boxed{y = -\tfrac{1}{60}\,x(x - 60); \quad y(10) \approx 8.3 \text{ m}}$$

Parabolic arch. A bridge arch spans 40 ft and is 20 ft tall at its center. Putting the origin at the left base of the arch, find the arch's equation and the clearance 5 ft in from the base.

Roots + vertex height

Givens: bases at $x = 0$ and $x = 40$ (roots, worth 2); center height 20 ft → vertex $(20, 20)$, its height worth 1. Budget: 3 ✓

$y = ax(x - 40)$; at the vertex: $20 = a(20)(-20) = -400a \Rightarrow a = -\tfrac{1}{20}$.

Clearance at $x = 5$: $\;y = -\tfrac{1}{20}(5)(-35) = \tfrac{175}{20} = 8.75$ ft.

$$\boxed{y = -\tfrac{1}{20}\,x(x - 40); \quad \text{clearance } 8.75 \text{ ft}}$$

Revenue. A shop sells 100 T-shirts a week at \$10 each. Each \$1 price increase costs 5 sales per week. What price maximizes weekly revenue, and what is that revenue?

Build the quadratic, then vertex

Givens: base price \$10 → 100 sales; each $+\$1$ → $-5$ sales.

Variables: let $x$ = number of \$1 increases; revenue $R = (\text{price})(\text{quantity})$:

$$R(x) = (10 + x)(100 - 5x)$$

This is factored form with roots $x = -10$ and $x = 20$! The vertex sits midway: $x = \dfrac{-10 + 20}{2} = 5$.

Price $= 10 + 5 = \$15$; quantity $= 100 - 25 = 75$; revenue $= 15 \times 75 = \$1125$.

$$\boxed{\$15 \text{ per shirt} \;\rightarrow\; \$1125 \text{ per week}}$$

Full flight, no shortcuts given. A rocket launches from an 80-ft platform with initial velocity 64 ft/s. Find $h(t)$, the height at $t = 1$, the maximum height, and the landing time.

Complete initial-value problem

Givens: $h_0 = 80$, $v_0 = 64$, $a = -16$.

$$h(t) = -16t^2 + 64t + 80$$

At $t=1$: $-16 + 64 + 80 = 128$ ft.

Maximum: $t = \dfrac{64}{32} = 2$ s; $\;h(2) = -64 + 128 + 80 = 144$ ft.

Landing: divide $-16t^2 + 64t + 80 = 0$ by $-16$: $\;t^2 - 4t - 5 = 0 \Rightarrow (t - 5)(t + 1) = 0 \Rightarrow t = 5$ (reject $-1$).

$$\boxed{h(t) = -16t^2 + 64t + 80; \;\; h(1) = 128 \text{ ft}; \;\; \text{max } 144 \text{ ft}; \;\; \text{lands } t = 5 \text{ s}}$$

Capstone: count the information. For each scenario, say whether the parabola is fully determined, underdetermined, or overdetermined — no solving needed. (i) Launch height and launch velocity known, gravity $= -16$. (ii) Landing time and maximum height known, gravity not assumed. (iii) Launch height, launch velocity, max height, AND landing time all given, gravity $= -16$.

Information budget only

(i) Determined. Gravity fixes $a$ (1), launch height fixes $c$ (1), launch velocity fixes $b$ (1). Total 3 = 3 parameters. ✓

(ii) Underdetermined. Landing time is a root (1); max height gives the vertex's $y$-value (1). That's 2 units against 3 parameters — a family of flights fits. (E.g. steep-and-fast vs. shallow-and-slow can share a landing time and max height.)

(iii) Overdetermined. That's 4 units of information for 3 parameters. It only works if the givens happen to be consistent — like a 3×3 system plus one extra equation that had better agree. Real data usually won't, which is exactly why "best fit" exists in statistics.

$$\boxed{\text{(i) determined} \quad \text{(ii) underdetermined} \quad \text{(iii) overdetermined}}$$

You made it. One thread, start to finish: unknowns cost information. Variables cost equations; parameters cost points; physics can pick up part of the bill. If you can run that budget on sight, you're ready for Precalculus.
