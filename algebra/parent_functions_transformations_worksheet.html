Every function family starts from a parent function — the simplest member of the family. Know these cold: their shape, key points, domain, and range.

Linear

$f(x) = x$
Domain: $(-\infty, \infty)$
Range: $(-\infty, \infty)$
Key: passes through origin, slope 1

$f(x) = x^2$

The 4-Step Method: From Equation to Graph

Every transformation problem, no matter how messy it looks, can be handled with the same four moves. Learn the routine here; the rest of the worksheet is practice applying it.

1

Identify the parent function. Strip away every number and ask: what is being done to $x$? A square, an absolute value, a root, a base raised to $x$, a sine? That operation names the parent $f(x)$.

2

Rewrite into standard form and read off $h$, $b$, $a$, $k$. Force the equation to look like $g(x) = a \cdot f\big(b(x - h)\big) + k$. The key trap: if $x$ has a coefficient inside, factor it out first — $(2x - 6)$ must become $2(x - 3)$ before you can see $h$.

3

Apply the transformations in order, inside-out. Horizontal shift ($h$) → horizontal stretch/reflect ($b$) → vertical stretch/reflect ($a$) → vertical shift ($k$). Sketch each stage lightly, or just track the "anchor" of the graph (vertex, starting point, center, or a point on the asymptote).

4

Verify with one point. Pick one easy parent point, push it through $\left(\dfrac{x_0}{b} + h,\; a\,y_0 + k\right)$, and confirm it lies on your final sketch. If it does not, the mistake is almost always in Step 2.

Worked Example: Graph $g(x) = 3 \cdot 2^{\,2x - 4} - 1$

Worked Example

Step 1 — Parent. The variable $x$ sits in an exponent with base 2, so the parent is the exponential $f(x) = 2^x$. Everything else is decoration.

Step 2 — Standard form. The exponent $2x - 4$ has a coefficient on $x$, so factor it: $2x - 4 = 2(x - 2)$. Now the equation matches the template:

$$g(x) = \underbrace{3}_{a} \cdot 2^{\,\overbrace{2}^{b}\,(x - \overbrace{2}^{h})} \;\underbrace{-\;1}_{k}$$

Given: parent $f(x) = 2^x$;   $h = 2$,   $b = 2$,   $a = 3$,   $k = -1$

Common mistake: reading $2x - 4$ as "shift right 4." The shift is $h = 2$, not 4 — the horizontal compression by $b = 2$ halved it. Always factor before you read $h$.

Step 3 — Apply in order. Track the parent's anchor point $(0, 1)$ and its asymptote $y = 0$ through each stage:

Run the 4-step method on $g(x) = \tfrac{1}{2}\,|2x + 6| - 3$. Name the parent, list $h$, $b$, $a$, $k$, describe the transformations in order, and give the vertex.

The General Transformation Form

$$g(x) = a \cdot f\!\left(b(x - h)\right) + k$$
ParameterWhat It DoesExample
$a > 1$ Vertical stretch (taller) by factor $|a|$ $2x^2$ is twice as tall as $x^2$
$0 < |a| < 1$ Vertical compression (shorter) by factor $|a|$ $\tfrac{1}{2}x^2$ is half as tall
$a < 0$ Reflection over the $x$-axis (flips vertically) $-x^2$ opens downward
$h > 0$ Shift right by $h$ units $(x-3)^2$ shifts right 3
$h < 0$ Shift left by $|h|$ units $(x+2)^2$ shifts left 2
$k > 0$ Shift up by $k$ units $x^2 + 4$ shifts up 4
$k < 0$ Shift down by $|k|$ units $x^2 - 1$ shifts down 1
$b > 1$ Horizontal compression (narrower) by factor $\tfrac{1}{b}$ $(2x)^2$ is half as wide
$0 < b < 1$ Horizontal stretch (wider) by factor $\tfrac{1}{b}$ $(\tfrac{1}{2}x)^2$ is twice as wide
$b < 0$ Reflection over the $y$-axis (flips horizontally) $\sqrt{-x}$ is reflected left-right

Order of Transformations

When graphing $g(x) = a \cdot f(b(x-h)) + k$, read the transformations inside-out — just like PEMDAS tells you to start with the innermost parentheses:

$$\underbrace{a}_{\text{4th: multiply}} \cdot \underbrace{f\Big(\underbrace{b\big(\underbrace{x - h}_{\text{1st: shift}}\big)}_{\text{2nd: stretch}}\Big)}_{\text{3rd: apply }f} + \underbrace{k}_{\text{5th: shift}}$$
Think of it like PEMDAS: Just as $3(x-2)^2 + 5$ means "subtract 2, then square, then multiply by 3, then add 5," the transformation $a \cdot f(b(x-h))+k$ means: start closest to $x$ and work outward.

Follow the $x$: $$\begin{aligned} x \;&\xrightarrow{\;\text{subtract }h\;}\; (x - h) \;\xrightarrow{\;\text{multiply by }b\;}\; b(x-h) \;\xrightarrow{\;\text{apply }f\;}\; f\!\big(b(x-h)\big) \\[6pt] &\xrightarrow{\;\text{multiply by }a\;}\; a \cdot f\!\big(b(x-h)\big) \;\xrightarrow{\;\text{add }k\;}\; \boxed{a \cdot f\!\big(b(x-h)\big) + k} \end{aligned}$$
Why does this matter? If you do $b$ before $h$, you can accidentally shift to the wrong spot. Example: for $g(x) = (2x - 6)^2$, first rewrite as $(2(x-3))^2$ so you can see it's $h = 3$ then $b = 2$ — shift right 3, then compress horizontally by $\tfrac{1}{2}$. If you stretch first without rewriting, you'll misplace the vertex.

Example 3A: Graph $g(x) = -2(x - 3)^2 + 4$ by applying transformations to $f(x) = x^2$ in the correct order.

Given: $a = -2$, $b = 1$, $h = 3$, $k = 4$

Step 1 — Horizontal shift ($h = 3$): Closest to $x$ in the expression. Shift the entire parabola right 3 units. The vertex moves from $(0,0)$ to $(3,0)$. We now have $(x-3)^2$.

Step 2 — Horizontal stretch ($b = 1$): $b = 1$ means no horizontal scaling — skip this one.

Step 3 — Vertical stretch & reflect ($a = -2$): Stretch vertically by factor 2, then flip over the $x$-axis. The vertex stays at $(3,0)$ but the parabola now opens downward and is narrower. We have $-2(x-3)^2$.

Step 4 — Vertical shift ($k = 4$): Last operation, outermost. Shift everything up 4 units. The vertex moves from $(3,0)$ to $(3,4)$. Final: $g(x) = -2(x-3)^2 + 4$.

Showing: $f(x) = x^2$ (parent)

Example 3B: Graph $g(x) = \sqrt{-(x + 2)} + 1$ by applying transformations to $f(x) = \sqrt{x}$.

Given: Rewrite as $g(x) = \sqrt{-1 \cdot (x - (-2))} + 1$, so $a = 1$, $b = -1$, $h = -2$, $k = 1$.

Step 1 — Horizontal shift ($h = -2$): Innermost operation on $x$. Shift left 2 units. The starting point moves from $(0,0)$ to $(-2, 0)$. We have $\sqrt{x+2}$.

Step 2 — Horizontal reflect ($b = -1$): Reflect over the $y$-axis (through the shifted starting point). The square root now extends to the left from $(-2, 0)$. We have $\sqrt{-(x+2)}$.

Step 3 — Vertical stretch ($a = 1$): No change.

Step 4 — Vertical shift ($k = 1$): Outermost operation. Shift up 1 unit. Starting point moves to $(-2, 1)$. Final: $g(x) = \sqrt{-(x+2)} + 1$.

Showing: $f(x) = \sqrt{x}$ (parent)

The Key-Point Method: An Alternative to Step-by-Step Shifting

Heads up: most courses teach transformations only as the step-by-step "shift, stretch, reflect, shift" process from the Rules tab. The method below is a faster alternative that many textbooks skip: instead of moving the whole graph one transformation at a time, you move a handful of points with a single formula and connect them. Both methods give the same graph — use whichever your class expects, and use this one to check your work.

If $(x_0, y_0)$ is a point on the parent $f(x)$, then the corresponding point on $g(x) = a \cdot f(b(x-h))+k$ is:

$$\left(\frac{x_0}{b} + h,\; a \cdot y_0 + k\right)$$

Where does this come from? Two parallel questions:

For $X$: "What input $X$ makes the inside of $f$ equal $x_0$?"   Solve $b(X - h) = x_0$:

$$X = \frac{x_0}{b} + h \quad \longleftarrow \text{only } b \text{ and } h \text{ affect the } x\text{-coordinate}$$

For $Y$: "Once $f$ outputs $y_0$, what does the outside of $f$ do to it?"   Apply $Y = a \cdot f(\cdots) + k$:

$$Y = a \cdot y_0 + k \quad \longleftarrow \text{only } a \text{ and } k \text{ affect the } y\text{-coordinate}$$
Clean symmetry: The horizontal parameters ($b$ and $h$) control where the point lands left–right. The vertical parameters ($a$ and $k$) control where it lands up–down. They don't cross over — $a$ and $k$ never touch the $x$-coordinate, and $b$ and $h$ never touch the $y$-coordinate.

This is the fastest way to plot a transformed function: take 3–5 key points from the parent, apply the formula, and connect the dots.

Why does order matter in the strip? Because $g(x) = a\cdot f\big(b(x-h)\big) + k$ is evaluated inside-out. The input $x$ is shifted by $h$ first, then scaled by $b$, then $f$ is applied, then the output is scaled by $a$, then shifted by $k$. Amplitude: $|a| = 2$. Period: $2\pi$. Phase shift: Left $\tfrac{\pi}{4}$. Midline: $y = 1$.

Watch out: Because $a < 0$, the sine wave is flipped — the first quarter-cycle goes down to the minimum instead of up to the maximum. The key-point method catches this automatically!

For the function below, identify the parent, describe all transformations, find the domain and range, and sketch the graph with at least 3 labeled points:

$$g(x) = -\frac{1}{2}\sqrt[3]{x + 4} + 3$$

Parent: $f(x) = \sqrt[3]{x}$.

Parameters: $a = -\tfrac{1}{2}$, $h = -4$, $k = 3$.

2. Vertical compression by factor $\tfrac{1}{2}$

$(1, 1) \to (-3, 2.5)$

For each description, write the equation of the transformed function. A reliable method: list the givens first — identify the parent, then assign each transformation to one of $a$, $b$, $h$, $k$ — and only then substitute into $g(x) = a \cdot f\big(b(x-h)\big) + k$.

Write the Equation

The graph of $f(x) = |x|$ is shifted right 3 units, vertically stretched by a factor of 4, and shifted down 2 units. Write the equation of the transformed function and state its vertex.

Given: parent $f(x) = |x|$
right 3 $\Rightarrow h = 3$;   vertical stretch by 4 $\Rightarrow a = 4$;   down 2 $\Rightarrow k = -2$;   no horizontal scaling $\Rightarrow b = 1$

Substitute into $g(x) = a\,f(x-h)+k$:

$$g(x) = 4|x - 3| - 2$$

Vertex: the parent's vertex $(0,0)$ maps to $(0 + h,\; a\cdot 0 + k) = (3, -2)$.

Write the Equation

The graph of $f(x) = x^2$ is reflected over the $x$-axis, shifted left 5 units, vertically compressed by a factor of $\tfrac{1}{3}$, and shifted up 1 unit. Write the equation.

Given: parent $f(x) = x^2$
reflect over $x$-axis $\Rightarrow a < 0$;   compress by $\tfrac13 \Rightarrow |a| = \tfrac13$, so $a = -\tfrac13$
left 5 $\Rightarrow h = -5$;   up 1 $\Rightarrow k = 1$
$$g(x) = -\tfrac{1}{3}(x + 5)^2 + 1$$
Why the listed order didn't trip us up: the reflection and the compression are both part of $a$, and the horizontal shift lives in a completely separate slot ($h$). The only order that changes the answer is vertical shift vs. vertical reflect/stretch — see the next problem.
15
Order Matters

The graph of $f(x) = 2^x$ is shifted down 3 units first, and then reflected over the $x$-axis. Write the equation, and explain why it differs from "reflect first, then shift down 3."

Given: parent $f(x) = 2^x$;   step 1: down 3;   step 2: reflect over the $x$-axis

Apply the steps in the order stated, to the whole expression each time:

Step 1 (down 3): $2^x - 3$

Step 2 (reflect over $x$-axis, i.e. multiply the entire output by $-1$): $-(2^x - 3)$

$$g(x) = -2^x + 3$$

In standard form this is $a = -1$, $k = +3$ — the reflection flipped the sign of the shift. Had we reflected first and then shifted down 3, we would get $-2^x - 3$, whose asymptote is $y = -3$ instead of $y = 3$.

Rule of thumb: the standard form $a\,f(b(x-h)) + k$ always means "stretch/reflect vertically then shift vertically." If a problem describes the vertical shift before the reflection or stretch, apply the operations literally in order and then simplify to read off $a$ and $k$.
— — — parent $2^x$ ——— $g(x) = -2^x + 3$ - - - asymptote $y = 3$

Reflection over the y-axis

The graph of $f(x) = \dfrac{1}{x}$ is reflected over the $y$-axis, shifted right 2 units, and shifted up 4 units. Write the equation in the form $a\,f\big(b(x-h)\big)+k$, then simplify. State the asymptotes.

Given: parent $f(x) = \dfrac1x$
reflect over $y$-axis $\Rightarrow b = -1$;   right 2 $\Rightarrow h = 2$;   up 4 $\Rightarrow k = 4$;   $a = 1$

Standard form: $g(x) = f\big(-1\cdot(x-2)\big) + 4 = \dfrac{1}{-(x-2)} + 4$

$$g(x) = -\frac{1}{x - 2} + 4$$

Asymptotes: VA at $x = 2$ (from $h$), HA at $y = 4$ (from $k$). Reflections never move asymptotes that pass through the "center."

Notice: because $\frac1x$ is an odd function, reflecting over the $y$-axis produces the same graph as reflecting over the $x$-axis: $\frac{1}{-x} = -\frac1x$. That's why the simplified answer looks like an $x$-axis reflection ($a = -1$). For an odd parent, either description is correct.
17
Horizontal Compression & Reflection

The graph of $f(x) = \sqrt{x}$ is horizontally compressed by a factor of $\tfrac12$, reflected over the $y$-axis, shifted left 1 unit, and shifted up 2 units. Write the equation and state the domain and range.

Given: parent $f(x) = \sqrt{x}$
horizontal compression by $\tfrac12 \Rightarrow |b| = 2$;   reflect over $y$-axis $\Rightarrow b < 0$, so $b = -2$
left 1 $\Rightarrow h = -1$;   up 2 $\Rightarrow k = 2$;   $a = 1$

Substitute: $g(x) = \sqrt{\,b(x-h)\,} + k = \sqrt{-2(x+1)} + 2$

$$g(x) = \sqrt{-2(x + 1)} + 2$$

Domain: need $-2(x+1) \ge 0 \Rightarrow x + 1 \le 0 \Rightarrow x \le -1$, i.e. $(-\infty, -1]$.

Range: $[2, \infty)$ (starting point $(-1, 2)$, opening upward and to the left).

Key-point check: parent $(4, 2) \to \left(\dfrac{4}{b} + h,\; y_0 + k\right) = \left(\dfrac{4}{-2} - 1,\; 4\right) = (-3, 4)$. Verify: $g(-3) = \sqrt{-2(-2)} + 2 = \sqrt4 + 2 = 4$. ✓

Trig from a Description

Write the equation of a cosine function that is reflected over the $x$-axis, has amplitude 3, period $4\pi$, is shifted right $\pi$, and has midline $y = -2$.

Given: parent $f(x) = \cos(x)$
amplitude 3 and reflected $\Rightarrow a = -3$;   period $4\pi \Rightarrow \dfrac{2\pi}{b} = 4\pi \Rightarrow b = \tfrac12$
right $\pi \Rightarrow h = \pi$;   midline $y = -2 \Rightarrow k = -2$
$$g(x) = -3\cos\!\left(\tfrac{1}{2}(x - \pi)\right) - 2$$

Expanded form: $g(x) = -3\cos\!\left(\tfrac{x}{2} - \tfrac{\pi}{2}\right) - 2$. At $x = \pi$ the reflected cosine is at its minimum: $g(\pi) = -3(1) - 2 = -5$.

Equation + Point Tracking

The graph of $f(x) = x^3$ is vertically stretched by a factor of 2, shifted right 1 unit, and shifted down 4 units. (a) Write the equation. (b) Find the image of the parent point $(1, 1)$ under this transformation and confirm it lies on $g$.

Given: parent $f(x) = x^3$;   $a = 2$, $b = 1$, $h = 1$, $k = -4$

(a)

$$g(x) = 2(x - 1)^3 - 4$$

(b) Key-point formula: $(x_0, y_0) \to (x_0 + h,\; a\,y_0 + k) = (1 + 1,\; 2(1) - 4) = (2, -2)$.

Check: $g(2) = 2(2-1)^3 - 4 = 2 - 4 = -2$. ✓
