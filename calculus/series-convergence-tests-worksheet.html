The question every test answers

A series $\sum a_n$ converges when its partial sums approach a limit:

$$S_N = a_1 + a_2 + \cdots + a_N, \qquad \sum_{n=1}^{\infty} a_n = \lim_{N\to\infty} S_N$$

If the limit exists, the series converges to that number. If not, it diverges. Every test below is a shortcut for deciding this without computing the limit directly.

The first check, every time

$n$th-term test for divergence. If $\lim a_n \ne 0$ (or does not exist), the series diverges.

If $\lim a_n = 0$, the test says nothing. The harmonic series $\sum \frac1n$ has terms going to $0$ and still diverges. Terms going to $0$ is necessary for convergence, never sufficient.

2

Benchmarks you compare against

Geometric series

$$\sum_{n=0}^{\infty} a\,r^n = \frac{a}{1-r} \ \text{ if } |r| < 1; \quad \text{diverges if } |r| \ge 1$$

The only common series whose sum you can write down. $\sum_{n=1}^\infty r^n = \frac{r}{1-r}$: check where the index starts.

$p$-series

$$\sum_{n=1}^{\infty} \frac{1}{n^p} \ \text{ converges if } p > 1, \ \text{diverges if } p \le 1$$

$p = 1$ is the harmonic series, which diverges. $\sum\frac{1}{n^2}$ converges ($p = 2$); $\sum\frac{1}{\sqrt n}$ diverges ($p = \tfrac12$).

Alternating harmonic series

$$\sum_{n=1}^{\infty} \frac{(-1)^{n+1}}{n} = 1 - \frac12 + \frac13 - \cdots = \ln 2$$

Converges by the alternating series test, but $\sum\frac1n$ diverges, so the convergence is conditional, not absolute.

Factorials beat exponentials beat powers

$$\sum \frac{c^n}{n!} \text{ converges for every } c; \qquad \sum \frac{n^k}{c^n} \text{ converges for } c > 1$$

$n!$ eventually outgrows any $c^n$, and $c^n$ with $c > 1$ outgrows any power $n^k$. The ratio test proves both.

Absolute and conditional convergence

Absolutely convergent: $\sum |a_n|$ converges. Then $\sum a_n$ converges too. The ratio and root tests, applied to $|a_n|$, prove absolute convergence.

Conditionally convergent: $\sum a_n$ converges but $\sum |a_n|$ diverges. The alternating harmonic series is the standard example.

When a question asks "absolutely, conditionally, or divergent," run two tests: one on $\sum |a_n|$, and if that diverges, the alternating series test on $\sum a_n$.

A sequence and a series are different questions

A sequence is a list of numbers $a_1, a_2, a_3, \ldots$ and asks one question: do the terms approach a limit? A series adds the terms and asks a different question: do the running totals approach a limit? The running totals are the partial sums.

$$S_1 = a_1, \quad S_2 = a_1 + a_2, \quad S_3 = a_1 + a_2 + a_3, \quad \ldots, \quad S_N = \sum_{n=1}^{N} a_n$$

The series $\sum a_n$ converges if $\lim_{N\to\infty} S_N$ exists, and that limit is the sum. Otherwise the series diverges. Nothing in this definition requires you to find the sum. Most tests only decide whether a sum exists.

Start with the example you can compute. For $\sum_{n=1}^\infty \frac{1}{2^n}$ the partial sums are $\frac12, \frac34, \frac78, \frac{15}{16}, \ldots$, which approach $1$. For $\sum_{n=1}^\infty (-1)^n$ they are $-1, 0, -1, 0, \ldots$, which never settle. For $\sum_{n=1}^\infty \frac1n$ they are $1, 1.5, 1.83, 2.08, \ldots$ and keep growing, slowly, without bound. This last one is the case to look at closely, because its terms go to $0$ and the series still diverges.

What to look for
  1. Compare $\sum\frac1n$ with $\sum\frac{1}{n^2}$. Both term plots go to $0$. One sum keeps climbing past every line you draw; the other levels off near $1.645$. The difference is how fast the terms shrink.
  2. For $\sum(-1)^n$ the terms never go to $0$, and the partial sums alternate between two values. This is what the $n$th-term test catches.
  3. For $\sum\frac{n}{n+1}$ the terms approach $1$, not $0$, so every partial sum adds almost $1$. Divergence here is immediate.
  4. For $\sum\frac{(-1)^{n+1}}{n}$ the sums bounce above and below $\ln 2 \approx 0.693$ with shrinking swings. This is the picture behind the alternating series test.

The $n$th-term test: the check you run first

$n$th-term test for divergence

$$\text{If } \lim_{n\to\infty} a_n \ne 0 \text{ (or the limit does not exist), then } \sum a_n \text{ diverges.}$$

The logic: if the partial sums approach a limit $S$, then $a_n = S_n - S_{n-1}$ approaches $S - S = 0$. So convergent series must have terms going to $0$. The test is the contrapositive.

What the test cannot do is prove convergence. $\lim a_n = 0$ is consistent with both outcomes. When the limit is $0$, move on to another test.

Worked examples

Worked example

$\displaystyle\sum_{n=1}^\infty \frac{n}{2n+1}$. $\lim \frac{n}{2n+1} = \frac12 \ne 0$. Diverges by the $n$th-term test.

$\displaystyle\sum_{n=1}^\infty (-1)^n\frac{n}{n+1}$. The terms approach $\pm 1$ and have no limit. Diverges by the $n$th-term test. The alternating series test does not apply, because its condition $b_n \to 0$ fails.

$\displaystyle\sum_{n=1}^\infty \frac{1}{n}$. $\lim\frac1n = 0$, so the test is silent. (The series diverges, but that needs the integral test or a comparison, not this one.)

Two families you can decide on sight

Geometric series

Concept

Each term is the previous term times a fixed ratio $r$. The partial sums have a closed form, $S_N = a\,\frac{1 - r^{N+1}}{1 - r}$, and $r^{N+1} \to 0$ exactly when $|r| < 1$.

$$\sum_{n=0}^{\infty} a\,r^n = \frac{a}{1-r} \quad (|r| < 1)$$
Worked example

$\displaystyle\sum_{n=1}^\infty \frac{2^n}{3^{n+1}}$. Rewrite: $\frac{2^n}{3^{n+1}} = \frac13\left(\frac23\right)^n$. Ratio $\frac23$, first term (at $n = 1$) $\frac13\cdot\frac23 = \frac29$. Converges, and the sum is $\frac{2/9}{1 - 2/3} = \frac23$.

$\displaystyle\sum_{n=0}^\infty \left(-\frac{3}{2}\right)^n$. $|r| = \frac32 \ge 1$. Diverges; the terms do not go to $0$.

$p$-series

Concept

$\sum \frac{1}{n^p}$ converges exactly when $p > 1$. This comes from the integral test: $\int_1^\infty x^{-p}\,dx$ is finite exactly when $p > 1$.

$$\sum_{n=1}^{\infty}\frac{1}{n^p}: \quad p > 1 \text{ converges}, \quad p \le 1 \text{ diverges}$$
Worked example

$\displaystyle\sum \frac{1}{n\sqrt n} = \sum \frac{1}{n^{3/2}}$: $p = \frac32 > 1$, converges.

$\displaystyle\sum \frac{1}{\sqrt n}$: $p = \frac12 \le 1$, diverges.

$\displaystyle\sum \frac{1}{n^{1.01}}$: $p = 1.01 > 1$, converges. The boundary at $p = 1$ is exact, and slowly convergent series are still convergent.

Why these two matter beyond themselves

Every comparison test needs a series whose behavior you already know. Geometric series and $p$-series are that known series almost every time. When you look at a complicated term, the question to ask is "for large $n$, does this behave like $r^n$ or like $\frac{1}{n^p}$?"

A test is a tool with conditions

Each convergence test is an if-then statement. It has hypotheses that must be checked and a conclusion that follows only when they hold. Choosing a test means matching the shape of the general term to a test whose hypotheses you can verify. The decision tree below turns that matching into a sequence of yes-or-no questions. Use it until the choices feel automatic, and then keep using the same order in your head.

Three outcomes to write down. A test can say converges, diverges, or inconclusive. Inconclusive is not a failure. It means this tool does not fit, and you move to a different branch. The ratio test on $\sum\frac1{n^2}$ gives $L = 1$; the $p$-series branch then settles it in one line.

Common mistakes and what to check
  1. Skipping the $n$th-term check. It takes one line and ends many problems. Running a comparison test on $\sum\frac{n}{3n+1}$ wastes time on a series whose terms never shrink.
  2. Treating "$\lim a_n = 0$" as a conclusion. It is a prerequisite, not a verdict. Write "the $n$th-term test is inconclusive" and move on.
  3. Using the ratio test on rational terms. Polynomial ratios always give $L = 1$. Go to limit comparison instead.
  4. Forgetting the hypotheses. Comparison and integral tests need positive terms. The alternating series test needs $b_n$ decreasing. State the hypotheses you checked; that is part of a complete answer.
  5. Stopping after the alternating series test. If the question asks for absolute or conditional convergence, there is a second test to run on $\sum |a_n|$.

The ratio test

For a series $\sum a_n$, let

$$L = \lim_{n\to\infty}\left|\frac{a_{n+1}}{a_n}\right|.$$
  • $L < 1$: the series converges (absolutely).
  • $L > 1$ or $L = \infty$: the series diverges.
  • $L = 1$: the test is inconclusive. Use a different test.

The ratio test decides whether a series converges. It does not find the sum. For $\sum\frac{5^n}{n!}$ the test says converges; knowing that the sum is $e^5 - 1$ comes from recognizing the $e^x$ series, not from the test.

Why it works. A geometric series $\sum r^n$ has $\frac{a_{n+1}}{a_n} = r$ for every $n$. The ratio test asks whether a series is eventually geometric-like. If the ratios approach $L < 1$, then from some point on each term is at most, say, $\frac{L+1}{2}$ times the one before, and the tail is squeezed under a convergent geometric series. If $L > 1$, the terms eventually grow, so they cannot go to $0$. At $L = 1$ the comparison with a geometric series gives no information, which is why $p$-series and rational terms, where the ratio always tends to $1$, cannot be decided this way.

Use it when the term contains

  • a factorial: $n!$, $(2n)!$, $(n+1)!$
  • a constant raised to the $n$th power: $2^n$, $e^n$, $\left(\frac32\right)^n$
  • products of those with powers of $n$: $\frac{n^2 3^n}{n!}$

Do not expect it to decide

  • $p$-series and rational or algebraic terms: $\frac{1}{n^2}$, $\frac{n+1}{n^3+2}$, $\frac{1}{\sqrt n}$. The limit is $1$.
  • terms with only logarithms: $\frac{1}{n\ln n}$. The limit is $1$.

Setting up the ratio

The ratio test is mostly algebra. The same four moves work in each problem, and the common mistakes all happen in moves 1 and 3.

1

Write $a_{n+1}$. Replace every $n$ in $a_n$ with $(n+1)$, in parentheses. $\frac{n\,2^n}{n!}$ becomes $\frac{(n+1)\,2^{n+1}}{(n+1)!}$.

2

Divide by $a_n$ by multiplying by its reciprocal. $\left|\dfrac{a_{n+1}}{a_n}\right| = \dfrac{(n+1)\,2^{n+1}}{(n+1)!}\cdot\dfrac{n!}{n\,2^n}$. Absolute values remove any $(-1)^n$.

3

Simplify each kind of factor. $\dfrac{2^{n+1}}{2^n} = 2$. $\dfrac{n!}{(n+1)!} = \dfrac{1}{n+1}$, because $(n+1)! = (n+1)\cdot n!$. $\dfrac{n+1}{n} \to 1$. The example becomes $\dfrac{2(n+1)}{n(n+1)} = \dfrac{2}{n}$.

4

Take the limit and compare with $1$. $\lim \dfrac{2}{n} = 0 < 1$. The series converges. Write the conclusion with the test named: "by the ratio test, $\sum\frac{n2^n}{n!}$ converges."

Worked example: $\displaystyle\sum_{n=1}^\infty \frac{4^n}{n}$

The root test, for terms raised to the $n$th power

$$L = \lim_{n\to\infty}\sqrt[n]{|a_n|}: \qquad L < 1 \text{ converges}, \quad L > 1 \text{ diverges}, \quad L = 1 \text{ inconclusive}$$

Same three outcomes as the ratio test, same reasoning (eventually geometric). It is the natural choice when the whole term is something to the $n$th power, because the root undoes the power in one step. Useful facts: $\sqrt[n]{n} \to 1$, $\sqrt[n]{c} \to 1$ for any constant $c > 0$, and $\sqrt[n]{n^k} \to 1$.

Worked example: $\displaystyle\sum_{n=1}^\infty \left(\frac{n}{2n+1}\right)^n$

Worked example $$\sqrt[n]{|a_n|} = \frac{n}{2n+1} \;\longrightarrow\; \frac12 < 1$$

Converges by the root test. The ratio test would also work here but involves $\left(\frac{n+1}{2n+3}\right)^{n+1}\Big/\left(\frac{n}{2n+1}\right)^n$, which is much more algebra for the same answer.

Common mistakes and what to check
  1. Replacing only some of the $n$'s. Every $n$ in $a_n$ becomes $(n+1)$, including the ones in exponents and inside factorials: $4^{n+1}$ becomes $4^{n+2}$, and $(n+2)$ becomes $(n+3)$.
  2. Simplifying factorials incorrectly. $\frac{(n+1)!}{n!} = n+1$ and $\frac{(2n+2)!}{(2n)!} = (2n+2)(2n+1)$. Expand one or two factors; never cancel $n!$ against $(2n)!$.
  3. Dropping the absolute value. With a $(-1)^n$ factor the ratio of $a_{n+1}$ to $a_n$ is negative. The test uses $|a_{n+1}/a_n|$, which is positive.
  4. Concluding anything at $L = 1$. Write "inconclusive" and move to another branch of the tree. $\sum\frac1n$ and $\sum\frac1{n^2}$ both have $L = 1$.
  5. Reading the first few ratios instead of the limit. $\sum\frac{5^n}{n!}$ has ratios $5, 2.5, 1.67, 1.25, 1, 0.83, \ldots$ The first five are at least $1$, and the series still converges.
1

Direct comparison: squeeze against something you know

Suppose $0 \le a_n \le b_n$ for all $n$ (or all large $n$).

  • If $\sum b_n$ converges, then $\sum a_n$ converges. (Below a convergent series.)
  • If $\sum a_n$ diverges, then $\sum b_n$ diverges. (Above a divergent series.)

The inequality has to point the useful way. Being below a divergent series or above a convergent series tells you nothing. Before writing a comparison, decide which outcome you expect, then check that your inequality can deliver it.

Standard moves. Replace a bounded factor by its bound ($\sin^2 n \le 1$). Drop a positive term from a denominator to make the fraction bigger, or add one to make it smaller. Replace $\ln n$ by $1$ for $n \ge 3$, since $\ln n > 1$ there.

Worked examples

Worked example

$\displaystyle\sum\frac{\sin^2 n}{n^2}$. $0 \le \frac{\sin^2 n}{n^2} \le \frac{1}{n^2}$, and $\sum\frac{1}{n^2}$ converges ($p = 2$). Converges by direct comparison.

$\displaystyle\sum\frac{1}{2^n + n}$. $2^n + n > 2^n$, so $\frac{1}{2^n+n} < \frac{1}{2^n}$, and $\sum\frac1{2^n}$ is geometric with $r = \frac12$. Converges.

$\displaystyle\sum_{n=2}^\infty\frac{\ln n}{n}$. For $n \ge 3$, $\ln n > 1$, so $\frac{\ln n}{n} > \frac1n$, and $\sum\frac1n$ diverges. Diverges by direct comparison. (The first term does not affect convergence.)

Limit comparison: the workhorse for algebraic terms

Suppose $a_n > 0$ and $b_n > 0$, and

$$\lim_{n\to\infty}\frac{a_n}{b_n} = c \quad \text{with } 0 < c < \infty.$$

Then $\sum a_n$ and $\sum b_n$ either both converge or both diverge.

This test removes the need to get an inequality pointing the right way. You only need $a_n$ and $b_n$ to be the same size for large $n$. Choose $b_n$ by keeping the highest power of $n$ on top and on bottom and throwing everything else away.

$\dfrac{n+1}{n^3+2}$ behaves like $\dfrac{n}{n^3} = \dfrac{1}{n^2}$. $\dfrac{1}{\sqrt{n^2+1}}$ behaves like $\dfrac{1}{n}$. $\dfrac{3^n}{5^n - n}$ behaves like $\left(\dfrac35\right)^n$.

Worked examples

Worked example

$\displaystyle\sum\frac{n+1}{n^3+2}$. Compare with $b_n = \frac{1}{n^2}$:

$$\lim\frac{(n+1)/(n^3+2)}{1/n^2} = \lim\frac{n^3 + n^2}{n^3 + 2} = 1$$

$0 < 1 < \infty$ and $\sum\frac1{n^2}$ converges, so the series converges.

$\displaystyle\sum\frac{1}{\sqrt{n^2+1}}$. Compare with $b_n = \frac1n$: $\lim\frac{n}{\sqrt{n^2+1}} = 1$. $\sum\frac1n$ diverges, so the series diverges.

$\displaystyle\sum\frac{n}{n^2+1}$. Looks like $\frac{1}{n}$; the limit of the ratio is $1$; diverges. Note the terms do go to $0$, so the $n$th-term test would not have caught this.

3

Integral test: when the term is a function you can integrate

Suppose $a_n = f(n)$ where $f$ is positive, continuous, and decreasing for $x \ge 1$ (or from some point on). Then

$$\sum_{n=1}^\infty a_n \text{ and } \int_1^\infty f(x)\,dx \text{ either both converge or both diverge.}$$

The series is a sum of rectangles of width $1$ and the integral is the area under the curve; decreasing $f$ keeps each within a term of the other. Check all three conditions in writing. Decreasing is the one that is sometimes false: $f(x) = \frac{\ln x}{x}$ increases until $x = e$, so the test applies from $n = 3$ on.

The value of the integral is not the sum of the series. $\int_1^\infty\frac{dx}{x^2} = 1$, while $\sum\frac{1}{n^2} = \frac{\pi^2}{6}$.

Worked examples

Worked example

$\displaystyle\sum_{n=2}^\infty\frac{1}{n\ln n}$. $f(x) = \frac{1}{x\ln x}$ is positive, continuous, and decreasing for $x \ge 2$. With $u = \ln x$:

$$\int_2^\infty\frac{dx}{x\ln x} = \lim_{b\to\infty}\Big[\ln(\ln x)\Big]_2^{b} = \infty$$

Diverges. (Compare: the ratio test gives $L = 1$ here, and limit comparison with $\frac1n$ gives $c = 0$, which is outside the allowed range. The integral test is the tool that fits.)

$\displaystyle\sum_{n=2}^\infty\frac{1}{n(\ln n)^2}$. Same substitution: $\int_2^\infty\frac{dx}{x(\ln x)^2} = \left[-\frac{1}{\ln x}\right]_2^\infty = \frac{1}{\ln 2}$, finite. Converges. One extra power of $\ln n$ in the denominator is the difference.

4

Alternating series test, and absolute versus conditional

For $\sum (-1)^n b_n$ or $\sum (-1)^{n+1} b_n$ with $b_n > 0$: the series converges if

  1. $b_{n+1} \le b_n$ for all large $n$ (the terms decrease), and
  2. $\lim b_n = 0$.

The partial sums bounce across the limit with shrinking swings (Tab 1 shows the picture). Both conditions must be stated. If condition 2 fails, the series diverges by the $n$th-term test. If condition 1 fails, the test does not apply, which is rare on exams but possible.

Absolute versus conditional. After the alternating series test says converges, ask what $\sum b_n$ does, using another branch of the tree:

  • $\sum b_n$ converges: the original series converges absolutely.
  • $\sum b_n$ diverges: the original series converges conditionally.

Worked examples

Worked example

$\displaystyle\sum\frac{(-1)^n}{\sqrt n}$. $b_n = \frac{1}{\sqrt n}$ decreases and $\to 0$: converges by the alternating series test. $\sum\frac{1}{\sqrt n}$ is a $p$-series with $p = \frac12$: diverges. So the series converges conditionally.

$\displaystyle\sum\frac{(-1)^n}{n^2}$. $\sum\frac{1}{n^2}$ converges ($p = 2$), so the series converges absolutely. When the absolute series converges, you do not need the alternating series test at all.

$\displaystyle\sum\frac{\cos(n\pi)}{n}$. $\cos(n\pi) = (-1)^n$, so this is $\sum\frac{(-1)^n}{n}$, the alternating harmonic series: converges conditionally.

The alternating series error bound

When the alternating series test applies, the partial sum $S_N$ is within one term of the true sum:

$$\left|S - S_N\right| \le b_{N+1}$$

This is the same bound used for Taylor polynomial approximations in the Maclaurin and Taylor Series sheet. Example: for the alternating harmonic series, $S_{10} \approx 0.6456$, and the bound says $|\ln 2 - S_{10}| \le \frac{1}{11} \approx 0.0909$. The actual error is about $0.0475$.

To guarantee an error below $0.01$, choose $N$ with $b_{N+1} = \frac{1}{N+1} \le 0.01$, so $N \ge 99$. Slow, which is one reason conditionally convergent series are awkward to work with numerically.

Common mistakes and what to check
  1. Comparing in the useless direction. "$\frac{1}{n^2+n} \le \frac1n$ and $\sum\frac1n$ diverges" proves nothing. Compare with $\frac{1}{n^2}$ instead, or use limit comparison, which has no inequality direction to check.
  2. Applying comparison tests to series with mixed signs. Both comparison tests and the integral test need nonnegative terms. For $\sum\frac{(-1)^n}{n}$, compare $\sum\frac1n$ to learn about absolute convergence, then use the alternating series test.
  3. Getting $c = 0$ or $c = \infty$ in limit comparison and drawing a conclusion. The test applies only for $0 < c < \infty$. If $c = 0$ and $\sum b_n$ converges, $\sum a_n$ does converge, but by direct comparison, and you should say so; otherwise choose a better $b_n$.
  4. Forgetting to check that $f$ is decreasing before the integral test. State all three conditions, and note the starting index if the function only decreases eventually.
  5. Reporting the value of the integral as the sum. The integral decides convergence; it does not compute the series.

Work.

$$\left|\frac{a_{n+1}}{a_n}\right| = \frac{5^{n+1}}{\ln(n+1)}\cdot\frac{\ln n}{5^n} = 5\cdot\frac{\ln n}{\ln(n+1)} \longrightarrow 5$$

The logarithm ratio tends to $1$: by L'Hôpital's rule on $\frac{\ln x}{\ln(x+1)}$, the limit is $\lim\frac{1/x}{1/(x+1)} = \lim\frac{x+1}{x} = 1$.

$L = 5 > 1$: diverges.

Check. $5^n$ grows much faster than $\ln n$, so the terms go to infinity.

11

$\displaystyle\sum_{n=0}^{\infty}\frac{(-1)^n n^3}{3^n}$ Column A

Method: ratio test

Setup. Inside the absolute value the $(-1)^n$ disappears: $|a_n| = \dfrac{n^3}{3^n}$.

Work.

$$\left|\frac{a_{n+1}}{a_n}\right| = \frac{(n+1)^3}{3^{n+1}}\cdot\frac{3^n}{n^3} = \frac13\left(\frac{n+1}{n}\right)^3 \longrightarrow \frac13$$
$L = \frac13 < 1$: converges (absolutely).

Check. The ratio test proves absolute convergence, so no alternating series test is needed. The cube contributes $\left(1 + \frac1n\right)^3 \to 1$; the $3^n$ sets the limit.

12

$\displaystyle\sum_{n=0}^{\infty}\frac{(-1)^n n\,3^n}{n!}$ Column B

Method: ratio test

Setup. $|a_n| = \dfrac{n\,3^n}{n!}$.

Work.

$$\left|\frac{a_{n+1}}{a_n}\right| = \frac{(n+1)\,3^{n+1}}{(n+1)!}\cdot\frac{n!}{n\,3^n} = \frac{3(n+1)}{(n+1)\,n} = \frac{3}{n} \longrightarrow 0$$
$L = 0 < 1$: converges (absolutely).

Check. Compare with problem 3, which has $2^n$ in place of $3^n$ and no sign factor. The structure is identical and the factorial wins in both.

13

$\displaystyle\sum_{n=0}^{\infty}\frac{(-1)^n n!}{e^n}$ Column A

Method: ratio test

Setup. $|a_n| = \dfrac{n!}{e^n}$.

Work.

$$\left|\frac{a_{n+1}}{a_n}\right| = \frac{(n+1)!}{e^{n+1}}\cdot\frac{e^n}{n!} = \frac{n+1}{e} \longrightarrow \infty$$
$L = \infty$: diverges.

Check. The sign factor cannot rescue a series whose terms grow: $|a_n| \to \infty$, so the $n$th-term test also says diverges. The alternating series test does not apply because $b_n \to 0$ fails.

14

$\displaystyle\sum_{n=1}^{\infty}\frac{(-1)^n\left(\frac32\right)^n}{n^2}$ Column B

Method: ratio test

Setup. The index starts at $n = 1$ because of the $n^2$ in the denominator. $|a_n| = \dfrac{(3/2)^n}{n^2}$.

Work.

$$\left|\frac{a_{n+1}}{a_n}\right| = \frac{(3/2)^{n+1}}{(n+1)^2}\cdot\frac{n^2}{(3/2)^n} = \frac32\left(\frac{n}{n+1}\right)^2 \longrightarrow \frac32$$
$L = \frac32 > 1$: diverges.

Check. $\left(\frac32\right)^n$ outgrows $n^2$, so $|a_n| \to \infty$ and the terms do not go to $0$.

15

$\displaystyle\sum_{n=0}^{\infty}\frac{8^n}{(n+2)\,4^{n+1}}$ Column A

Method: ratio test

Setup. Replace every $n$: $a_{n+1} = \dfrac{8^{n+1}}{(n+3)\,4^{n+2}}$.

Work.

$$\left|\frac{a_{n+1}}{a_n}\right| = \frac{8^{n+1}}{(n+3)\,4^{n+2}}\cdot\frac{(n+2)\,4^{n+1}}{8^n} = \frac84\cdot\frac{n+2}{n+3} \longrightarrow 2$$
$L = 2 > 1$: diverges.

Check. Simplify the term first: $\frac{8^n}{4^{n+1}} = \frac14\cdot 2^n$, so $a_n = \frac{2^n}{4(n+2)} \to \infty$.

16

$\displaystyle\sum_{n=0}^{\infty}\frac{n^2\,3^{n+1}}{4^n}$ Column B

Method: ratio test

Setup. $a_{n+1} = \dfrac{(n+1)^2\,3^{n+2}}{4^{n+1}}$.

Work.

$$\left|\frac{a_{n+1}}{a_n}\right| = \frac{(n+1)^2\,3^{n+2}}{4^{n+1}}\cdot\frac{4^n}{n^2\,3^{n+1}} = \frac34\left(\frac{n+1}{n}\right)^2 \longrightarrow \frac34$$
$L = \frac34 < 1$: converges.

Check. Rewrite the term as $3n^2\left(\frac34\right)^n$: a power of $n$ times a geometric factor with $|r| < 1$ always converges. The extra $3^{1}$ in the numerator only scales the series.

17

$\displaystyle\sum_{n=0}^{\infty}\frac{n!}{4^n}$ Column A

Method: ratio test

Setup. $a_{n+1} = \dfrac{(n+1)!}{4^{n+1}}$.

Work.

$$\left|\frac{a_{n+1}}{a_n}\right| = \frac{(n+1)!}{4^{n+1}}\cdot\frac{4^n}{n!} = \frac{n+1}{4} \longrightarrow \infty$$
$L = \infty$: diverges.

Check. The ratios $\frac14, \frac24, \frac34, 1, \frac54, \ldots$ pass $1$ at $n = 3$ and keep growing, so from $n = 4$ on each term is larger than the one before.

18

$\displaystyle\sum_{n=1}^{\infty} n\left(-\frac23\right)^n$ Column B

Method: ratio test

Setup. $|a_n| = n\left(\frac23\right)^n$.

Work.

$$\left|\frac{a_{n+1}}{a_n}\right| = \frac{(n+1)\left(\frac23\right)^{n+1}}{n\left(\frac23\right)^n} = \frac23\cdot\frac{n+1}{n} \longrightarrow \frac23$$
$L = \frac23 < 1$: converges (absolutely).

Check. Differentiating the geometric series gives $\sum_{n\ge1} n x^n = \frac{x}{(1-x)^2}$ for $|x| < 1$; at $x = -\frac23$ the sum is $\frac{-2/3}{(5/3)^2} = -\frac{6}{25}$, a finite value.

B

Choose the Test

For each series, first decide which branch of the decision tree applies and write it down. Then carry out the test, stating its hypotheses, and give a conclusion. Where the series alternates, say whether the convergence is absolute or conditional. Each solution is organized as Method, Setup, Work, Answer, and Check.

1

$\displaystyle\sum_{n=1}^{\infty}\frac{n}{3n+1}$

Method: nth-term test

Setup. Tree node 1: do the terms go to $0$?

Work. $\lim\frac{n}{3n+1} = \frac13 \ne 0$.

Diverges by the $n$th-term test.

Check. Each term is close to $\frac13$, so $S_N \approx \frac N3$ grows without bound.

2

$\displaystyle\sum_{n=1}^{\infty}\frac{5}{4^n}$. Decide convergence, and find the sum if it converges.

Method: geometric series

Setup. $\frac{5}{4^n} = 5\left(\frac14\right)^n$: ratio $r = \frac14$, first term $\frac54$.

Work. $|r| < 1$, so the series converges, and the sum is $\dfrac{5/4}{1 - 1/4} = \dfrac{5/4}{3/4} = \dfrac53$.

Converges, with sum $\frac53$.

Check. $S_3 = \frac54 + \frac{5}{16} + \frac{5}{64} = \frac{105}{64} \approx 1.64$, already close to $\frac53 \approx 1.667$.

3

$\displaystyle\sum_{n=1}^{\infty}\frac{1}{n^{0.9}}$

Method: p-series

Setup. A $p$-series with $p = 0.9$.

Work. $p \le 1$.

Diverges ($p$-series, $p = 0.9 \le 1$).

Check. $\frac{1}{n^{0.9}} > \frac1n$ for $n \ge 2$, and $\sum\frac1n$ diverges, so direct comparison agrees.

4

$\displaystyle\sum_{n=1}^{\infty}\frac{n+1}{n^3+2}$

Method: limit comparison

Setup. Algebraic, positive terms. Dominant terms: $\frac{n}{n^3} = \frac{1}{n^2}$, so $b_n = \frac{1}{n^2}$.

Work.

$$\lim\frac{a_n}{b_n} = \lim\frac{(n+1)\,n^2}{n^3+2} = \lim\frac{n^3+n^2}{n^3+2} = 1$$
$0 < 1 < \infty$ and $\sum\frac{1}{n^2}$ converges: converges.

Check. Direct comparison also works: $\frac{n+1}{n^3+2} \le \frac{2n}{n^3} = \frac{2}{n^2}$ for $n \ge 1$.

5

$\displaystyle\sum_{n=1}^{\infty}\frac{1}{\sqrt{n^2+1}}$

Method: limit comparison

Setup. $\sqrt{n^2+1}$ behaves like $n$, so $b_n = \frac1n$.

Work. $\lim\dfrac{1/\sqrt{n^2+1}}{1/n} = \lim\dfrac{n}{\sqrt{n^2+1}} = \lim\dfrac{1}{\sqrt{1 + 1/n^2}} = 1$.

$\sum\frac1n$ diverges: diverges.

Check. The terms go to $0$, so the $n$th-term test could not have decided this. For a direct comparison, $\sqrt{n^2+1} \le \sqrt{2n^2} = n\sqrt2$, so $a_n \ge \frac{1}{n\sqrt2}$, above a divergent series.

6

$\displaystyle\sum_{n=2}^{\infty}\frac{1}{n\ln n}$

Method: integral test

Setup. $f(x) = \frac{1}{x\ln x}$ is positive, continuous, and decreasing for $x \ge 2$.

Work. With $u = \ln x$, $du = \frac{dx}{x}$:

$$\int_2^\infty\frac{dx}{x\ln x} = \lim_{b\to\infty}\Big[\ln(\ln x)\Big]_2^b = \infty$$
The integral diverges: diverges.

Check. This series diverges more slowly than the harmonic series. The partial sums pass $4$ only around $N \approx 5 \times 10^{10}$, so numerical evidence is misleading here; the test is what settles it.

7

$\displaystyle\sum_{n=1}^{\infty}\frac{(-1)^n}{\sqrt n}$. Absolutely convergent, conditionally convergent, or divergent?

Method: alternating series test, then p-series

Setup. $b_n = \frac{1}{\sqrt n}$.

Work. $b_n$ is decreasing and $\lim b_n = 0$, so the series converges by the alternating series test. For absolute convergence, $\sum\frac{1}{\sqrt n}$ is a $p$-series with $p = \frac12 \le 1$, which diverges.

Converges conditionally.

Check. Both tests were needed. The alternating series test alone cannot distinguish absolute from conditional.

8

$\displaystyle\sum_{n=1}^{\infty}\frac{(-1)^n}{n^2}$. Absolutely convergent, conditionally convergent, or divergent?

Method: absolute convergence via p-series

Setup. Test $\sum|a_n| = \sum\frac{1}{n^2}$ first.

Work. $p = 2 > 1$, converges.

Converges absolutely.

Check. Absolute convergence implies convergence, so the alternating series test is not needed. Starting with $\sum|a_n|$ is the efficient order when you expect absolute convergence.

9

$\displaystyle\sum_{n=1}^{\infty}\frac{\sin^2 n}{n^2}$

Method: direct comparison

Setup. $0 \le \sin^2 n \le 1$, so $0 \le \frac{\sin^2 n}{n^2} \le \frac{1}{n^2}$.

Work. $\sum\frac{1}{n^2}$ converges ($p = 2$), and the given series sits below it.

Converges by direct comparison.

Check. Limit comparison would fail here: $\frac{a_n}{1/n^2} = \sin^2 n$ has no limit. The bounded-factor move is what makes direct comparison the right tool.

10

$\displaystyle\sum_{n=1}^{\infty}\frac{1}{2^n+n}$

Method: direct comparison

Setup. Dropping the $n$ makes the denominator smaller and the fraction larger: $\frac{1}{2^n+n} < \frac{1}{2^n}$.

Work. $\sum\frac{1}{2^n}$ is geometric with $r = \frac12$, convergent.

Converges by direct comparison.

Check. Limit comparison with $\frac{1}{2^n}$ also works: $\lim\frac{2^n}{2^n+n} = 1$.

11

$\displaystyle\sum_{n=1}^{\infty}\left(\frac{n}{2n+1}\right)^n$

Method: root test

Setup. The whole term is raised to the $n$th power.

Work. $\sqrt[n]{a_n} = \frac{n}{2n+1} \to \frac12$.

$L = \frac12 < 1$: converges.

Check. $\frac{n}{2n+1} < \frac12$ for every $n$, so $a_n < \left(\frac12\right)^n$ and direct comparison with a geometric series confirms it.

12

$\displaystyle\sum_{n=1}^{\infty}\frac{n^n}{n!}$

Method: ratio test

Setup. Factorial and $n$ in an exponent.

Work.

$$\frac{a_{n+1}}{a_n} = \frac{(n+1)^{n+1}}{(n+1)!}\cdot\frac{n!}{n^n} = \frac{(n+1)^{n+1}}{(n+1)\,n^n} = \left(\frac{n+1}{n}\right)^n = \left(1 + \frac1n\right)^n \longrightarrow e$$
$L = e > 1$: diverges.

Check. $n^n \ge n!$ for every $n$ (each of the $n$ factors in $n!$ is at most $n$), so $a_n \ge 1$ and the terms cannot go to $0$.

13

$\displaystyle\sum_{n=1}^{\infty}\frac{(n!)^2}{(2n)!}$

Method: ratio test

Setup. $a_{n+1} = \dfrac{((n+1)!)^2}{(2n+2)!}$. Expand only what is needed: $(n+1)! = (n+1)\,n!$ and $(2n+2)! = (2n+2)(2n+1)\,(2n)!$.

Work.

$$\frac{a_{n+1}}{a_n} = \frac{(n+1)^2\,(n!)^2}{(2n+2)(2n+1)\,(2n)!}\cdot\frac{(2n)!}{(n!)^2} = \frac{(n+1)^2}{(2n+2)(2n+1)} = \frac{n+1}{2(2n+1)} \longrightarrow \frac14$$
$L = \frac14 < 1$: converges.

Check. $a_1 = \frac12$, $a_2 = \frac{4}{24} = \frac16$, $a_3 = \frac{36}{720} = \frac1{20}$; successive ratios $\frac13, \frac{3}{10}$ are heading toward $\frac14$ from above.

14

$\displaystyle\sum_{n=1}^{\infty}(-1)^n\frac{n}{n+1}$

Method: nth-term test

Setup. The series alternates, which invites the alternating series test, but tree node 1 comes first.

Work. $\frac{n}{n+1} \to 1$, so the terms approach $\pm 1$ and have no limit.

Diverges by the $n$th-term test.

Check. The alternating series test requires $b_n \to 0$, which fails. A common mistake is to see $(-1)^n$ and conclude convergence without checking that condition.

15

$\displaystyle\sum_{n=1}^{\infty}\frac{3^n}{n^3}$

Method: ratio test

Setup. $n$ in an exponent.

Work. $\dfrac{a_{n+1}}{a_n} = \dfrac{3^{n+1}}{(n+1)^3}\cdot\dfrac{n^3}{3^n} = 3\left(\dfrac{n}{n+1}\right)^3 \to 3$.

$L = 3 > 1$: diverges.

Check. Compare with Ratio Test Practice problem 11, which had $\frac{n^3}{3^n}$ and converged. Flipping the fraction flips the verdict.

16

$\displaystyle\sum_{n=1}^{\infty}\frac{1}{n(n+1)}$. Decide convergence, and find the sum if it converges.

Method: limit comparison, then telescoping for the sum

Setup. Algebraic terms behaving like $\frac{1}{n^2}$.

Work. $\lim\dfrac{1/(n(n+1))}{1/n^2} = \lim\dfrac{n^2}{n^2+n} = 1$, and $\sum\frac{1}{n^2}$ converges, so the series converges. For the sum, partial fractions give $\frac{1}{n(n+1)} = \frac1n - \frac{1}{n+1}$, so

$$S_N = \left(1 - \tfrac12\right) + \left(\tfrac12 - \tfrac13\right) + \cdots + \left(\tfrac1N - \tfrac{1}{N+1}\right) = 1 - \frac{1}{N+1} \longrightarrow 1$$
Converges, with sum $1$.

Check. $S_4 = \frac12 + \frac16 + \frac1{12} + \frac1{20} = \frac45$, which matches $1 - \frac15$.
