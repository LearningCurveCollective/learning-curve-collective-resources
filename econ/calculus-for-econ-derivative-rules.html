Every rule on one page

Most derivatives in a first calculus course for economics come from this short list. The first five rules handle single functions. The last three handle functions that have been combined. Learn the list, then practice choosing the rule that fits.

Notation. $y'$ and $\dfrac{dy}{dx}$ mean the same thing: the derivative of $y$. This sheet mostly writes $y'$.

Rules for single functions
Rule 1Constant: a number on its own has derivative zero. $(c)' = 0$
ExampleIn $TC = \dots + 400$, the $400$ gives $0$.
Fixed cost does not change with output, so it adds nothing to marginal cost.
Rule 2Power rule: bring the power down, then lower the power by one. $(x^n)' = nx^{n-1}$
Example$(Q^3)' = 3Q^2$ and $(Q^{0.5})' = 0.5Q^{-0.5}$.
Rule 3Sums and multiples: keep the number in front. Plus and minus signs carry straight through, so differentiate one term at a time.
Example$(2Q^3 - 15Q^2 + 90Q + 400)' = 6Q^2 - 30Q + 90$.
Rule 4Exponential: $e^x$ stays $e^x$, and a number multiplying $x$ in the power comes down in front. $(e^{x})' = e^{x}$, $(e^{ax})' = ae^{ax}$.
Example$(6e^{0.5x})' = 6(0.5e^{0.5x}) = 3e^{0.5x}$.
Rule 5Natural log: $(\ln x)' = \dfrac{1}{x}$.
Example$(25 + 4\ln Q)' = \dfrac{4}{Q}$.
Rules for combined functions
Rule 6Chain rule: for a function inside a function. Differentiate the outside and leave the inside unchanged, then multiply by the derivative of the inside.
Steps1. Let $u$ be the inside, and find $u'$. 2. Rewrite $y$ with $u$. 3. Differentiate, then multiply by $u'$. 4. Plug in what $u$ was.
Example$y = (3x + 10)^2$: $u = 3x + 10$, so $u' = 3$. Then $y = u^2$, so $y' = 2u \cdot 3 = 6(3x + 10)$.
Three shortcuts that come from it: $\big([f]^n\big)' = n[f]^{n-1}f'$, $\big(e^{f}\big)' = f'e^{f}$, $(\ln f)' = \dfrac{f'}{f}$.
Rule 7Product rule: for a function times a function. If $y = f(x)\cdot h(x)$, then $y' = f'(x)\,h(x) + f(x)\,h'(x)$.
Steps1. Copy the product twice, with a plus sign between. 2. Differentiate the first piece in the first copy and the second piece in the second copy.
Example$y = x^3\ln x$: write $(x^3)(\ln x) + (x^3)(\ln x)$, which becomes $y' = (3x^2)(\ln x) + (x^3)\left(\dfrac{1}{x}\right)$.
Rule 8Quotient rule: for a function divided by a function. If $y = \dfrac{f(x)}{h(x)}$, then $y' = \dfrac{f'(x)\,h(x) - f(x)\,h'(x)}{[h(x)]^2}$.
Steps1. Copy the product rule for top times bottom. 2. Change the plus to a minus. 3. Divide by the bottom squared.
Example$P = \dfrac{5Q}{2Q + 3}$: $P' = \dfrac{(5)(2Q + 3) - (5Q)(2)}{(2Q + 3)^2} = \dfrac{15}{(2Q + 3)^2}$.
Because of the minus sign, the order matters. The derivative of the top comes first.
Rewrite first

These changes often turn a hard-looking function into one the first five rules can handle. Before you use the quotient rule, ask whether the function can be rewritten as a power. It usually saves time and leaves less room for small slips.

RewriteRoots become powers: $\sqrt{Q} = Q^{0.5}$ and $\sqrt[3]{x} = x^{1/3}$.
RewriteA single power on the bottom becomes a negative power: $\dfrac{6}{Q^3} = 6Q^{-3}$ and $\dfrac{1}{x} = x^{-1}$.
RewriteLog laws: $\ln(ab) = \ln a + \ln b$, $\ln\!\left(\dfrac{a}{b}\right) = \ln a - \ln b$, $\ln(a^n) = n\ln a$.
Example$\ln(5x) = \ln 5 + \ln x$, so its derivative is $\dfrac{1}{x}$.
There is no law for the log of a sum: $\ln(Q + 4)$ does not split. Use the chain rule for that one.
RewriteSplit a fraction whose bottom is one term: $\dfrac{Q^2 + 64}{Q} = Q + 64Q^{-1}$.

Which rule? A four-question plan

1

Rewrite?

Can a root, a fraction with a one-term bottom, or a log be simplified first? Do that before anything else.

2

Multiplied?

Are two functions of the variable multiplied, like $x^3\ln x$? Use the product rule.

3

Divided?

Is the variable on the top and the bottom, like $\frac{5Q}{2Q+3}$? Use the quotient rule.

4

Inside?

Is there a bracket to a power, $e$ to something other than $x$, or $\ln$ of something other than $x$? Use the chain rule.

How the function is built names the rule. Functions multiplied together: product rule. A function divided by a function: quotient rule. A function inside a function: chain rule. If none of these apply, use Rules 1 to 5 term by term.

If you get stuck, try another rule. Suppose you try the chain rule on $6\sqrt{Q}\,(Q + 2)$ with $u = Q + 2$. The $6\sqrt{Q}$ cannot be rewritten with $u$, so Step 2 does not work. That is a sign the function is a product, not a chain.

Two rules can work together. In $80Ye^{-0.25Y}$ the pieces are multiplied, so start with the product rule. The chain rule then comes up on its own when you differentiate $e^{-0.25Y}$.

What a derivative tells you

A derivative measures how fast one quantity changes when another changes. On a graph, it is the slope of the curve at a single point. In economics, the derivative of a total is the matching marginal: the derivative of total cost is marginal cost.

You will see the same idea written several ways. These all mean "the derivative of $y$ with respect to $x$":

$$y' \qquad \frac{dy}{dx} \qquad f'(x) \qquad \frac{d(TC)}{dQ}$$

The letter on the bottom of the fraction is the variable. $\frac{d(TC)}{dQ}$ means you treat $Q$ as the variable. Economics uses letters such as $Q$, $Y$, $L$, $P$ and $t$, and the rules work the same way for each one.

The power rule and its three pieces

These three rules work together, and many courses call the set "the power rule". If you have differentiated a polynomial before, you have already used all three.

Rule 1Constant: $(c)' = 0$.
WhyA constant does not change, so its rate of change is zero.
AlsoYou can see it from the power rule. $7$ is $7x^0$. Bring the $0$ down in front and the whole term becomes $0$.
Rule 2Power rule: $(x^n)' = nx^{n-1}$. The power comes down in front, then the power drops by one.
Example$(x^5)' = 5x^4$ and $(Q)' = 1Q^0 = 1$.
This works for whole-number powers, fractions and negatives.
Rule 3Sums and multiples: a number in front stays where it is, and plus and minus signs carry straight through.
Example$(6x^3 - 4x + 9)' = 18x^2 - 4 + 0$.
Differentiate a sum one term at a time.

Common mistakes and what to check

These are common mistakes with the first three rules. Review them so you know what to check when an answer seems off.

Common mistake 1

Keeping the constant. The derivative of $400$ is $0$, not $400$. Check: does any number sit on its own in your answer that was on its own in the question?

Common mistake 2

Negative powers. Lowering $-1$ by one gives $-2$, not $0$. Check: $(Q^{-1})' = -Q^{-2}$.

Common mistake 3

Two new standard functions

Two more functions join the power rule. Both come up often in economic models: $e$ for growth and decay, $\ln$ for costs and outputs that rise more and more slowly.

Exponential, base $e$

$$(e^{x})' = e^{x}$$

$e^x$ stays $e^x$ when you differentiate it.

Exponential, $e^{ax}$

$$(e^{ax})' = a\,e^{ax}$$

The number multiplying $x$ in the power comes down in front. The power itself stays the same.

Natural log

$$(\ln x)' = \frac{1}{x}$$

Only for $\ln$ of the variable on its own. For $\ln$ of a bracket, see the chain rule.

Still true

$$(a f \pm b g)' = a f' \pm b g'$$

Numbers in front stay, and sums split, just as in Tab 1.

Why the power rule does not apply to $e^x$. The power rule is for $x^n$: the variable in the base and a fixed number in the power. In $e^x$ the base is fixed and the variable is in the power. That is a different kind of function, so it has its own rule.

The $e^{ax}$ rule is not really a separate rule. It is the chain rule applied to $e^{ax}$. Tab 3 shows why, using $e^{4x}$.

Worked example: first, second and third derivatives

A second derivative, $y''$, is the derivative of the first derivative. A third is the derivative of the second. Nothing new is needed: apply the same rule again.

Step 1 of 5
Worked example

Find the first, second and third derivatives of $S = 50(3 - e^{t})$.

1

Multiply out first. $S = 150 - 50e^{t}$.

2

Differentiate term by term. The $150$ gives $0$, and $e^t$ stays $e^t$: $S' = -50e^{t}$.

3

Repeat. $-50e^t$ differentiates to itself, so $S'' = -50e^{t}$ and $S''' = -50e^{t}$.

Worked example

Find the first, second and third derivatives of $TC = 25 + 4\ln Q$.

1

First derivative. The $25$ gives $0$ and $\ln Q$ gives $\dfrac{1}{Q}$: $TC' = \dfrac{4}{Q} = 4Q^{-1}$.

2

Second derivative. Now it is a power of $Q$, so use the power rule: $TC'' = -4Q^{-2} = -\dfrac{4}{Q^2}$.

3

Third derivative. $TC''' = -4(-2Q^{-3}) = 8Q^{-3} = \dfrac{8}{Q^3}$.

After the first step, $\ln$ is gone and only the power rule is needed.

Common mistakes and what to check

These are common mistakes with $e$ and $\ln$. Review them so you know what to check when an answer seems off.

Common mistake 1

Using the power rule on $e^x$. $(e^{x})'$ is $e^x$, not $xe^{x-1}$. The variable is in the power, so the power rule does not apply.

Common mistake 2

Changing the power. $(e^{0.5x})' = 0.5e^{0.5x}$. The $0.5$ comes down in front, and the power stays $0.5x$.

Common mistake 3

Splitting the log of a sum. $\ln(Q + 4)$ is not $\ln Q + \ln 4$. Only a product splits like that.

Common mistake 4

Writing $\frac{1}{5x}$ for the derivative of $\ln(5x)$. Split it first: $\ln 5 + \ln x$. Since $\ln 5$ is a constant, the derivative is $\frac{1}{x}$.

Quick Check: Can You Apply It?

Differentiate each one on paper first, then open the answer.

(a) $y = 8e^{0.25x}$

$y' = 8(0.25e^{0.25x}) = 2e^{0.25x}$.

(b) $S = 5\ln Q - e^{-Q}$

The power is $-1\cdot Q$, so $(e^{-Q})' = -e^{-Q}$. Then $S' = \dfrac{5}{Q} + e^{-Q}$.

(c) $y = \ln(Q^6)$

Simplify to $6\ln Q$. Then $y' = \dfrac{6}{Q}$.

(d) Find the second derivative of $TC = 30 + 12\ln Q$.

$TC' = \dfrac{12}{Q} = 12Q^{-1}$, so $TC'' = -12Q^{-2} = -\dfrac{12}{Q^2}$.

A function inside a function

Many functions do one thing to $x$, then do something else to the result. That is a function inside a function, and the chain rule is the rule for it.

FunctionThe inside: call it $u$What happens to $u$
$(3x + 10)^2$$u = 3x + 10$it is squared
$e^{4x}$$u = 4x$$e$ is raised to it
$\ln(2x + 9)$$u = 2x + 9$$\ln$ is taken of it

The chain rule in words: differentiate the outside and leave the inside unchanged, then multiply by the derivative of the inside.

$$y' = \underbrace{\frac{dy}{du}}_{\text{differentiate with } u} \cdot \underbrace{\;u'\;}_{\text{derivative of the inside}}$$

Written with fractions, this is $\dfrac{dy}{dx} = \dfrac{dy}{du}\cdot\dfrac{du}{dx}$.

You only need to find the inside. You do not have to name the outside function. To find the inside, look for where the variable sits: inside a bracket, in a power, or inside a log.

Worked example: e to a power

Differentiate $y = e^{4x}$.

1

Let $u$ be the inside. $u = 4x$, so $u' = 4$.

2

Rewrite with $u$. $y = e^{u}$.

3

Differentiate, then multiply by $u'$. $y' = e^{u}\cdot u' = e^{u}\cdot 4$.

4

Plug in what $u$ was. $y' = 4e^{4x}$.

$$\boxed{y' = 4e^{4x}}$$

Compare this with the $e^{ax}$ rule from Tab 2: $(e^{ax})' = ae^{ax}$. Same answer. That rule is the chain rule with the four steps done in your head.

Worked example: log of a bracket

Differentiate $y = \ln(2x + 9)$.

1

Let $u$ be the inside. $u = 2x + 9$, so $u' = 2$.

2

Rewrite with $u$. $y = \ln u$.

3

Differentiate, then multiply by $u'$. $y' = \dfrac{1}{u}\cdot u' = \dfrac{1}{u}\cdot 2$.

4

Plug in what $u$ was. $y' = \dfrac{2}{2x + 9}$.

$$\boxed{y' = \frac{2}{2x + 9}}$$

Step 2 matters here. The derivative of $\ln u$ is $\frac{1}{u}$, not $\frac{1}{x}$.

Worked example: a root, with an economics variable

Differentiate $C = \sqrt{Y^3 + 4Y}$.

0

Rewrite the root as a power. $C = (Y^3 + 4Y)^{0.5}$.

1

Let $u$ be the inside. $u = Y^3 + 4Y$, so $u' = 3Y^2 + 4$.

2

Rewrite with $u$. $C = u^{0.5}$.

3

Differentiate, then multiply by $u'$. $C' = 0.5u^{-0.5}\cdot u' = 0.5u^{-0.5}(3Y^2 + 4)$.

4

Plug in what $u$ was. $C' = 0.5(Y^3 + 4Y)^{-0.5}(3Y^2 + 4)$.

$$\boxed{C' = 0.5(Y^3 + 4Y)^{-0.5}(3Y^2 + 4) = \frac{3Y^2 + 4}{2\sqrt{Y^3 + 4Y}}}$$

Either form is a complete answer. You do not need to expand it.

4

Why multiply by u'?

The question asks for $\dfrac{dy}{dx}$: how $y$ changes with $x$. In Step 3, $y$ is written with $u$, so differentiating gives $\dfrac{dy}{du}$ instead. Multiplying by $u' = \dfrac{du}{dx}$ finishes the job:

$$\frac{dy}{du}\cdot\frac{du}{dx} = \frac{dy}{dx}$$

The $du$ terms cancel, like a fraction, and what is left is the derivative you were looking for.

5

Once the steps feel familiar

The four steps are the clearest way to learn the chain rule and to show your work. With practice you can run them in your head: differentiate the outside, leave the inside unchanged, multiply by the derivative of the inside. These three shortcuts are that idea for the outsides you will meet most. Here $f$ is the inside and $f'$ is its derivative.

ShortcutBracket to a power: $\big([f]^n\big)' = n[f]^{n-1}\cdot f'$.
Example$\big((4x - 1)^5\big)' = 5(4x - 1)^4\cdot 4 = 20(4x - 1)^4$.
Shortcut$e$ to a function: $\big(e^{f}\big)' = f'\,e^{f}$.
Example$\big(500e^{-0.3Q}\big)' = 500(-0.3)e^{-0.3Q} = -150e^{-0.3Q}$.
Shortcut$\ln$ of a function: $(\ln f)' = \dfrac{f'}{f}$.
Example$\big(\ln(Y^2 + 7)\big)' = \dfrac{2Y}{Y^2 + 7}$.
Derivative of the inside, over the inside.

Tidying the answer. It is usual to write the number in front: $5e^{2x}$ instead of $e^{2x}\cdot 5$. Both are correct, in the same way that $2x$ and $x \cdot 2$ are the same thing. You usually do not need to expand brackets in a chain rule answer unless your course asks for it.

Common mistakes and what to check

These are common chain rule mistakes. Review them so you know what to check when an answer seems off.

Common mistake 1

Forgetting to multiply by $u'$. Check: does your answer contain the derivative of the inside? For $(3x + 10)^2$ that is the $3$.

Common mistake 2

Skipping Step 2. For $\ln(2x + 9)$ it is easy to write $\frac{1}{x}$ out of habit. Rewriting as $\ln u$ first reminds you the derivative is $\frac{1}{u}$.

Common mistake 3

Differentiating a second time. For $y = (2x + 1)^{-3}$, Step 3 gives $-3u^{-4}\cdot 2$. The $-3$ has already come down, so do not multiply it by the new power $-4$. After Step 3 there are no more derivatives to take: $y' = -6(2x + 1)^{-4}$.

Common mistake 4

Leaving $u$ in the final answer. Plug in so the answer uses the original variable.

Quick Check: Can You Apply It?

Differentiate each one on paper first, then open the answer.

(a) $y = (4Q - 3)^5$

$u = 4Q - 3$, so $u' = 4$. Then $y = u^5$ and $y' = 5u^4\cdot 4 = 20(4Q - 3)^4$.

(b) $y = 30e^{-0.2t}$

$u = -0.2t$, so $u' = -0.2$. Then $y = 30e^{u}$ and $y' = 30e^{u}(-0.2) = -6e^{-0.2t}$.

(c) $y = \ln(6Q + 5)$

$u = 6Q + 5$, so $u' = 6$. Then $y = \ln u$ and $y' = \dfrac{1}{u}\cdot 6 = \dfrac{6}{6Q + 5}$.

(d) $y = e^{x^3}$

$u = x^3$, so $u' = 3x^2$. Then $y = e^{u}$ and $y' = e^{u}\cdot 3x^2 = 3x^2e^{x^3}$.

A function times a function

The product rule is for two separate functions of the variable multiplied together. Call the first piece $f(x)$ and the second piece $h(x)$.

FunctionFirst pieceSecond piece
$x^3\ln x$$x^3$$\ln x$
$6\sqrt{Q}\,(Q + 2)$$6Q^{0.5}$$Q + 2$
$(2x + 5)e^{x}$$2x + 5$$e^x$
$$y = f(x)\cdot h(x) \quad\Longrightarrow\quad y' = f'(x)\,h(x) + f(x)\,h'(x)$$

In words: the derivative of the first times the second, plus the first times the derivative of the second.

2

Two steps: copy it twice, then differentiate one piece in each copy

You do not have to memorize the formula as a string of symbols. Build it in two steps.

Step 1. Copy it twice. Write the product two times, with a plus sign between the copies.

$f(x)$×$h(x)$+$f(x)$×$h(x)$

Step 2. Differentiate one piece in each copy. In the first copy, differentiate the first piece. In the second copy, differentiate the second piece. Leave the other piece in each copy as it is.

$f'(x)$×$h(x)$+$f(x)$×$h'(x)$

Shaded tiles have been differentiated. Plain tiles are copied as they are.

That is the whole rule. Keep the pieces in the same order in both copies. It makes the pattern easy to see, and it sets you up for the quotient rule, where the order matters.

A number in front is not a product. For $5x^3$, the $5$ is a constant, so Rule 3 is enough: $15x^2$. The product rule is for two pieces that both contain the variable.

4

Product rule with the chain rule inside

Sometimes one of the pieces needs the chain rule. You do not have to plan for that ahead of time. Start the product rule as usual. When you reach a piece that is a function inside a function, work out its derivative off to the side with the four steps, then bring the result back.

Worked example

Differentiate $S = 80Ye^{-0.25Y}$.

1

Copy it twice. $(80Y)(e^{-0.25Y}) + (80Y)(e^{-0.25Y})$.

2

First piece. $(80Y)' = 80$.

3

Second piece, off to the side. The power is not just $Y$, so use the chain rule. $u = -0.25Y$, so $u' = -0.25$. The piece is $e^{u}$, and its derivative is $e^{u}\cdot u' = -0.25e^{-0.25Y}$.

4

Bring it back. $S' = (80)(e^{-0.25Y}) + (80Y)(-0.25e^{-0.25Y})$.

$$\boxed{S' = 80e^{-0.25Y} - 20Ye^{-0.25Y}}$$

Multiplying $80$ by $-0.25$ gives the $-20$. You could also factor: $20e^{-0.25Y}(4 - Y)$.

Common mistakes and what to check

These are common product rule mistakes. Review them so you know what to check when an answer seems off.

Common mistake 1

Multiplying the two derivatives. $(f\cdot h)'$ is not $f'\cdot h'$. For $x\ln x$ that would give $1\cdot\frac{1}{x}$, but the derivative is $\ln x + 1$.

Common mistake 2

Differentiating both pieces in the same copy. Each copy has one piece differentiated and one piece left as it is.

Common mistake 3

Dropping one of the two terms. The product rule gives two terms added together. Check that each piece appears once as itself and once differentiated.

Common mistake 4

Using the product rule for a number times a function. $5e^{2x}$ only needs Rule 3 and the $e^{ax}$ rule.

Differentiate each one on paper first, then open the answer.

(a) $y = x^4\ln x$

(b) $Q = 6Le^{0.5L}$

(c) $y = (3x + 2)(x^2 - 5)$

Three steps: start from the product rule

If you can do the product rule, you can do the quotient rule. It is almost the same thing, with two changes.

Step 1. Copy the product rule. Treat the fraction as top times bottom. Write the pair twice, then differentiate the top in the first copy and the bottom in the second copy.

$f'(x)$×$h(x)$+$f(x)$×$h'(x)$

Step 2. Change the plus to a minus.

$f'(x)$×$h(x)$−$f(x)$×$h'(x)$

Step 3. Divide by the bottom squared. Square the whole bottom, $h(x)$, not its derivative.

4

How far to simplify

Simplify when it makes the answer easier to read. A useful order:

  1. Tidy the top. Multiply out and collect like terms. Terms often cancel, as in the worked example.
  2. Look for a factor to cancel before you expand anything. If the top has a factor that matches the bottom, it can be crossed off.
  3. Leave the bottom as a square. $(2Q + 3)^2$ is usually clearer than $4Q^2 + 12Q + 9$, and it keeps any matching factor easy to spot.

Both forms describe the same function. Some courses prefer the bottom expanded, so check what yours expects.

Common mistakes and what to check

These are common quotient rule mistakes. Review them so you know what to check when an answer seems off.

Common mistake 1

Keeping the plus sign, or swapping the order. The term with the derivative of the top comes first, and the second term is subtracted. Swapping them gives the negative of the answer.

Common mistake 2

Squaring the derivative of the bottom. For a bottom of $2Q + 3$, the answer is over $(2Q + 3)^2$, not over $2^2 = 4$.

Common mistake 3

Forgetting brackets. In $(5)(2Q + 3) - (5Q)(2)$ the minus applies to the whole second product. With longer pieces, a missing bracket changes the sign of part of the answer.

b

c

Off to the side, for the second piece: $u = -Q$, $u' = -1$, so $\big(e^{u}\big)' = -e^{-Q}$.

Copy it twice. $\left(Q^2\right)\left(e^{-Q}\right) + \left(Q^2\right)\left(e^{-Q}\right)$

Differentiate the first piece, then the second. $TR' = \left(2Q\right)\left(e^{-Q}\right) + \left(Q^2\right)\left(-e^{-Q}\right)$

Tidy up. $TR' = 2Qe^{-Q} - Q^2e^{-Q} = Qe^{-Q}(2 - Q)$.

$TR'$ is marginal revenue.

Rewrite, then basic rules

Rewrite $\dfrac{10}{Y} = 10Y^{-1}$.

$C' = 0.8 + 10Y^{-2} = 0.8 + \dfrac{10}{Y^2}$.

Differentiate $y = \dfrac{e^x}{1 + e^x}$

Quotient rule

Top and bottom. Top: $f = e^x$, $f' = e^x$. Bottom: $h = 1 + e^x$, $h' = e^x$.

Product rule copy, with a minus, over the bottom squared. $y' = \dfrac{\left(e^x\right)\left(1 + e^x\right) - \left(e^x\right)\left(e^x\right)}{\left(1 + e^x\right)^2}$

Tidy the top. $y' = \dfrac{e^x + e^{2x} - e^{2x}}{(1 + e^x)^2} = \dfrac{e^x}{(1 + e^x)^2}$.

Differentiate $y = \ln(Q^2 + 3Q)$

Chain rule

Step 1. $u = Q^2 + 3Q$, so $u' = 2Q + 3$.

Step 2. $y = \ln u$.

Step 3. $y' = \dfrac{1}{u}(2Q + 3)$.

Step 4. $y' = \dfrac{2Q + 3}{Q^2 + 3Q}$.

Differentiate $AC = \dfrac{Q^2 + 100}{Q}$

Split first

The bottom is one term, so split the fraction: $AC = Q + 100Q^{-1}$.

$AC' = 1 - 100Q^{-2} = 1 - \dfrac{100}{Q^2}$.

Differentiate $y = x\ln(x^2)$

Log law, then product rule

Log law first: $\ln(x^2) = 2\ln x$, so $y = 2x\ln x$.

Copy it twice. $\left(2x\right)\left(\ln x\right) + \left(2x\right)\left(\ln x\right)$

Differentiate the first piece, then the second. $y' = \left(2\right)\left(\ln x\right) + \left(2x\right)\left(\dfrac{1}{x}\right)$

Tidy up. $y' = 2\ln x + 2$.

Multiply out: $S = 200 - 200e^{-0.3t}$. The $200$ gives $0$.

Economics applications

1

A demand function is $P = 20 - 4\ln Q$.

  1. Write down the equation for TR. Find the value of $Q$ at which TR is a maximum, and the maximum TR.
  2. Write down the equation for MR. Show, by differentiating, that MR decreases as $Q$ increases and that the MR curve is concave up.

Product rule, then optimize

(a) $TR = PQ = 20Q - 4Q\ln Q$.

For $4Q\ln Q$, copy it twice: $(4Q)(\ln Q) + (4Q)(\ln Q)$. Differentiating one piece in each copy gives $(4)(\ln Q) + (4Q)\left(\dfrac{1}{Q}\right) = 4\ln Q + 4$.

$MR = 20 - (4\ln Q + 4) = 16 - 4\ln Q$. Setting $MR = 0$: $\ln Q = 4$, so $Q = e^4 \approx 54.5982$.

$TR'' = -\dfrac{4}{Q}$, which is negative for every $Q > 0$, so this is a maximum.

At $Q = e^4$, $P = 20 - 16 = 4$, so $TR = 4e^4 \approx 218.3926$.

(b) $MR = 16 - 4\ln Q$.

$MR' = -\dfrac{4}{Q} < 0$, so MR decreases as $Q$ increases.

$MR'' = \dfrac{4}{Q^2} > 0$, so the MR curve is concave up (it bends upward).

2

A demand function is $P = 80e^{-0.04Q}$. Find the output at which TR is a maximum, the price at that output, and the maximum TR.

Product rule with chain rule inside, then optimize

$TR = 80Qe^{-0.04Q}$. Copy it twice: $(80Q)(e^{-0.04Q}) + (80Q)(e^{-0.04Q})$.

$MR = (80)(e^{-0.04Q}) + (80Q)(-0.04e^{-0.04Q}) = 80e^{-0.04Q} - 3.2Qe^{-0.04Q}$.

Factor: $MR = 3.2e^{-0.04Q}(25 - Q)$. Since $e^{-0.04Q}$ is never zero, $MR = 0$ gives $Q = 25$.

Check: $TR'' = e^{-0.04Q}(0.128Q - 6.4)$, which at $Q = 25$ is $-3.2e^{-1} \approx -1.1772 < 0$. A maximum.

$P = 80e^{-1} \approx 29.4304$, and $TR = 80(25)e^{-1} = 2000e^{-1} \approx 735.7589$.

3

A total cost function is $TC = 50\ln(Q + 5) + 200$.

  1. Find TFC.
  2. Write down MC, and evaluate it at $Q = 20$.
  3. Show that MC decreases as output increases.

Chain rule

(a) $TFC = TC(0) = 50\ln 5 + 200 \approx 280.4719$.

(b) $u = Q + 5$, $u' = 1$. Then $50\ln u$ differentiates to $\dfrac{50}{u}\cdot 1$, so $MC = \dfrac{50}{Q + 5}$. At $Q = 20$: $MC = \dfrac{50}{25} = 2$.

(c) Rewrite $MC = 50(Q + 5)^{-1}$. Then $MC' = -50(Q + 5)^{-2} = -\dfrac{50}{(Q + 5)^2}$, which is negative for every $Q \ge 0$. So MC decreases as output increases.

4

A firm's short-run production function is $Q = 20Le^{-0.1L}$, where $L$ is labour. Find $MP_L$, the level of $L$ that maximizes output, and the maximum output.

Product rule with chain rule inside, then optimize

Copy it twice: $(20L)(e^{-0.1L}) + (20L)(e^{-0.1L})$.

$MP_L = Q' = (20)(e^{-0.1L}) + (20L)(-0.1e^{-0.1L}) = 20e^{-0.1L} - 2Le^{-0.1L} = 2e^{-0.1L}(10 - L)$.

Setting $MP_L = 0$: $10 - L = 0$, so $L = 10$.

Check: $Q'' = e^{-0.1L}(0.2L - 4)$, which at $L = 10$ is $-2e^{-1} \approx -0.7358 < 0$. A maximum.

$Q = 20(10)e^{-1} = 200e^{-1} \approx 73.5759$.
