# Game Theory

Interactive worksheets covering strategic behavior in microeconomics: simultaneous games, dominance and Nash equilibrium, the Prisoner's Dilemma and cartel collusion, sequential games and backward induction, repeated games and the discount-factor condition for sustaining cooperation, mixed strategies, and Cournot competition as a Nash equilibrium in continuous strategies.

## Contents

- **game-theory-micro.html** — full interactive worksheet: definitions with worked numeric examples, payoff-matrix lab, sequential game trees, grim-trigger discount-factor explorer, mixed-strategy best-response diagrams, and a Cournot bridge connecting reaction functions to best responses. Includes 8 scaffolded practice problems with step-by-step checks.
