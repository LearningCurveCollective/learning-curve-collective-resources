Question 12 of 15Quantitative
Each of the 576 houses in Tenantville is owned by one of the following property owners: Matt, Gavin, Angela, or Susan. Matt and Angela together own as many houses as Gavin and Susan own combined. Gavin owns 100 more houses than Susan owns, and Matt owns 100 more houses than Angela owns. How many houses does Susan own?
Solution. Let Susan = S, Gavin = S + 100, Angela = A, Matt = A + 100. "Matt + Angela = Gavin + Susan" means (A + 100 + A) = (S + 100 + S), i.e. both pairs are equal, so each pair is half of 576 = 288. Then Gavin + Susan = 288 → (S + 100) + S = 288 → 2S = 188 → S = 94. Answer: B (94).
