Exponent rules

The rules below govern how powers combine. In every rule, the bases $b$, $x$, and $y$ are nonzero real numbers, and the exponents $m$, $n$, and $a$ are integers unless noted. Read slowly; each rule comes with two worked examples.

Rule 1Negative exponents:   $b^{-n} = \dfrac{1}{b^{\,n}}$
Example A $5^{-2} = \dfrac{1}{5^2} = \dfrac{1}{25}$
Example B $x^{-7} = \dfrac{1}{x^{7}}$
Example C $\dfrac{1}{3^{-m}} = 3^{\,m}$   (the flip works in both directions)
Rule 2Product rule:   $b^m \cdot b^n = b^{\,m+n}$
Example A $(2^3)(2^5) = 2^{3+5} = 2^8 = 256$
Example B $(w^4)(w^{-1}) = w^{3}$
Rule 3Quotient rule:   $\dfrac{b^m}{b^n} = b^{\,m-n} = \dfrac{1}{b^{\,n-m}}$
Example A $\dfrac{7^6}{7^2} = 7^{6-2} = 7^4$
Example B $\dfrac{s^2}{s^9} = s^{-7} = \dfrac{1}{s^{7}}$
Rule 4Zero exponent:   $b^{\,0} = 1$
Example A $12^{0} = 1$
Example B $(-6)^{0} = 1$
Note that $0^{0}$ is not defined.
Rule 5Power of a product:   $x^a \, y^a = (xy)^a$
Example A $(5^2)(2^2) = 10^2 = 100$
Example B $(4k)^3 = 4^3 k^3 = 64k^{3}$
Rule 6Power of a quotient:   $\left(\dfrac{x}{y}\right)^{\!a} = \dfrac{x^a}{y^a}$
Example A $\left(\dfrac{2}{5}\right)^{\!3} = \dfrac{2^3}{5^3} = \dfrac{8}{125}$
Example B $\left(\dfrac{m}{3n}\right)^{\!2} = \dfrac{m^2}{9n^{2}}$
Rule 7Power of a power:   $(b^m)^n = b^{\,mn}$
Example A $(3^2)^4 = 3^{8}$
Example B $(2z^5)^2 = 4z^{10}$
Rule 8Roots as exponents:   $\sqrt{b} = b^{1/2}$
Example A $\sqrt{5} \cdot \sqrt{5} = 5^{1/2} \cdot 5^{1/2} = 5^{1} = 5$
Example B $(\sqrt{2})^{6} = (2^{1/2})^{6} = 2^{3} = 8$
Moves that are not allowed

The rules above are identities — they hold for every legal value. The six statements below look like rules but are false, and each one generates a standard wrong answer. Keep them in mind.

Case 1not allowed:   $x^a \, y^b \neq (xy)^{a+b}$
For example, $(3^2)(2^3) = 9 \cdot 8 = 72$, while $(3 \times 2)^{2+3} = 6^5 = 7{,}776$. Different bases with different exponents do not combine.
Case 2not allowed:   $(x^a)^b \neq x^a x^b$
Instead, $(x^a)^b = x^{ab}$ while $x^a x^b = x^{a+b}$. For example, $(5^2)^3 = 5^6$, but $5^2 \cdot 5^3 = 5^{5}$.
Case 3not allowed:   $(x+y)^a \neq x^a + y^a$
In particular, $(x+y)^2 = x^2 + 2xy + y^2$ — the correct expansion carries the extra term $2xy$.
Case 4not allowed:   $(-x)^2 \neq -x^2$
Instead, $(-x)^2 = x^2$, while $-x^2$ is the negative of $x^2$. The exponent applies only to what it touches: $(-3)^2 = 9$ but $-3^2 = -9$.
Case 5not allowed:   $\sqrt{x^2 + y^2} \neq x + y$
For example, $\sqrt{9 + 16} = \sqrt{25} = 5$, not $3 + 4 = 7$. Roots do not distribute over addition.
Case 6not allowed:   $\dfrac{a}{x+y} \neq \dfrac{a}{x} + \dfrac{a}{y}$
A sum in the denominator does not split. A sum in the numerator does: $\dfrac{x+y}{a} = \dfrac{x}{a} + \dfrac{y}{a}$.

Worked examples & practice

Everything on the reference tab runs on one idea: when powers of the same base combine, the operation steps down one level for the exponents. Multiplication becomes addition, division becomes subtraction, and a power of a power becomes multiplication.
