Watch the Tree Grow, One Decision at a Time

A decision tree classifies by asking yes/no questions about one feature at a time: “is $x_1 < 5$?” Each question slices the feature space with an axis-aligned line, so the finished tree carves the plane into rectangles, and each rectangle predicts the majority class of the training points inside it.

Growing the tree means choosing the slices — greedily, one at a time, always picking the split that most reduces the weighted Gini loss of the children. Step through the algorithm below on a 10-point dataset and watch every number get computed.

Problem 1(a): A Split Can Never Increase the Gini Loss

Givens. Binary classification ($K = 2$), no degenerate overlap. For any region $R_m$, let $p \in [0,1]$ denote its proportion of positive examples, so $p_{m1} = p$, $p_{m2} = 1-p$, and $\vec{p}_m = [\,p \;\; 1-p\,]$. Instantiating the Gini definition at $K = 2$:

$$G(R_m) = \sum_{k=1}^{2} p_{mk}(1-p_{mk}) = p(1-p) + (1-p)p = 2p(1-p)$$

A split $s_p(j,t)$ partitions parent $R_p$ into $R_1 = \{X \mid x_j < t,\ X \in R_p\}$ and $R_2 = \{X \mid x_j \geq t,\ X \in R_p\}$, with $n_1 = |R_1|$, $n_2 = |R_2|$ and positive-proportions $p_1, p_2$. Hint (two-point Jensen): for strictly concave $G$,

$$\forall\, p_1 \neq p_2,\ \forall\, \lambda \in (0,1): \quad \lambda G(p_1) + (1-\lambda)G(p_2) \;<\; G\bigl(\lambda p_1 + (1-\lambda)p_2\bigr)$$

Goal. $\dfrac{n_1 G(p_1) + n_2 G(p_2)}{n_1 + n_2} \;\leq\; G(P_p)$ for any split.

P

Plan. Divide every split into three exhaustive cases: an empty child; both children nonempty with $p_1 = p_2$; both nonempty with $p_1 \neq p_2$. Dispatch the empty-child case immediately by direct computation (equality). Then establish the shared identity both remaining cases need: counting positive examples shows $P_p$ is exactly the $\lambda$-weighted average of $p_1, p_2$, with $\lambda$ = the left child's share of the data. The $p_1 = p_2$ case follows by direct substitution (equality). For $p_1 \neq p_2$, show $G$ is strictly concave via the second-derivative test and apply Jensen's inequality at the $\lambda$-mixture (strict).

Case structure. Every split falls into exactly one of: Case 0 — a child ($n_1$ or $n_2$) is empty; Case A — both children nonempty with $p_1 = p_2$; Case B — both children nonempty with $p_1 \neq p_2$. The claim holds in all three, with equality in Cases 0 and A and strict inequality in Case B.

0

Case 0 (empty child). WLOG suppose $n_1 = 0$ (the case $n_2 = 0$ is symmetric). Then every point of $R_p$ lies in $R_2$, so $R_2 = R_p$, hence $p_2 = P_p$. The empty region contributes nothing to the loss:

$$\frac{n_1 G(R_1) + n_2 G(R_2)}{n_1 + n_2} = \frac{n_2\, G(p_2)}{n_2} = G(p_2) = G(P_p)$$

Equality — claim holds. For the remainder of the proof, assume $n_1, n_2 \geq 1$.

1

Counting positives (shared infrastructure). The parent's proportion is total positives over total count, and positives split across the children:

$$P_p = \frac{\text{positives in } R_1 + \text{positives in } R_2}{n_1 + n_2} = \frac{n_1 p_1 + n_2 p_2}{n_1 + n_2}$$

2

Define the mixing weight.

$$\lambda := \frac{n_1}{n_1 + n_2} \quad\Rightarrow\quad 1 - \lambda = \frac{n_2}{n_1 + n_2}, \qquad \lambda \in (0,1) \ \text{ since } n_1, n_2 \geq 1$$

Substituting into Step 1:

$$P_p = \lambda\, p_1 + (1-\lambda)\, p_2 \tag{$\ast\ast$}$$

A

Case A ($n_1, n_2 \geq 1$ and $p_1 = p_2$). Let $p := p_1 = p_2$. By $(\ast\ast)$: $P_p = \lambda p + (1-\lambda)p = p$. Thus the weighted children's loss:

$$\frac{n_1 G(p) + n_2 G(p)}{n_1 + n_2} = \frac{(n_1+n_2)\,G(p)}{n_1 + n_2} = G(p) = G(P_p)$$

Claim holds (with equality).

B

Case B ($n_1, n_2 \geq 1$ and $p_1 \neq p_2$). From the Givens, $G(p) = 2p(1-p) = 2p - 2p^2$. Differentiate twice:

$$G'(p) = 2 - 4p, \qquad G''(p) = -4 < 0 \quad \forall p \in [0,1]$$

A twice-differentiable function with $G'' < 0$ everywhere is strictly concave, so the hint holds. As established: $G$ is strictly concave, $\lambda \in (0,1)$ (Step 2), and $p_1 \neq p_2$ (case assumption) — so Jensen's inequality applies at our $\lambda$:

$$\lambda G(p_1) + (1-\lambda)G(p_2) \;<\; G\bigl(\lambda p_1 + (1-\lambda)p_2\bigr) = G(P_p) \qquad \text{(by } \ast\ast\text{)}$$

By definition of $\lambda$, the left side is precisely the weighted Gini loss of the children:

$$\frac{n_1 G(p_1) + n_2 G(p_2)}{n_1 + n_2} \;<\; G(P_p)$$

Claim holds (strictly).

Conclusion. Cases 0, A, B are exhaustive; equality holds in Cases 0 and A, strict inequality in Case B. Hence for any split:

$$\boxed{\;\frac{|R_1|\,G(R_1) + |R_2|\,G(R_2)}{|R_1| + |R_2|} \;\leq\; G(R_p)\;}$$

with equality if and only if the split is vacuous or $p_1 = p_2$. $\blacksquare$

Intuition: dome beats chord. $G$'s graph is a dome; every chord hangs at or below it. Step 1 chains the parent's proportion to a point on the chord's horizontal span, Step 2 identifies that point as the chord parameter $\lambda$, and Case B reads off “curve above chord” there. The three cases are the three ways a chord can fail to sit strictly below the curve: no chord at all (Case 0), endpoints coincide (Case A), or neither — the split genuinely separated something and Gini strictly rewards it (Case B). Deeper echo: $G(p) = 2p(1-p)$ is twice the variance of a Bernoulli$(p)$, so “splitting reduces Gini” is the law-of-total-variance fact that conditioning can't increase variance.

Precision traps caught in drafting (keep these on the checklist): (1) The pset uses $t$ for both the split threshold and (in the hint) the mixing weight — we renamed the weight $\lambda$. (2) “Chord below curve” is concave, not convex — and on the diagram, the chord's label is the one with two $G$'s ($\lambda G(p_1) + (1-\lambda)G(p_2)$); the curve's has one ($G$ of the mixture). (3) $\lambda \in (0,1)$ must be cited, not assumed — it's exactly what the standing assumption $n_1, n_2 \geq 1$ buys, and Jensen's hypothesis check needs it. (4) In Case 0, every point (not just every positive) lies in the surviving child — that's what forces $R_2 = R_p$. (5) The claim is $\leq$ but strict concavity only delivers $<$ when $p_1 \neq p_2$: the equality cases must be handled explicitly, and they earn their keep in part (b).

Problem 1(b): When Gini Stalls — and Why Purity Still Arrives

The cases where Gini stays the same (by part (a)'s iff): (i) a vacuous split ($n_1 = 0$ or $n_2 = 0$); (ii) $n_1, n_2 \geq 1$ with $p_1 = p_2$ (whence $p_1 = p_2 = P_p$ by $\ast\ast$).

No violation of strict concavity. The strict inequality is conditional on two hypotheses: $\lambda \in (0,1)$ and $p_1 \neq p_2$. Case (i) falsifies the first: an empty child gives $\lambda \in \{0,1\}$. Case (ii) falsifies the second: the two points coincide — there is no chord for the curve to lie strictly above. $G$ itself remains strictly concave ($G'' = -4$ throughout); only the improvement is zero. A conditional asserts nothing when its hypotheses fail, so equality in these cases does not contradict strict concavity — indeed, by (a)'s iff, strict concavity is exactly what confines equality to these two cases.

Zero Gini is still reached. Any impure leaf ($0 < p_R < 1$) contains a positive and a negative example; by the no-overlap assumption these differ in some feature $j$, so any threshold strictly between their $x_j$ values gives a non-vacuous split. Non-vacuous splits — including those of case (ii) — strictly shrink region sizes (each child leaves at least one point to the other), and the data is finite, so a fully grown tree halts only when no impure leaf remains. Every leaf pure means $p \in \{0,1\}$ at each leaf, so $G(p) = 0$ everywhere and the tree's total Gini (a weighted average of zeros) is $0$. The equality cases stall progress on a given split, but they never destroy the existence of a further productive split — and it is existence, not per-split progress, that purity rests on. $\blacksquare$

The XOR checkerboard — all of (b) in four points. $+$ at $(0,0), (1,1)$; $-$ at $(0,1), (1,0)$. Every non-vacuous root split lands in case (ii): each child inherits the 50/50 mix, score frozen at $0.500$. Greedy commits to a non-improving split anyway — and each child drops from 4 points to 2, where the classes separate cleanly. Depth 2 reaches zero Gini. Stagnation isn't a trap, because splits shrink regions even when they don't improve the score. (Caveat for practice: a “stop when no split improves” rule does get trapped here at the root — the pset's “fully grown” sidesteps this by definition.)

The Tent: Misclassification Loss and the Additional Stalling Case

Part (c) swaps the Gini dome for the misclassification loss $M(p) = 1 - \max(p, 1-p) = \min(p, 1-p)$ — a tent, not a dome. Its two faces are straight lines, and straight lines change everything: a chord between two points on the same face doesn't sag below the curve, it lies on it. That geometric fact is the entire additional case: both children nonempty, $p_1 \neq p_2$, but both children share the same majority class. Step through it on a concrete dataset.

Why $M$ is a tent: the derivation

1

Instantiate the definition at $K = 2$. With $p := p_{m1}$ (fraction positive), so $p_{m2} = 1 - p$:

$$M(p) = 1 - \max_k p_{mk} = 1 - \max(p,\, 1-p)$$

2

One minus the max of two numbers summing to 1 is the min. If $p \geq 1-p$: $\;1 - \max(p, 1-p) = 1 - p = \min(p, 1-p)$. If $p < 1-p$: $\;1 - \max = 1 - (1-p) = p = \min$. Either way:

$$M(p) = \min(p,\, 1-p)$$

3

Split at which argument wins the min.

$$M(p) = \begin{cases} p, & p \leq \tfrac12 \quad \text{(region votes } -\text{; the errors are the positives)} \\[3pt] 1-p, & p \geq \tfrac12 \quad \text{(region votes } +\text{; the errors are the negatives)} \end{cases}$$

Each branch is a linear function of $p$ — slope $+1$ on the left, $-1$ on the right — and at $p = \tfrac12$ both branches give $\tfrac12$, so they meet consistently at the peak $(\tfrac12, \tfrac12)$. Two line segments joined at a peak: a tent. On each face $M'' = 0$: weakly concave, never strictly.

4

Count form (the hint's notation). Since $p = \tfrac{N_{m1}}{N_m}$:

$$M(R_m) = \frac{\min(N_{m1},\, N_{m2})}{N_m}$$

— the minority count over the region size: exactly the number of errors made by majority-vote prediction, per point. This is the form the freeze computation runs on in Step 3 of the walkthrough below.

Straightness, operationally. March $p$ up the right face in equal steps: $M(0.6), M(0.7), M(0.8), M(0.9) = 0.40, 0.30, 0.20, 0.10$ — equal steps out. Every convert removes exactly one error; the exchange rate never changes. Gini on the same march: $0.48, 0.42, 0.32, 0.18$ — steps of $0.06, 0.10, 0.14$, a changing exchange rate. Constant rate = straight = averaging commutes with the loss (chords lie on faces); changing rate = curved = Jensen bites (chords sag). That single contrast is all of part (c).

The one-sentence version. $M$ counts the errors of majority-vote prediction — so if a split flips no votes (both children inherit the parent's majority), the predictions on every point are unchanged, the errors are unchanged, and the loss is frozen, no matter how much purer one child became. Gini's strict curvature is exactly what lets it see that invisible progress — which is why trees are grown with Gini (or entropy) and evaluated with $M$.

Practice

1

Warm-up. A region contains 12 positive and 4 negative points. Compute $p$ and the binary Gini loss $G(p)$.

$p = \dfrac{12}{16} = \dfrac{3}{4}$, so $G\!\left(\tfrac34\right) = 2 \cdot \tfrac34 \cdot \tfrac14 = \dfrac{3}{8} = 0.375$.

Sanity check against the dome: $0.375 < 0.5 = G\!\left(\tfrac12\right)$, as it must be — the region has a clear majority, so it's less impure than a 50/50 mix.

2

Which split wins? A parent has 20 points, 10 of each class ($p_{\text{parent}} = \tfrac12$). Two candidate splits:

• Split A: children of sizes $10$ and $10$ with $p_1 = 0.9$, $p_2 = 0.1$.
• Split B: children of sizes $4$ and $16$ with $p_1 = 1$, $p_2 = 0.375$.

Verify both are consistent with the parent, compute each weighted Gini, and say which the greedy algorithm picks.

Consistency (mixture identity): A: $\tfrac{10(0.9)+10(0.1)}{20} = \tfrac{9+1}{20} = \tfrac12$ ✓.   B: $\tfrac{4(1)+16(0.375)}{20} = \tfrac{4+6}{20} = \tfrac12$ ✓.

Split A: $G(0.9) = G(0.1) = 2(0.9)(0.1) = 0.18$, so weighted $= \tfrac{10(0.18)+10(0.18)}{20} = 0.18$.

Split B: $G(1) = 0$; $G(0.375) = 2(0.375)(0.625) = 0.46875$; weighted $= \tfrac{4(0)+16(0.46875)}{20} = \tfrac{7.5}{20} = 0.375$.

$0.18 < 0.375$: greedy picks Split A. Note the lesson — B manufactures a small pure child, but purity of a tiny region buys little; Gini weights each child by its share of the data. Both beat the parent's $0.5$, as 1(a) guarantees.

3

Dome vs. chord, numerically. A split produces children $(n_1, p_1) = (6, \tfrac23)$ and $(n_2, p_2) = (9, \tfrac13)$. Compute $p_{\text{parent}}$, then compute both sides of the 1(a) inequality exactly (fractions, not decimals) and confirm the strict inequality.

$p_{\text{parent}} = \dfrac{6 \cdot \tfrac23 + 9 \cdot \tfrac13}{15} = \dfrac{4+3}{15} = \dfrac{7}{15}$.

Dome (parent): $G\!\left(\tfrac{7}{15}\right) = 2 \cdot \tfrac{7}{15} \cdot \tfrac{8}{15} = \dfrac{112}{225} \approx 0.498$.

Chord (children): $G\!\left(\tfrac23\right) = G\!\left(\tfrac13\right) = 2 \cdot \tfrac23 \cdot \tfrac13 = \tfrac49$, so weighted $= \tfrac{6 \cdot \frac49 + 9 \cdot \frac49}{15} = \tfrac49 = \dfrac{100}{225} \approx 0.444$.

$\dfrac{100}{225} < \dfrac{112}{225}$ ✓ — strict, since $p_1 \neq p_2$.

4

The equality case. A parent has 8 positives and 8 negatives. Construct an explicit split (give $n_1, p_1, n_2, p_2$) whose weighted children's Gini equals the parent's, and explain in one sentence why no strict improvement occurs.

Any split with $p_1 = p_2$ works, e.g. $(n_1, p_1) = (4, \tfrac12)$ and $(n_2, p_2) = (12, \tfrac12)$: each child inherits the parent's 50/50 mix, so weighted Gini $= G\!\left(\tfrac12\right) = 0.5 = G(p_{\text{parent}})$.

Why no improvement: the split moved points around but didn't change any region's class balance — the two chord endpoints coincide on the dome, so chord and curve touch. (Case B of the proof.)

Notation & Formula Reference

Cast of characters

SymbolWhat it is
$R_p$Parent region: the chunk of feature space (and the training points in it) we're about to split
$s_p(j, t)$A split: pick feature $j$ and threshold $t$; the question “is $x_j < t$?”
$R_1,\; R_2$The children: $R_1 = \{X \mid x_j < t\}$ (yes-points), $R_2 = \{X \mid x_j \geq t\}$ (no-points, boundary included)
$|R_m|$Number of training points in region $R_m$
$p_{mk}$Fraction of $R_m$'s points belonging to class $k$; the vector $\vec{p}_m$ stacks these over all $K$ classes and sums to 1
$G(R_m)$Gini loss of the region: $\sum_k p_{mk}(1 - p_{mk})$; in the binary case, one scalar $p$ suffices and $G(p) = 2p(1-p)$
$M(R_m)$Misclassification loss: $1 - \max_k p_{mk}$, the error rate of predicting the majority class

Binary Gini loss

$$G(p) = 2p(1-p)$$

Zero at $p \in \{0, 1\}$ (pure), max $0.5$ at $p = \tfrac12$. Equals the chance two draws from the region disagree; also $2 \times$ Bernoulli variance.

Split objective

$$\min_{j,t}\; \frac{|R_1|L(R_1) + |R_2|L(R_2)}{|R_1| + |R_2|}$$

Greedy search over all features and thresholds; each child's loss weighted by its share of the data.

Mixture identity

$$p_{\text{parent}} = w\,p_1 + (1-w)\,p_2,\;\; w = \tfrac{n_1}{n_1+n_2}$$

Pure counting: positives in the parent = positives in $R_1$ + positives in $R_2$. The hinge of the 1(a) proof.

Strict concavity (two-point Jensen)

$$G(wp_1 + (1{-}w)p_2) > wG(p_1) + (1{-}w)G(p_2)$$

For $p_1 \neq p_2$, $w \in (0,1)$. Certified by $G''(p) = -4 < 0$. Geometrically: dome beats chord.

The algorithm in one breath. Start with all data in one region. Search every (feature, threshold) pair; score each by weighted children's Gini; make the best split. Recurse into each child. Stop when a region is pure (or a depth/size limit hits). Predict with each leaf's majority class. Part (a) guarantees the score never gets worse as you grow — the interesting question the later parts probe is what “never worse” does and doesn't buy you for the loss you actually care about, $M$.
