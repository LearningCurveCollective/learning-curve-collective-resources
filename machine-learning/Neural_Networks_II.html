Formulas to know cold

Forward pass, one layer, a batch of $m$ examples

$$Z^{[l]} = W^{[l]}A^{[l-1]} + b^{[l]},\qquad A^{[l]} = g^{[l]}\big(Z^{[l]}\big)$$

Columns are examples. $W^{[l]}$ is $(n_l\times n_{l-1})$: a row per neuron, a column per input. $b^{[l]}$ is $(n_l\times1)$ and broadcasts across the batch. $A^{[0]} = X$ is $(n_0\times m)$.

Shape rule

$$(n_l\times n_{l-1})\,(n_{l-1}\times m) = (n_l\times m)$$

Inner dimensions must match; the batch dimension rides along on the right. Parameters per layer: $(n_{l-1}+1)\,n_l$.

Backprop, the five lines (column convention)

$$dZ^{[L]} = d\hat Y\odot g'(Z^{[L]})$$ $$dW^{[l]} = \tfrac1m\,dZ^{[l]}(A^{[l-1]})^\top,\qquad db^{[l]} = \tfrac1m\textstyle\sum_{\text{cols}}dZ^{[l]}$$ $$dA^{[l-1]} = (W^{[l]})^\top dZ^{[l]},\qquad dZ^{[l-1]} = dA^{[l-1]}\odot g'(Z^{[l-1]})$$

$dW$ has the shape of $W$; $dA$ and $dZ$ stay per-example $(n\times m)$. Elementwise derivatives always use $\odot$. A variable feeding two branches gets the sum of the branch gradients.

Output-layer shortcuts

$$\text{sigmoid + BCE, softmax + CE:}\quad dZ^{[L]} = \hat Y - Y$$ $$\text{identity + MSE:}\quad dZ^{[L]} = 2(\hat Y - Y)\ \ (\hat Y - Y \text{ with the } \tfrac12)$$

The $\sigma'$ or softmax Jacobian cancels against the log-loss. With squared loss on a sigmoid, the $\hat Y\odot(1-\hat Y)$ factor stays.

Activation derivatives

$$\sigma' = \sigma(1-\sigma)\le\tfrac14,\quad \tanh' = 1-\tanh^2\le1,\quad \text{ReLU}' = \mathbb{1}\{z>0\}$$

ReLU's slope is exactly $1$ on active units and $0$ on dead ones: no shrinking, no saturation, but a unit stuck at $z<0$ never learns. Leaky ReLU: slope $0.01$ instead of $0$.

Layer Jacobian and the ReLU mask

$$\frac{\partial h^{[l]}}{\partial h^{[l-1]}} = D^{[l]}W^{[l]},\qquad D^{[l]} = \text{Diag}\big(\mathbb{1}\{z^{[l]}>0\}\big)$$

Outer function on the left. $D$ zeroes the rows of $W$ belonging to dead neurons. Column gradients go back through $(D^{[l]}W^{[l]})^\top$.

Residual block

$$h^{[l]} = \text{ReLU}\big((I+W^{[l]})h^{[l-1]}\big)$$ $$\frac{\partial h^{[l]}}{\partial h^{[l-1]}} = D^{[l]}(I+W^{[l]})$$

Under small-norm init the product through $L$ blocks is $\approx I+\sum_l W^{[l]}$, so the gradient stays $\Theta(1)$ instead of $\rho^{L-1}$.

Convolution arithmetic

$$n_{\text{out}} = \Big\lfloor\frac{n+2p-f}{s}\Big\rfloor+1$$ $$\#\text{params} = f\cdot f\cdot n_C\cdot n_F + n_F$$

Same-size output at stride 1 needs $p = (f-1)/2$. Pooling uses the same size formula with $p=0$ and zero parameters. Stacking $k$ $3\times3$ convs sees a $(2k+1)\times(2k+1)$ patch.

Class-weighted BCE

$$L = \alpha\,y\log\hat y + \beta\,(1-y)\log(1-\hat y)$$ $$\frac{\partial L}{\partial z} = \alpha y(1-\hat y) - \beta(1-y)\hat y$$

With $\alpha=\beta=1$ this is $y-\hat y$ (so $dZ = \hat Y - Y$ on $J = -\frac1m\sum L$). Put the bigger weight on the rarer class.

Traps that cost points

  • Row vs. column of $W$. In matrix form a row of $W^{[1]}$ is one neuron's weights, i.e. the scalar sheet's $(w^{[1]}_{1,j}, w^{[1]}_{2,j})$. The from-to subscripts read transposed.
  • $WD$ instead of $DW$. The activation is the outer function, so its slope matrix goes on the left. Shapes only agree for square layers, so this is also a shape error.
  • Averaging $dA$ or $dZ$ over the batch. Only parameter gradients ($dW$, $db$) are summed over examples. Per-example quantities stay $(n\times m)$ until the next $dW$.
  • Forgetting the mask on the backward pass. ReLU's gradient is $dA\odot\mathbb{1}\{Z>0\}$, not $dA$. The mask is taken from the forward pass's $Z$, which is why forward caches $Z$.
  • Counting conv parameters from the input size. Weight sharing makes $f\cdot f\cdot n_C\cdot n_F + n_F$ independent of $H$, $W$, stride and padding. Those only set the output size.
  • Thinking $I+W$ means "$W$ is close to $I$." $W$ is small; the block is close to the identity because of the explicit $I$.
3

One-liners that earn the point

  • Forward multiplies by $W$; backward multiplies by $W^\top$. Everything else is elementwise.
  • $dW$ is the error signal times the input, transposed, averaged over the batch.
  • ReLU's Jacobian is a diagonal 0/1 mask; it switches rows of $W$ off.
  • A residual block learns a correction to the identity, so "do nothing" is the easiest thing it can learn.
  • A convolution is a fully connected layer whose weight matrix is sparse and shared; a fully connected layer is a convolution whose filter covers the whole input.
  • Stride and padding set output size; filter size, channels and filter count set the parameter count.

The same network, now as matrices

The first sheet wrote every weight by name: $z_j = w^{[1]}_{0,j} + w^{[1]}_{1,j}x_1 + w^{[1]}_{2,j}x_2$. Stack the three hidden neurons and the same network becomes one matrix product. Nothing about the computation changes; only the bookkeeping does, and the bookkeeping is what lets you run a thousand examples at once and write backprop in five lines.

Scalar form (sheet I)

$$z_j = w^{[1]}_{0,j} + w^{[1]}_{1,j}x_1 + w^{[1]}_{2,j}x_2,\quad h_j = \sigma(z_j)$$ $$u = w^{[2]}_0 + \textstyle\sum_j w^{[2]}_j h_j,\quad o = \sigma(u)$$

Matrix form (this sheet)

$$z^{[1]} = W^{[1]}x + b^{[1]},\quad a^{[1]} = g(z^{[1]})$$ $$z^{[2]} = W^{[2]}a^{[1]} + b^{[2]},\quad \hat y = \sigma(z^{[2]})$$

With the hand-picked weights from sheet I, the matrices are

$$W^{[1]} = \begin{bmatrix}1&0\\0&1\\-1&-1\end{bmatrix}_{3\times2},\quad b^{[1]} = \begin{bmatrix}-0.5\\-0.5\\3\end{bmatrix}_{3\times1},\quad W^{[2]} = \begin{bmatrix}2&2&2\end{bmatrix}_{1\times3},\quad b^{[2]} = \begin{bmatrix}-5\end{bmatrix}_{1\times1}.$$
Read the rows. Row $j$ of $W^{[1]}$ is neuron $h_j$'s weights, $(w^{[1]}_{1,j},\,w^{[1]}_{2,j})$. The scalar sheet's subscripts were "from, to"; in the matrix the row is "to" and the column is "from", so the indices read transposed. $W^{[l]}$ is always (neurons out $\times$ inputs in), which is what makes $W^{[l]}a^{[l-1]}$ have the right shape.

A batch of examples

Put examples side by side as the columns of $X\in\mathbb{R}^{2\times m}$. Then $Z^{[1]} = W^{[1]}X + b^{[1]}$ computes every example's $z$ at once: $(3\times2)(2\times m) = 3\times m$, and $b^{[1]}$ is added to every column (broadcasting). Pick a batch below and watch the shapes.

Convention check. CS230 (and this sheet) use columns-as-examples, so the layer is $W A + b$ and $W$ is (out $\times$ in). CS229, scikit-learn and PyTorch's nn.Linear use rows-as-examples: $X W^\top + b$ with $X\in\mathbb{R}^{m\times n}$. Same numbers, transposed layout. On an exam, copy the convention the question states and keep it to the end.

ReLU and the mask

$\text{ReLU}(z) = \max(0, z)$, applied entry by entry. Its derivative is a switch: $1$ where $z>0$, $0$ where $z<0$ (either value at exactly $0$). Three things follow.

  • No shrinking. An active unit passes gradient through with slope exactly $1$. A sigmoid passes at most $\tfrac14$, so ten sigmoid layers scale the gradient by at most $4^{-10}$; ten active ReLU layers scale it by $1$.
  • Sparsity. Roughly half the units are off for any given input, so each example uses its own sub-network.
  • Dead units. A unit whose $z$ is negative for every input has zero gradient forever. Leaky ReLU ($0.01z$ for $z<0$) keeps a trickle alive.

The Jacobian of a ReLU layer

For $h = \text{ReLU}(z)$, $z = Wh_{\text{prev}}$, the chain rule gives outer-function-first: $$\frac{\partial h}{\partial h_{\text{prev}}} = \underbrace{\frac{\partial\,\text{ReLU}(z)}{\partial z}}_{D = \text{Diag}(\mathbb{1}\{z>0\})}\cdot\underbrace{\frac{\partial z}{\partial h_{\text{prev}}}}_{W} = DW.$$ $D$ is diagonal with 0/1 entries, so $DW$ is $W$ with the dead neurons' rows zeroed. Pick a point and see which rows survive.

Compare with sigmoid. For a sigmoid layer the "mask" is $\text{Diag}(\sigma'(z)) = \text{Diag}(h\odot(1-h))$: every entry between $0$ and $\tfrac14$, none exactly $0$. Every row of $W$ survives but every row is shrunk. ReLU's mask is all-or-nothing, which is why the backward pass through ReLU is a copy-or-drop rather than a scaling.

Backprop in matrix form, step by step

Sheet I derived one weight's gradient as a five-link chain. In matrix form the whole layer's gradient is one line, and the whole network is five lines repeated. Here they run on a real batch: points A and D through the $2\to3\to1$ network with ReLU hidden units, a sigmoid output, and binary cross-entropy (labels $y=1$ inside the triangle, $y=0$ outside). Every matrix is printed with its shape.

$$Z^{[1]} = W^{[1]}X+b^{[1]},\qquad A^{[1]} = \text{ReLU}(Z^{[1]}),\qquad Z^{[2]} = W^{[2]}A^{[1]}+b^{[2]},\qquad \hat Y = \sigma(Z^{[2]})$$ $$J = -\tfrac1m\textstyle\sum\big[Y\log\hat Y + (1-Y)\log(1-\hat Y)\big]$$

What to notice

  • $dZ^{[2]} = \hat Y - Y$ is the sigmoid-plus-BCE cancellation from sheet I's Problem 1, now for a whole batch at once.
  • Every $dW$ is error $\times$ input$^\top$. $dW^{[2]} = \frac1m dZ^{[2]}(A^{[1]})^\top$ and $dW^{[1]} = \frac1m dZ^{[1]}X^\top$ have the same form; only which "input" changes.
  • The transpose flips the direction. Forward: $W^{[2]}A^{[1]}$ sends hidden to output. Backward: $(W^{[2]})^\top dZ^{[2]}$ sends the output error back to each hidden unit.
  • The mask kills dead units' gradients. In $dZ^{[1]} = dA^{[1]}\odot\mathbb{1}\{Z^{[1]}>0\}$, any row with $z\le0$ for an example gets $0$ for that example, and that example then contributes nothing to that row of $dW^{[1]}$.
  • Batch dimension. $dZ$ and $dA$ keep one column per example; $dW$ and $db$ sum (average) those columns away.
Exam form of this question. "Every line of this backward pass has a bug; fix it." The bug catalog on the Cheat Sheet lists the seven planted mistakes that appear: $\odot$ vs. np.dot, operand order, missing transpose, wrong sum axis, weight gradient instead of weight, branches multiplied instead of added, missing $\frac1m$. Run the shape check on every line.

Residual blocks

The problem residuals solve. Stacking more layers should never hurt a network on the training set, because the extra layers could learn to do nothing. In practice plain deep stacks got worse training loss (the degradation problem), because "do nothing" is hard for a layer $h = g(Wh_{\text{prev}})$ to learn: it needs $W$ to become an identity-like map through a nonlinearity. A residual block rewrites the layer so that doing nothing is the default.

$$\text{Plain:}\quad h^{[l]} = \text{ReLU}\big(W^{[l]}h^{[l-1]}\big)\qquad\qquad\text{Residual:}\quad h^{[l]} = \text{ReLU}\big(h^{[l-1]} + W^{[l]}h^{[l-1]}\big) = \text{ReLU}\big((I+W^{[l]})h^{[l-1]}\big)$$

If $W^{[l]}\to0$ the residual block outputs $\text{ReLU}(h^{[l-1]}) = h^{[l-1]}$ (the input is already nonnegative), so the identity costs nothing. The block learns the correction $W^{[l]}h^{[l-1]}$ to its input.

The Jacobian, and why gradients survive

Same chain rule as before, with $z^{[l]}_{\text{res}} = (I+W^{[l]})h^{[l-1]}$ and $D^{[l]} = \text{Diag}(\mathbb{1}\{z^{[l]}_{\text{res}}>0\})$: $$\frac{\partial h^{[l]}}{\partial h^{[l-1]}} = D^{[l]}(I+W^{[l]}) = D^{[l]} + D^{[l]}W^{[l]}.$$ Through $L$ blocks the gradient at $h^{[1]}$ is the product of these, transposed. With small-norm initialization $\|W^{[l]}\|_2\le\varepsilon$ and most gates open, $$\prod_{l=2}^{L}(I+W^{[l]}) \approx I + \sum_{l=2}^{L}W^{[l]} + O(\varepsilon^2 L),$$ a near-identity matrix. Compare the plain stack, whose product is bounded by $\rho^{L-1}$ with $\rho = \max_l\|D^{[l]}W^{[l]}\|_2$. The slider shows both bounds as depth grows.

Two things residuals do not do. They do not guarantee that deeper is better on test data (a 1202-layer ResNet overfit CIFAR-10 worse than a 110-layer one), and they do not rescue sigmoid as a hidden activation: $\sigma'\le\tfrac14$ still shrinks the non-identity path. ResNets use ReLU.

Convolutions: a sliding dot product

A convolutional layer slides a small kernel over the image. At each position it multiplies the kernel entry by entry with the patch underneath and sums the products: one output pixel. Every output pixel uses the same kernel, which is where the parameter savings come from, and each output pixel only sees its own patch, which is where the locality comes from. Step through it below.

The three things every conv question asks

QuantityFormula
Output size$n_{\text{out}} = \lfloor(n+2p-f)/s\rfloor+1$

Parameters$f\cdot f\cdot n_C\cdot n_F + n_F$
"Same" padding, stride 1$p = (f-1)/2$
Pooling ($k\times k$, stride $k$)$n\to\lfloor n/k\rfloor$, depth unchanged, 0 parameters
Receptive field of $k$ stacked $3\times3$$(2k+1)\times(2k+1)$
Conv and fully connected are the same operation. Flatten the image and a conv layer is a matrix $W_{\text{FC}}$ that is mostly zeros (each output sees only its patch) with repeated entries (the same kernel at every position). Conversely, a fully connected layer on an $8\times8\times32$ volume is a conv with a single $8\times8\times32$ filter per output unit: same $20{,}490$ parameters, output $1\times1\times10$. The FC-to-conv direction is what lets a classifier run as a sliding window over a bigger image in one pass.
Kernel reading traps. The identity kernel is a single $1$ in the center, not the identity matrix: diagonal ones sum three pixels along a diagonal, which blurs and brightens. Sobel-x (columns $[1,2,1]$ and $[-1,-2,-1]$) responds to left-right intensity change, which is a vertical edge; its transpose is the horizontal-edge detector. Try both on the two edge images above.
