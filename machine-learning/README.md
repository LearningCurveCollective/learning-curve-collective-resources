# Machine Learning Resources

This section contains machine learning and data science learning materials developed by Learning Curve Collective.

Topics may include:

- statistics and matrix calculus for ML  
- decision trees and neural networks, stepped through by hand  
- k-means clustering and image compression  
- semi-supervised learning with the EM algorithm  
- study guides tying the pieces together  
- a matrix calculus and linear algebra toolkit (chain rule order, spectral norm, Jacobians) with interactive explorers  
- Neural Networks II: the same small network as matrices, ReLU masks, backprop in matrix form, residual blocks, convolutions, and a drill generator  
- Reading Training Curves: a loss-plot playground, a diagnosis method, a name-the-cause drill, the nine-plot exam problem, and the vanishing-gradient bonus  
- a deep learning exam review: backprop, batch norm, regularization, residual blocks, CNN shape and parameter arithmetic, LoRA, plus full worked exam problems (chain-rule gradients, backprop by symbols and in code, vanishing gradients, matching ablations to loss plots)
