Order, transposes and shapes

Four rules

  1. Outer function on the left. $h = \text{ReLU}(Wx)\Rightarrow \partial h/\partial x = D\,W$. Same order as calculus, $f'(g(x))\,g'(x)$. Scalars hid this because they commute.
  2. A matrix acts on the vector to its right. Following a wiggle: $\Delta z = W\Delta x$, then $\Delta h = D\Delta z = (DW)\Delta x$. First step applied = rightmost factor.
  3. Transposing reverses order. $(XYZ)^\top = Z^\top Y^\top X^\top$. Row-vector gradients: loss on the left, no transposes. Column gradients: transposes everywhere, loss on the right. Never mix.
  4. Shape-check every product. $(a\times b)(b\times c) = a\times c$; the inner dimension cancels. A gradient has the shape of the thing you differentiate with respect to.

Backprop in both conventions

$$\text{row:}\quad \frac{\partial\mathcal{L}}{\partial h^{[1]}} = \delta\,W^{[L+1]}\,(D^{[L]}W^{[L]})\cdots(D^{[2]}W^{[2]})$$ $$\text{column:}\quad \frac{\partial\mathcal{L}}{\partial h^{[1]}} = (D^{[2]}W^{[2]})^\top\cdots(D^{[L]}W^{[L]})^\top(W^{[L+1]})^\top\delta^\top$$

The row product counts down ($L\to2$); the column product counts up ($2\to L$). Both read "start at the loss." Compute right to left: every step is matrix × vector, which is cheap.

Scalar by matrix: the left/right law

$$f = u^\top A\,v\quad\Longrightarrow\quad \nabla_A f = u\,v^\top\qquad(\text{same shape as } A)$$

Whatever multiplies the variable from the left becomes the column; whatever multiplies from the right becomes the row. A transpose on the variable swaps the sides ($u^\top A^\top v \Rightarrow v\,u^\top$). The neighbor is everything grouped on that side, not just the adjacent symbol. Backprop forms are this law with the upstream gradient as $u$: for $z = Wx$, $\nabla_W\mathcal{L} = \delta\,x^\top$.

The rules, ranked by reliability

  1. Shape test (never fails): gradient shape = variable shape; Jacobian = outputs × inputs; inner dimensions must click. Wrong layouts refuse to multiply.
  2. Left/right law (fast, matrix variables): $u^\top Av\Rightarrow uv^\top$.
  3. Vector-variable law (fast): $\partial(Aw)/\partial w = A$; $\nabla_w w^\top Aw = (A+A^\top)w$; linear scalars give the other factor as a column.
  4. Ground truth (when anything feels off): $f(A+\Delta)-f(A)\approx\langle\text{derivative},\Delta\rangle$, computed entrywise.

The norm ladder

ObjectNormFormulaMeaning
Number $x$absolute value$|x| = \sqrt{x^2}$size
Vector $v$Euclidean (2-norm)$\|v\|_2 = \sqrt{\sum_i v_i^2}$length of the arrow
Matrix $A$Frobenius$\|A\|_F = \sqrt{\sum_{i,j}A_{ij}^2}$"how big are the entries" (regularization)
Matrix $A$spectral (operator 2-norm)$\|A\|_2 = \max_{\|v\|=1}\|Av\| = \sqrt{\lambda_{\max}(A^\top A)} = \sigma_{\max}(A)$"how much can it stretch a vector" (gradient flow)

Every vector obeys the max

$$\|Av\|\le\|A\|_2\,\|v\|$$

Split $v = \|v\|\,u$ with $\|u\|=1$; $u$ is one candidate in the max. Equality only for $v=0$ or $v$ along the top eigenvector of $A^\top A$.

Stretches multiply

$$\|AB\|_2\le\|A\|_2\,\|B\|_2$$

Apply the previous line twice. Holds for any matrices; nothing needs to be symmetric or square.

Square first

$$\|Av\|^2 = v^\top(A^\top A)v$$

$A^\top A$ is symmetric with eigenvalues $\sigma_i^2\ge0$. Its top eigenvector is $A$'s max-stretch direction (not necessarily an eigenvector of $A$).

Budget picture

$$\|Av\|^2 = \sum_i c_i^2\sigma_i^2,\qquad \sum_i c_i^2 = 1$$

A unit vector splits a budget of 1 across the eigen-axes; squared stretch is the weighted average of the $\sigma_i^2$. Spend it all on the top axis to maximize.

Spectral theorem

$$A^\top A = Q\Lambda Q^\top$$

Rotate into eigen-axes ($Q^\top$), scale each axis ($\Lambda$), rotate back ($Q$). Length changes only in the middle step.

Power iteration

$$v_{k+1} = \frac{Av_k}{\|Av_k\|}$$

$A^kv_0 = \sum_i c_i\lambda_i^kq_i$: the top piece outgrows the rest by $|\lambda_1/\lambda_2|$ per step. Normalize or the length blows up / vanishes like $|\lambda_1|^k$.

Mask norm

$$D = \text{Diag}(0/1)\ \Rightarrow\ \|D\|_2\le1$$

Keeps or deletes coordinates (a projection); deleting can only shorten. Columns are standard unit vectors or zero.

Jacobian determinant

$$dx\,dy = |\det J|\,dr\,d\theta,\quad \det J_{\text{polar}} = r$$

$|\det J|$ = area scale of a tiny cell. Calculus uses the determinant; backprop uses the matrix itself.

The rules, ranked by reliability

1. Shape test (never fails)
Gradient shape = variable shape (scalar case) or outputs × inputs (Jacobian). Insert the unique transposes that make every product compose. The self-enforcing rule: wrong layouts refuse to multiply.
2. Left/right law (fast, matrix variables)
$u^\top Av\Rightarrow uv^\top$. Left neighbor → column, right neighbor → row. Transpose on the variable swaps sides. Neighbor = everything grouped on that side.
3. Vector-variable law (fast)
$\dfrac{\partial(Aw)}{\partial w} = A$, $\ \nabla_w\,w^\top Aw = (A+A^\top)w$. Coefficients as-is; quadratic forms symmetrize; linear scalars give the other factor as a column.
4. Ground truth (when anything feels off)
$f(A+\Delta)-f(A)\approx\langle\text{derivative},\Delta\rangle$. Entrywise partials plus first-order perturbation: the raw facts the other rules compress.

Conventions: what is a row, what is a column, what shape is a gradient

Bare vectors are columns. $w\in\mathbb{R}^{d\times1}$, $Xw\in\mathbb{R}^{b\times1}$, $Y\in\mathbb{R}^{b\times1}$. A row is always marked explicitly with a transpose: $v^\top$ is the row version of the column $v$. When you compute $Xw$ by matrix multiplication, the object you produce is a column; that is its birth format.

3

The translation table, derived

Linear: $\nabla_x(a^\top x) = a$

Derivation

$a^\top x = \sum_i a_ix_i$. Differentiate with respect to one coordinate $x_j$: every term except $i=j$ is constant, so $\partial/\partial x_j = a_j$. Stack the $d$ answers into a column: $\nabla_x(a^\top x) = a$. Same for $x^\top a$ (a number equals its transpose).

Matrix version. $\dfrac{\partial(Ax)}{\partial x} = A$: entry $i$ of $Ax$ is $\sum_j A_{ij}x_j$, so $\partial(Ax)_i/\partial x_j = A_{ij}$, which is exactly the matrix $A$ laid out as rows = outputs, columns = inputs. This is the "$\times W$" arrow of every layer.

Quadratic: $\nabla_x(x^\top Ax) = (A+A^\top)x$

Derivation

$x^\top Ax = \sum_i\sum_k x_iA_{ik}x_k$. Each $x_j$ appears twice: once as the row index ($i=j$) and once as the column index ($k=j$). Product rule on the double sum:

$$\frac{\partial}{\partial x_j}\sum_{i,k}x_iA_{ik}x_k = \underbrace{\sum_k A_{jk}x_k}_{(Ax)_j} + \underbrace{\sum_i x_iA_{ij}}_{(A^\top x)_j}\quad\Longrightarrow\quad \nabla_x(x^\top Ax) = Ax + A^\top x = (A+A^\top)x$$

If $A$ is symmetric this is $2Ax$, the matrix twin of $\frac{d}{dx}ax^2 = 2ax$. Special case $A = I$: $\nabla_x(x^\top x) = 2x$, which is where $\nabla_w\frac\lambda2\|w\|^2 = \lambda w$ comes from.

Worked example

$A = \begin{bmatrix}2&1\\0&3\end{bmatrix}$, $x = \begin{bmatrix}1\\2\end{bmatrix}$. Expand: $x^\top Ax = 2x_1^2 + x_1x_2 + 3x_2^2 = 2+2+12 = 16$. Gradient by hand: $(4x_1+x_2,\ x_1+6x_2) = (6, 13)$. Formula: $(A+A^\top)x = \begin{bmatrix}4&1\\1&6\end{bmatrix}\begin{bmatrix}1\\2\end{bmatrix} = \begin{bmatrix}6\\13\end{bmatrix}$ ✓. Using $2Ax$ would give $(8,12)$, wrong because $A$ is not symmetric.

Derivation (chain rule)

Let $r = Ax-b$ (the residual, $m\times1$). Then $\|Ax-b\|^2 = r^\top r$ and $\nabla_r(r^\top r) = 2r$ by the quadratic rule.

2

$\partial r/\partial x = A$ by the linear rule (an $m\times d$ Jacobian).

Chain rule for a scalar through a vector: $\nabla_x = (\partial r/\partial x)^\top\nabla_r = A^\top(2r)$. The transpose appears because we want a $d\times1$ column: $(d\times m)(m\times1)$.

$$\nabla_x\|Ax-b\|^2 = 2A^\top(Ax-b)\qquad\text{set to }0:\quad A^\top Ax = A^\top b\quad(\text{normal equations})$$

Same skeleton as a linear layer: $\nabla_W\mathcal{L} = \delta\,x^\top$ where $\delta = \nabla_z\mathcal{L}$ and $z = Wx$. Derivation: $z_k = \sum_jW_{kj}x_j$ so $W_{kj}$ appears only in $z_k$, $\partial z_k/\partial W_{kj} = x_j$, and $\partial\mathcal{L}/\partial W_{kj} = \delta_kx_j$, an outer product.

Elementwise functions: diagonal Jacobians

If $\phi$ acts entry by entry, $h_i = \phi(z_i)$ depends only on $z_i$, so $\partial h_i/\partial z_j = \phi'(z_i)$ when $i=j$ and $0$ otherwise. The Jacobian is $\text{Diag}(\phi'(z))$. For ReLU, $\phi'(z) = \mathbb{1}\{z\gt0\}$, giving the mask $D$. For sigmoid, $\text{Diag}(\sigma(z)(1-\sigma(z)))$. Softmax is not elementwise (every output uses every input), which is why its Jacobian has off-diagonal entries $-f_if_k$.

Scalar by matrix: the left/right law

The master template for scalar-by-matrix gradients. Fixed vectors for the widget: $u = (1,2,-1)^\top$ on the left of $E$, $v = (3,1,2)^\top$ on the right. The left neighbor $u$ slides in as the column skeleton of the gradient, the right neighbor $v$ rotates in as the row skeleton, and each cell fills with the product $u_jv_k$. Toggle to $u^\top E^\top v$ to watch the transpose on the variable swap the sides: the gradient becomes $vu^\top$.

$$f = u^\top E\,v = \sum_{j,k}u_jE_{jk}v_k\quad\Longrightarrow\quad\frac{\partial f}{\partial E_{jk}} = u_jv_k\quad\Longrightarrow\quad\nabla_Ef = u\,v^\top$$

Derivation in one line: $E_{jk}$ appears in exactly one term of the double sum, with coefficient $u_jv_k$. Filing those coefficients into an $E$-shaped grid puts $u$ down the rows and $v$ across the columns, which is the outer product.

The filing machine: $\nabla_EY_i$ for $Y = E(Xw)$

Running example with every number fixed:

$$E = \begin{pmatrix}1&1&0\\1&0&1\\0&1&1\end{pmatrix},\quad X = \begin{pmatrix}1&2\\0&1\\3&-1\end{pmatrix},\quad w = \begin{pmatrix}2\\1\end{pmatrix}\;\Longrightarrow\;v = Xw = \begin{pmatrix}4\\1\\5\end{pmatrix},\quad Y = Ev = \begin{pmatrix}5\\9\\6\end{pmatrix}$$

Form the intermediate column. By definition of matrix-vector multiplication ($3\times2$ times $2\times1$ gives $3\times1$):

$$v = Xw = \begin{pmatrix}X_{11}w_1+X_{12}w_2\\X_{21}w_1+X_{22}w_2\\X_{31}w_1+X_{32}w_2\end{pmatrix} =: \begin{pmatrix}v_1\\v_2\\v_3\end{pmatrix}\quad\text{a column, as computed.}$$
2

Write one output entrywise. Row $i$ of $E$ dots the column $v$:

$$Y_i = \sum_{k=1}^{3}E_{ik}v_k = E_{i1}v_1+E_{i2}v_2+E_{i3}v_3.$$

Only row $i$'s entries of $E$ appear, so $Y_i$ cannot depend on the other rows.

3

Read off every partial derivative, one entry at a time with all others held fixed:

$$\frac{\partial Y_i}{\partial E_{ik}} = v_k\quad(k = 1,2,3),\qquad\frac{\partial Y_i}{\partial E_{jk}} = 0\ \text{ for } j\ne i.$$

These numbers are the sensitivity object: nudge $E_{ik}$ by $\epsilon$ and $Y_i$ moves by $\epsilon\,v_k$. As a set of numbers they are neither row nor column yet; they are indexed by which knob you poked.

4

File into an $E$-shaped grid. By the scalar-by-matrix convention, slot $(j,k)$ holds $\partial Y_i/\partial E_{jk}$. Shown for $i = 1$:

$$\nabla_EY_1 = \begin{pmatrix}v_1&v_2&v_3\\0&0&0\\0&0&0\end{pmatrix} = e_1v^\top.$$

The values landed horizontally, not by choice, but because the knobs they measure ($E_{11},E_{12},E_{13}$) occupy row 1 of $E$. Sensitivities live where the knobs are. A column's worth of numbers laid into a horizontal strip is that column transposed.

$$\boxed{\nabla_EY_i = e_i\,(Xw)^\top}\qquad\text{row } i \text{ holds } (Xw)^\top,\text{ zeros elsewhere. Shorthand: } \frac{\partial Y}{\partial E} = (Xw)^\top.$$
Column-born, row-filed. In $Ev$, the row of $E$ sweeps across the column $v$; each horizontally placed knob $E_{ik}$ gets multiplied by the matching $v_k$. The knobs are strung horizontally, so the sensitivities are written horizontally. The transpose is the re-filing, not a property of $Xw$ itself.

The perturbation identity: convention-free ground truth

When any layout question feels ambiguous, drop to first principles. Perturb the whole matrix, $E\to E+\Delta$, for an arbitrary small $3\times3$ matrix $\Delta$. By linearity of matrix multiplication:

$$Y(E+\Delta)-Y(E) = (E+\Delta)v-Ev = \Delta v$$

The change in $Y$ is exactly linear in $\Delta$, with coefficient object $v = Xw$. That linear map $\Delta\mapsto\Delta v$ is the derivative; no convention needed. Reading off row $i$: the change in $Y_i$ is $\sum_k\Delta_{ik}v_k$, whose coefficient on $\Delta_{ik}$ is $v_k$, matching step 3 of the derivation exactly.

Three-step protocol that never lies. (1) Compute the sensitivity object entrywise, or by expanding $f(A+\Delta)-f(A)$ to first order. (2) Determine the required shape from the convention (variable's shape for scalar gradients; outputs × inputs for Jacobians). (3) Transpose or arrange the sensitivity object to fit that shape. The transposes appear here, mechanically, at filing time.

Contrast: $\partial Y/\partial w = EX$ needs no transpose

Group the same model as $Y = (EX)w$ and set $A = EX\in\mathbb{R}^{3\times2}$. Entrywise:

$$Y_i = \sum_{k=1}^{2}A_{ik}w_k\;\Longrightarrow\;\frac{\partial Y_i}{\partial w_k} = A_{ik}\;\Longrightarrow\;\frac{\partial Y}{\partial w} = A = EX\in\mathbb{R}^{3\times2}$$

Here the Jacobian's filing grid is indexed (output $i$, input $k$) and the coefficient formula is already indexed $(i,k)$. Grid indices match formula indices, so the entries drop straight in. Transposes only appeared in the $E$-derivative because there the variable was the matrix, and the sensitivities had to be re-filed into its shape. Side by side: with respect to $w$, the coefficient matrix $EX$ files directly as the Jacobian; with respect to $E$, each output reads one row of $E$, so the column $Xw$ gets filed sideways into that row as $(Xw)^\top$.

The chain rule with matrices

$$y = f(g(x))\quad\Longrightarrow\quad J_y = J_f\big(g(x)\big)\;J_g(x)\qquad\text{outer function on the left, same as } f'(g(x))\,g'(x)$$

Why this order. Follow a small input change: $\Delta g = J_g\Delta x$, then $\Delta y = J_f\Delta g = J_f(J_g\Delta x) = (J_fJ_g)\Delta x$. A matrix multiplies the vector to its right, so the first map applied is the rightmost factor. In $f(g(x))$, $g$ is written on the right and happens first; the notation already agrees.

Worked example: one ReLU layer

$h = \text{ReLU}(Wx)$, $W = \begin{bmatrix}2&-1\\1&3\end{bmatrix}$, $x = \begin{bmatrix}1\\-2\end{bmatrix}$. Inner: $z = Wx = \begin{bmatrix}4\\-5\end{bmatrix}$, Jacobian $W$. Outer: ReLU at $z$, Jacobian $D = \text{Diag}(1,0)$.

$$J_h = D\,W = \begin{bmatrix}1&0\\0&0\end{bmatrix}\begin{bmatrix}2&-1\\1&3\end{bmatrix} = \begin{bmatrix}2&-1\\0&0\end{bmatrix}\qquad\text{vs. wrong order}\quad WD = \begin{bmatrix}2&0\\1&0\end{bmatrix}$$

$DW$ zeroes row 2: output 2 is dead and cannot move. $WD$ zeroes column 2: it would claim input 2 affects nothing, but nudging $x_2$ by $+0.1$ moves $z_1$ by $-0.1$ and so moves output 1. Numbers settle the order.

Worked example: a sum over paths (softmax)

With $\mathcal{L} = -\sum_iy_i\log f_i$ and $f = \text{softmax}(z)$, each $z_k$ influences every $f_i$, so

$$\frac{\partial\mathcal{L}}{\partial z_k} = \sum_i\frac{\partial\mathcal{L}}{\partial f_i}\frac{\partial f_i}{\partial z_k} = \sum_i\Big(-\frac{y_i}{f_i}\Big)f_i(\delta_{ik}-f_k) = -y_k+f_k\sum_iy_i = f_k-y_k$$

Dropping the $i\ne k$ terms gives $-y_k(1-f_k)$, which is $0$ for every wrong class, so wrong classes would never be pushed down. In matrix language, $\nabla_z\mathcal{L} = J_f^\top\nabla_f\mathcal{L}$: the transpose of the Jacobian carries a gradient backward.

Backprop is the chain rule read outer-to-inner

Take a network with two layers and a loss, $L = \ell\big(\sigma(W\,\varphi(Vx))\big)$. Written as a formula, the last operation applied, $\ell$, is the outermost symbol and sits furthest left. Written as a network, that same $\ell$ sits furthest right, at the output. The chain rule differentiates the outermost function first, so its product lists the factors in nesting order, outer to inner, which is the network read from the output back to the input. That is all backprop is: the chain-rule product evaluated one factor at a time, right to left through the diagram.

Three orders, one picture. The top row is the network; the forward pass runs left to right. The middle row is the same computation written as nested parentheses, outermost ring first. The bottom row is the chain-rule product in row form. Follow any color: box $\to$ ring is a crossing line (the network order and the nesting order are reverses of each other), ring $\to$ chip is a straight line (the chain-rule order is the nesting order). The numbered badges say it without the lines: $1\to5$ reads right to left on the network and left to right everywhere else.

$$\frac{\partial L}{\partial x} = \underbrace{\ell'}_{1\times n_2}\;\underbrace{\sigma'}_{n_2\times n_2}\;\underbrace{W}_{n_2\times n_1}\;\underbrace{\varphi'}_{n_1\times n_1}\;\underbrace{V}_{n_1\times d}\qquad\text{outer function on the left; each inner dimension cancels with the next}$$

Here $\ell'$ is the $1\times n_2$ row of partials of the loss with respect to its argument, $\sigma'$ and $\varphi'$ are the diagonal Jacobians of the elementwise activations (the 0/1 mask $D$ for ReLU), and $W$, $V$ are their own Jacobians. The column convention is the same product transposed once: $\nabla_xL = V^\top\varphi'\,W^\top\sigma'\,\ell'^{\,\top}$, which reverses the order and puts a transpose on every factor (section 4).

The bridge is one identity: $(XYZ)^\top = Z^\top Y^\top X^\top$. Transposing the entire row product once gives the column product, and that single transpose is what flips the order and adds a $\top$ to every factor. It is not true that $XY = Y^\top X^\top$; the two sides hold the same numbers in different layouts.

Reversing the product index. $\prod_{l=2}^{L}M_l$ conventionally lists $M_2$ first. When shapes demand $M_L$ first, either write the factors out, $M_LM_{L-1}\cdots M_2$, or write $\prod_{l=L}^{2}$ with a note that $l$ decreases. Product notation records which factors appear; the page order is yours to specify.

The spectral norm: maximum stretch

Definition. Feed every nonzero vector through $A$ and record the largest stretch ratio. Because scaling $v$ by $c$ scales both $\|Av\|$ and $\|v\|$ by $|c|$, the ratio depends only on direction, so unit vectors suffice:

$$\|A\|_2 = \max_{v\ne0}\frac{\|Av\|}{\|v\|} = \max_{\|v\|=1}\|Av\| = \sqrt{\lambda_{\max}(A^\top A)} = \sigma_{\max}(A)$$

The first two are definitions (same idea, magnitude cancelled). The last two are how you compute it and what it's called. $v$ is any test direction you are free to try; $\|A\|_2$ is the winner's stretch.

Worked example

$A = \text{diag}(3, 0.5)$: $v=(1,0)\to(3,0)$, stretch $3$; $v=(0,1)\to(0,0.5)$, stretch $0.5$; $v = \frac{1}{\sqrt2}(1,1)\to\frac{1}{\sqrt2}(3,0.5)$, stretch $\sqrt{(9+0.25)/2}\approx2.1506$. The max over all directions is $3$, at $v=(1,0)$.

Lemma: $\|Av\|\le\|A\|_2\,\|v\|$ for every $v$

Equality holds only when $v = 0$ or $v$ points along an eigenvector of $A^\top A$ for its largest eigenvalue. Other eigenvectors give strict inequality: for $\text{diag}(3,0.5)$, $v=(0,1)$ is an eigenvector of $A^\top A$ but $\|Av\| = 0.5\lt3$.

Lemma: $\|AB\|_2\le\|A\|_2\,\|B\|_2$ (stretches multiply)

Take any unit $u$. Apply the first lemma twice, once with $v = Bu$ (not a unit vector, which is why the lemma had to work for any $v$) and once with $v = u$:

$$\|ABu\| = \|A(Bu)\|\le\|A\|_2\,\|Bu\|\le\|A\|_2\,\|B\|_2\,\|u\| = \|A\|_2\,\|B\|_2$$

Every candidate in the max defining $\|AB\|_2$ is at most $\|A\|_2\|B\|_2$, so the max is too. No symmetry or squareness was used; the "unit vectors" live inside every $\|\cdot\|_2$.

The ReLU mask. $D = \text{Diag}(m)$ with $m_i\in\{0,1\}$ has columns that are standard unit vectors or zero: it keeps some coordinates and deletes the rest (a projection). $\|Dv\|^2 = \sum_im_i^2v_i^2\le\sum_iv_i^2$, so $\|D\|_2\le1$, hence $\|DW\|_2\le\|W\|_2$. Chain $L-1$ such factors and you get the vanishing-gradient bound $\le\rho^{L-1}$.

3

Which direction stretches most? Square first.

Length squared avoids the square root and reveals a symmetric matrix:

$$\|Av\|^2 = (Av)^\top(Av) = v^\top\big(A^\top A\big)v\qquad\text{for every } v$$

So maximizing $\|Av\|$ over unit vectors is the same as maximizing the quadratic form $v^\top(A^\top A)v$, and $A^\top A$ is always symmetric with eigenvalues $\ge0$. The winner is the top eigenvector of $A^\top A$, and the max value is $\sqrt{\lambda_{\max}(A^\top A)}$.

  1. Compute $A^\top A$.
  2. Find its largest eigenvalue $\lambda_{\max}$ (and eigenvector $v$ if the direction is needed).
  3. $\|A\|_2 = \sqrt{\lambda_{\max}}$. Check by running $v$ through $A$: $\|Av\| = \sqrt{v^\top A^\top Av} = \sqrt{\lambda_{\max}}$.
Worked example: a shear, where eigenvectors of $A$ mislead

$A = \begin{bmatrix}1&10\\0&1\end{bmatrix}$ has the single eigenvalue $1$ with eigenvector $(1,0)$, stretched by $1$. But $v=(0,1)\mapsto(10,1)$ has length $\sqrt{101}\approx10.0499$. Eigenvalues of $A$ badly underestimate the stretch.

$$A^\top A = \begin{bmatrix}1&10\\10&101\end{bmatrix},\quad \lambda^2-102\lambda+1 = 0\ \Rightarrow\ \lambda\approx101.9902,\ 0.0098,\qquad \|A\|_2 = \sqrt{101.9902}\approx10.0990$$

Top eigenvector $v\approx(0.0985, 0.9951)$, nearly straight up, and $\|Av\|\approx10.099$ ✓. The max-stretch direction is an eigenvector of $A^\top A$, not of $A$.

Why symmetry fixes it. A symmetric matrix $M$ has perpendicular eigenvectors $q_1,\ldots,q_n$ (spectral theorem). Write a unit $v = \sum_ic_iq_i$ with $\sum_ic_i^2 = 1$. Applying $M$ scales each piece by its $\lambda_i$, and because the axes are perpendicular, Pythagoras adds the squared lengths:

$$\|Mv\|^2 = \sum_i\lambda_i^2c_i^2\le\lambda_{\max}^2\sum_ic_i^2 = \lambda_{\max}^2$$

A weighted average of the $\lambda_i^2$ with weights $c_i^2$ summing to 1: maximized by putting the whole budget on the top axis. Non-symmetric matrices break this because their eigenvectors are not perpendicular (or don't exist in full), so $M$ also shears and Pythagoras fails. Negative eigenvalues are not penalized: $Mv = -5v$ still has length $5\|v\|$. For symmetric $A$, $A^\top A = A^2$ with eigenvalues $\lambda_i^2$, so the recipe returns $|\lambda_i|$ as it should.

What a Jacobian is

For a map from vectors to vectors, the Jacobian is the first derivative: a matrix with rows indexed by outputs and columns by inputs, entry $J_{ij} = \partial(\text{out}_i)/\partial(\text{in}_j)$. Its meaning in one line:

$$\Delta(\text{output})\approx J\,\Delta(\text{input})\qquad\text{zoom in far enough and any smooth map is multiplication by } J$$

The columns of $J$ say where each input direction gets sent. Column $j$ is the image of a tiny step along input $j$. A tiny square in input space (sides along inputs 1 and 2) maps to a tiny parallelogram whose edges are columns 1 and 2 of $J$. Everything below follows from that picture.

Worked example: polar to Cartesian

Givens. Inputs $(r,\theta)$, outputs $x = r\cos\theta$, $y = r\sin\theta$.

1

Column 1: wiggle $r$ only (step outward).

$$\frac{\partial(x,y)}{\partial r} = \begin{bmatrix}\cos\theta\\\sin\theta\end{bmatrix},\qquad\text{length } \sqrt{\cos^2\theta+\sin^2\theta} = 1$$

A step $\Delta r$ outward keeps its length: no stretch.

2

Column 2: wiggle $\theta$ only (step around the circle).

$$\frac{\partial(x,y)}{\partial\theta} = \begin{bmatrix}-r\sin\theta\\r\cos\theta\end{bmatrix},\qquad\text{length } \sqrt{r^2\sin^2\theta+r^2\cos^2\theta} = r$$

A step $\Delta\theta$ becomes an arc of length $r\,\Delta\theta$: stretched by $r$.

3

Together. The two columns are perpendicular (dot product $-r\cos\theta\sin\theta+r\sin\theta\cos\theta = 0$), so the tiny cell becomes a rectangle with sides $1\cdot\Delta r$ and $r\cdot\Delta\theta$. In general the parallelogram's area is $|\det J|$, here $1\cdot r\cdot\sin90^\circ = r$:

$$\det J = r\cos^2\theta + r\sin^2\theta = r\qquad\Longrightarrow\qquad dx\,dy = r\,dr\,d\theta$$

Why the cells have different areas. Every input block has the same $\Delta r\times\Delta\theta$, but its image is a piece of a ring: thickness $\Delta r$ everywhere, arc length $r\Delta\theta$ growing with $r$. Pizza slices: equal angles, wider at the crust. This variation is real, and it is exactly what $\det J = r$ measures. The exact ring-piece area, $\frac{r_2^2-r_1^2}{2}\Delta\theta = r_{\text{mid}}\Delta r\Delta\theta$, matches $\det J$ at the cell's center.

Where the approximation lives. $J$ treats the cell as a flat parallelogram; the true image has curved edges. The mismatch depends on the cell's size, not its location, and vanishes as the cell shrinks, which is why calculus uses infinitesimal $dr\,d\theta$. Note the reverse map $(x,y)\mapsto(r,\theta)$ has derivatives like $\partial(r^2)/\partial x = 2x$; its Jacobian is the inverse of this one, with determinant $1/r$.

Wiggle $x_2\to1.1$: $z_1 = 1+2.2 = 3.2$, so $h_1$ rises by $0.2 = 2\times0.1$ ✓ (entry $(1,2) = 2$). $z_2 = -3+1.1 = -1.9\lt0$, $h_2$ stays $0$ ✓ (row 2 zero).

4

Fix the convention. A student writes $\dfrac{\partial\mathcal{L}}{\partial h^{[1]}} = (\hat y-y)\,W^{[L+1]}\prod_{l=2}^{L}(D^{[l]}W^{[l]})^\top$. Identify the error and give two correct versions.

transposes reverse order

Row order (loss on the left) is mixed with column-style transposes, and the shapes don't chain: $W^{[L+1]}$ is $1\times n_L$ but $(D^{[2]}W^{[2]})^\top$ is $n_1\times n_2$.

Row form: $(\hat y-y)\,W^{[L+1]}(D^{[L]}W^{[L]})\cdots(D^{[2]}W^{[2]})$, shape $1\times n_1$, counting down.

Column form: $(D^{[2]}W^{[2]})^\top\cdots(D^{[L]}W^{[L]})^\top(W^{[L+1]})^\top(\hat y-y)$, shape $n_1\times1$. One is the transpose of the other.

5

Spectral norm by hand. $A = \begin{bmatrix}2&0\\0&-5\end{bmatrix}$. Find $\|A\|_2$, $\|A\|_F$, the max-stretch direction, and confirm $\|Av\|\le\|A\|_2\|v\|$ for $v = (3,4)^\top$.

square first

$A^\top A = \text{diag}(4,25)$, $\lambda_{\max} = 25$, so $\|A\|_2 = 5$ (the negative sign does not matter: lengths only). Direction: $(0,1)$. $\|A\|_F = \sqrt{4+25} = \sqrt{29}\approx5.3852\ge5$ ✓.

$Av = (6,-20)^\top$, $\|Av\| = \sqrt{436}\approx20.8806$; bound $5\cdot5 = 25$. $20.8806\le25$ ✓, strict because $v$ is not along $(0,1)$.

6

Shear. $A = \begin{bmatrix}1&2\\0&1\end{bmatrix}$. Show the eigenvalues of $A$ underestimate its stretch, then compute $\|A\|_2$.

eigenvectors of AᵀA, not A

$A$ has eigenvalue $1$ (twice), eigenvector $(1,0)$ only. But $A(0,1)^\top = (2,1)^\top$ has length $\sqrt5\approx2.2361\gt1$.

$A^\top A = \begin{bmatrix}1&2\\2&5\end{bmatrix}$; $\lambda^2-6\lambda+1 = 0$, $\lambda = 3\pm2\sqrt2$, so $\lambda_{\max} = 3+2\sqrt2\approx5.8284$ and $\|A\|_2 = \sqrt{5.8284}\approx2.4142 = 1+\sqrt2$.

7

Budget. $M = \text{diag}(4,1)$, unit input at $60^\circ$ from the $x$-axis. Compute the budget split, $\|Mv\|^2$ as a weighted average, and the output angle.

weighted average of λ²

$v = (\cos60^\circ,\sin60^\circ) = (0.5, 0.8660)$, budget $c_1^2 = 0.25$, $c_2^2 = 0.75$.

$\|Mv\|^2 = 0.25\cdot16 + 0.75\cdot1 = 4.75$, $\|Mv\| = 2.1794$, between $1$ and $4$.

8

Power iteration. $M = \text{diag}(2,-0.5)$, $v_0 = (1,1)/\sqrt2$. Give $v_1$, $v_2$ (normalized) and the angle after 5 steps. What happens to the sign of the second coordinate?

top piece wins by |λ₁/λ₂| per step

$M^kv_0\propto(2^k, (-0.5)^k)$. $k=1$: $(2,-0.5)\to(0.9701,-0.2425)$. $k=2$: $(4,0.25)\to(0.9981,0.0624)$. $k=5$: $(32,-0.03125)$, angle $\approx-0.056^\circ$.

The second coordinate shrinks by $|{-0.5}/2| = 1/4$ each step and alternates sign (negative $\lambda_2$). The direction converges to $(1,0)$, the top eigenvector.

9

Jacobian determinant. $(u,v)\mapsto(x,y) = (u^2-v^2,\ 2uv)$. Find $J$, $\det J$, and the area scale at $(u,v) = (1,2)$.

columns = images of input directions

$J = \begin{bmatrix}\partial x/\partial u&\partial x/\partial v\\\partial y/\partial u&\partial y/\partial v\end{bmatrix} = \begin{bmatrix}2u&-2v\\2v&2u\end{bmatrix}$.

$\det J = 4u^2+4v^2 = 4(u^2+v^2)$. At $(1,2)$: $4\cdot5 = 20$. A tiny cell near $(1,2)$ has its area multiplied by 20; $dx\,dy = 4(u^2+v^2)\,du\,dv$.

10

Bound a deep product. Each of 30 layers has $\|W^{[l]}\|_2\le0.8$ and ReLU gates. Bound the stretch of the gradient reaching layer 1 relative to the top. Then redo it with residual blocks and $\|W^{[l]}\|_2\le0.02$.

stretches multiply

Plain: $\prod\|D^{[l]}W^{[l]}\|_2\le0.8^{29}\approx0.0015$. About 0.15% of the signal survives.

Residual: each factor $D(I+W)$ stretches between $0.98$ and $1.02$ (triangle inequality), so the product is at least $0.98^{29}\approx0.5566$ and at most $1.02^{29}\approx1.7758$. Order 1 either way.

11

Sum over paths. $f = \text{softmax}(z)$ with $z = (2,0,-1)$ and true class 1. Compute $\nabla_z\mathcal{L}$ numerically and check that the entries sum to 0.

f − y

$e^z = (7.3891, 1, 0.3679)$, sum $8.7570$, so $f = (0.8438, 0.1142, 0.0420)$.

$\nabla_z\mathcal{L} = f-y = (-0.1562, 0.1142, 0.0420)$. Sum $= 0$ because $\sum f_i = 1 = \sum y_i$. The correct class is pushed up, the wrong ones down.

12

Weight gradient of a linear layer. $z = Wx$ with $x = (1,2,3)^\top$ and upstream $\delta = \nabla_z\mathcal{L} = (0.5,-1)^\top$. Write $\nabla_W\mathcal{L}$ with its shape.

outer product

$W$ is $2\times3$, so the gradient is $2\times3$: $\delta x^\top = \begin{bmatrix}0.5\\-1\end{bmatrix}\begin{bmatrix}1&2&3\end{bmatrix} = \begin{bmatrix}0.5&1&1.5\\-1&-2&-3\end{bmatrix}$.

Entry $(k,j) = \delta_kx_j$ because $W_{kj}$ appears only in $z_k$ with coefficient $x_j$.

13

Outer product, entry by entry. $u = (1,2)^\top$, $v = (3,-1)^\top$, $f = u^\top Ev$ with $E\in\mathbb{R}^{2\times2}$. Write out $f$ as a sum, read off $\partial f/\partial E_{jk}$, and file the four numbers into $\nabla_Ef$.

left/right law

$f = \sum_{j,k}u_jE_{jk}v_k = 3E_{11}-E_{12}+6E_{21}-2E_{22}$.

Each $E_{jk}$ appears once with coefficient $u_jv_k$, so $\partial f/\partial E_{jk} = u_jv_k$.

Filed into $E$\'s shape: $\nabla_Ef = uv^\top = \begin{bmatrix}3&-1\\6&-2\end{bmatrix}$. Left neighbor $u$ runs down the rows, right neighbor $v$ across the columns.

14

One output, one row. With $E = \begin{pmatrix}1&1&0\\1&0&1\\0&1&1\end{pmatrix}$, $X = \begin{pmatrix}1&2\\0&1\\3&-1\end{pmatrix}$, $w = (2,1)^\top$ and $Y = E(Xw)$, compute $Y_2$ and $\nabla_EY_2$ with every entry.

column-born, row-filed

$v = Xw = (4,1,5)^\top$. $Y_2 = \text{row}_2(E)\cdot v = 1\cdot4+0\cdot1+1\cdot5 = 9$.

$\partial Y_2/\partial E_{2k} = v_k$ and every other partial is $0$ (rows 1 and 3 of $E$ never touch $Y_2$).

$\nabla_EY_2 = e_2v^\top = \begin{pmatrix}0&0&0\\4&1&5\\0&0&0\end{pmatrix}$: the column $v$ laid sideways into row 2.

15

Upstream gradient through the matrix. Same $E, X, w$. A scalar loss has upstream gradient $g = \nabla_YL = (1,0,-1)^\top$. Find $\nabla_EL$ and check its shape.

g (Xw)ᵀ

$L$ depends on $E$ only through $Y = Ev$, so $\nabla_EL = \sum_ig_i\nabla_EY_i = \sum_ig_ie_iv^\top = g\,v^\top$.

$g\,v^\top = \begin{pmatrix}1\\0\\-1\end{pmatrix}\begin{pmatrix}4&1&5\end{pmatrix} = \begin{pmatrix}4&1&5\\0&0&0\\-4&-1&-5\end{pmatrix}$, shape $(3\times1)(1\times3) = 3\times3$ = shape of $E$ ✓.

Row 2 is zero because $g_2 = 0$: the loss is indifferent to $Y_2$, so no entry in row 2 of $E$ matters.

16

The neighbor is the whole side. Same $E, X, w, g$. Now differentiate $L$ with respect to $X$: find $\nabla_XL$ and verify one entry by the perturbation identity.

neighbor = everything grouped on that side

$L$ is linear in $X$ through $g^\top EXw$. Regroup: $g^\top E = (E^\top g)^\top$, so the left neighbor of $X$ is $E^\top g$ and the right neighbor is $w$.

$E^\top g = (1,0,-1)^\top$ here (this $E$ happens to be symmetric), so $\nabla_XL = (E^\top g)\,w^\top = \begin{pmatrix}1\\0\\-1\end{pmatrix}\begin{pmatrix}2&1\end{pmatrix} = \begin{pmatrix}2&1\\0&0\\-2&-1\end{pmatrix}$, shape $3\times2$ ✓.

Check entry $(3,1)$: bump $X_{31}$ by $\epsilon$. Then $Xw$ gains $2\epsilon$ in slot 3, $Y = E(Xw)$ gains $2\epsilon\,E_{\cdot3} = 2\epsilon(0,1,1)^\top$, and $L$ gains $g\cdot 2\epsilon(0,1,1)^\top = -2\epsilon$. Slope $-2$ ✓.

17

Transpose on the variable swaps the sides. $u = (1,2,-1)^\top$, $a = (3,1,2)^\top$, $f = u^\top E^\top a$ with $E\in\mathbb{R}^{3\times3}$. Find $\nabla_Ef$ without expanding the sum.

uᵀEᵀa = aᵀEu

A scalar equals its transpose: $f = (u^\top E^\top a)^\top = a^\top Eu$. Now $E$ appears un-transposed with left neighbor $a$ and right neighbor $u$.

$\nabla_Ef = a\,u^\top = \begin{pmatrix}3\\1\\2\end{pmatrix}\begin{pmatrix}1&2&-1\end{pmatrix} = \begin{pmatrix}3&6&-3\\1&2&-1\\2&4&-2\end{pmatrix}$.

Compare $u^\top Ea\Rightarrow ua^\top$: the transpose on $E$ swapped which vector becomes the column skeleton. Shape $3\times3$ either way, so only the meaning check (which side touched $E$ from the left after regrouping) separates them.
