The Filing Machine: $\nabla_E Y_i$ for $Y = E(Xw)$

The running example throughout this worksheet, with every number fixed:

$$E = \begin{pmatrix} 1 & 1 & 0 \\ 1 & 0 & 1 \\ 0 & 1 & 1 \end{pmatrix}, \quad X = \begin{pmatrix} 1 & 2 \\ 0 & 1 \\ 3 & -1 \end{pmatrix}, \quad w = \begin{pmatrix} 2 \\ 1 \end{pmatrix} \;\Longrightarrow\; v = Xw = \begin{pmatrix} 4 \\ 1 \\ 5\end{pmatrix}, \quad Y = Ev = \begin{pmatrix} 5 \\ 9 \\ 6 \end{pmatrix}$$

The animation below plays the two moves in sequence. Move A: row $i$ of $E$ sweeps across the column $v$ — each row entry $E_{ik}$ pairs with $v_k$, and the products accumulate into the single number $Y_i$. Move B: the sensitivities $\partial Y_i / \partial E_{ik} = v_k$ get filed into a gradient grid the same shape as $E$ — and because the knobs $E_{i1}, E_{i2}, E_{i3}$ sit horizontally, the column-born values of $v$ land horizontally: the column tips over into row $i$. That tipping is the transpose in $(Xw)^\top$.

The law in one line: whatever multiplies the variable from the left lands as the column; whatever multiplies from the right lands as the row. A transpose on the variable swaps the two sides. Each factor stays on the side of the outer product it touched the variable from.

3

Shape Dominoes: the chain rule must compose

The test that never fails: in a chain-rule product, inner dimensions must click like dominoes, and the final shape must match the variable you differentiated by. Loss $L(Y)$ is a scalar, $Y = EXw$, and the upstream gradient is $g = \nabla_Y L \in \mathbb{R}^{3\times 1}$. Pick a target gradient, then pick a candidate arrangement — one composes, one clashes.

Common slip: writing $\nabla_E L = g \,(Xw)$ without the transpose. Check the shapes: $(3\times 1)(3\times 1)$ — the inner dimensions $1$ and $3$ do not match, so the product does not even exist. There is only ever one way to place the transposes so everything composes; let the shapes place them for you.

1

Conventions: what is a row, what is a column, what shape is a gradient

Bare vectors are columns. $w \in \mathbb{R}^{d\times 1}$, $Xw \in \mathbb{R}^{b \times 1}$, $Y \in \mathbb{R}^{b\times 1}$. A row is always marked explicitly with a transpose: $v^\top$ is the row version of the column $v$. When you compute $Xw$ by matrix multiplication, the object you produce is a column — that is its birth format.

Gradient shapes are fixed by convention:

  • Scalar by vector: $\nabla_w f$ has the shape of $w$ (a column, $d \times 1$).
  • Scalar by matrix: $\nabla_A f$ has the shape of $A$, with slot $(j,k)$ holding $\partial f / \partial A_{jk}$.
  • Vector by vector (Jacobian): $\partial Y / \partial w$ is (outputs $\times$ inputs), so $b \times d$; slot $(i,k)$ holds $\partial Y_i / \partial w_k$.
  • Vector by matrix: a 3-index tensor. Exams compress it: report the per-component gradient $\nabla_A Y_i$ (a matrix of $A$'s shape), and if every component has the same repeating content, report just that block.

Row-vs-column is not mathematics — it is typesetting for a linear map. The convention-free fact is the perturbation identity (Section 3). Everything else is bookkeeping chosen so that matrix multiplication executes the chain rule automatically.

2

Deriving $\nabla_E Y_i = e_i (Xw)^\top$, every move shown

0

The plan. Name the intermediate column $v = Xw$ so the model reads $Y = Ev$. Write out one output component $Y_i$ entrywise, read off the partial derivative with respect to every entry of $E$, then file those numbers into a grid the same shape as $E$. The filing step is where the transpose appears — and we will see exactly why.

1

Form the intermediate column. By definition of matrix-vector multiplication ($3\times 2$ times $2\times 1$ gives $3 \times 1$):

$$v = Xw = \begin{pmatrix} X_{11}w_1 + X_{12}w_2 \\ X_{21}w_1 + X_{22}w_2 \\ X_{31}w_1 + X_{32}w_2 \end{pmatrix} =: \begin{pmatrix} v_1 \\ v_2 \\ v_3 \end{pmatrix} \quad\text{— a column, as computed.}$$

2

Write one output entrywise. Again by definition of matrix-vector multiplication, row $i$ of $E$ dots the column $v$:

$$Y_i = \sum_{k=1}^{3} E_{ik} v_k = E_{i1}v_1 + E_{i2}v_2 + E_{i3}v_3.$$

Observe which entries of $E$ appear: only row $i$'s. The other rows of $E$ are absent from this formula, so $Y_i$ cannot depend on them.

3

Read off every partial derivative. Differentiating the sum in Step 2 with respect to each entry $E_{jk}$ (one entry at a time, all others held fixed):

$$\frac{\partial Y_i}{\partial E_{ik}} = v_k \quad (k = 1,2,3), \qquad \frac{\partial Y_i}{\partial E_{jk}} = 0 \;\text{ for } j \neq i.$$

These numbers are the sensitivity object: nudge $E_{ik}$ by $\epsilon$ and $Y_i$ moves by $\epsilon\, v_k$. As a set of numbers they are neither row nor column yet — they are indexed by which knob you poked.

4

File into an $E$-shaped grid. By the scalar-by-matrix convention, $\nabla_E Y_i$ has $E$'s shape, slot $(j,k)$ holding $\partial Y_i / \partial E_{jk}$. Filling the grid from Step 3 (shown for $i = 1$):

$$\nabla_E Y_1 = \begin{pmatrix} v_1 & v_2 & v_3 \\ 0 & 0 & 0 \\ 0 & 0 & 0 \end{pmatrix} = e_1 v^\top.$$

The values landed horizontally — not by choice, but because the knobs they measure ($E_{11}, E_{12}, E_{13}$) occupy row 1 of $E$. Sensitivities live where the knobs are. A column's worth of numbers laid into a horizontal strip is that column transposed.

$$\boxed{\;\nabla_E Y_i = e_i\,(Xw)^\top \quad\text{— row } i \text{ holds } (Xw)^\top, \text{ zeros elsewhere. Exam shorthand: } \frac{\partial Y}{\partial E} = (Xw)^\top.\;}$$

Physical mnemonic: in $Ev$, the row of $E$ sweeps across the column $v$ — each horizontally-placed knob $E_{ik}$ gets multiplied by the matching $v_k$. The knobs are strung horizontally, so the sensitivities are written horizontally. Column-born, row-filed.

3

The perturbation identity: the convention-free ground truth

When any layout question feels ambiguous, drop to first principles. Perturb the whole matrix: $E \to E + \Delta$ for an arbitrary small $3\times 3$ matrix $\Delta$. By linearity of matrix multiplication:

$$Y(E + \Delta) - Y(E) = (E + \Delta)v - Ev = \Delta v.$$

The change in $Y$ is exactly linear in $\Delta$, with coefficient object $v = Xw$. That linear map $\Delta \mapsto \Delta v$ is the derivative — no convention needed. Reading off row $i$: the change in $Y_i$ is $\sum_k \Delta_{ik} v_k$, whose coefficient on $\Delta_{ik}$ is $v_k$ — matching Step 3 of the derivation exactly.

Three-step protocol that never lies:

1. Compute the sensitivity object entrywise, or by expanding $f(A + \Delta) - f(A)$ to first order.

2. Determine the required shape from the convention (variable's shape for scalar gradients; outputs $\times$ inputs for Jacobians).

3. Transpose or arrange the sensitivity object to fit that shape. The transposes appear here, mechanically, at filing time.

4

Contrast: $\partial Y / \partial w = EX$ needs no transpose — why?

Group the same model as $Y = (EX)w$ and set $A = EX \in \mathbb{R}^{3\times 2}$. Entrywise:

$$Y_i = \sum_{k=1}^{2} A_{ik} w_k \;\Longrightarrow\; \frac{\partial Y_i}{\partial w_k} = A_{ik} \;\Longrightarrow\; \frac{\partial Y}{\partial w} = A = EX \in \mathbb{R}^{3 \times 2}.$$

Here the Jacobian's filing grid is indexed (output $i$, input $k$) — and the coefficient formula is already indexed $(i,k)$. Grid indices match formula indices, so the entries drop straight in with no rearrangement. Transposes only appeared in the $E$-derivative because there the variable was the matrix, and the sensitivities had to be re-filed into its shape.

Side by side: w.r.t. $w$ — coefficient matrix $EX$ files directly as the Jacobian. W.r.t. $E$ — each output reads one row of $E$, so the column $Xw$ gets filed sideways into that row: $(Xw)^\top$.

1

Cast of characters (fixed shapes throughout)

$$E \in \mathbb{R}^{b\times b}, \quad X \in \mathbb{R}^{b\times d}, \quad w \in \mathbb{R}^{d\times 1} \;(\text{weights, column}), \quad a, u \in \mathbb{R}^{b\times 1}, \; v \in \mathbb{R}^{d\times 1}, \quad A \in \mathbb{R}^{m\times n}.$$

Convention recap: bare vectors are columns; scalar-by-matrix gradients take the variable's shape; Jacobians are (outputs $\times$ inputs). The rules below are ranked at the end by reliability — when any two disagree in your head, the shape test wins.

6

The rules, ranked by reliability

1. Shape test (never fails)

Gradient shape = variable shape (scalar case) or outputs $\times$ inputs (Jacobian). Insert the unique transposes that make every product compose.

The self-enforcing rule: wrong layouts refuse to multiply.

2. Left/right law (fast, matrix variables)

$$u^\top A v \;\Rightarrow\; uv^\top$$

Left neighbor → column, right neighbor → row. Transpose on the variable swaps sides. Neighbor = everything grouped on that side.

3. Vector-variable law (fast)

$$\frac{\partial (Aw)}{\partial w} = A, \qquad \nabla_w\, w^\top A w = (A + A^\top)w$$

Coefficients as-is; quadratic forms symmetrize; linear scalars give the other factor as a column.

4. Ground truth (when anything feels off)

$$f(A + \Delta) - f(A) \approx \langle \text{derivative}, \Delta\rangle$$

Entrywise partials + first-order perturbation — the raw facts the other rules compress.

1

Gradient drills — compute, then shape-check

For every problem: (1) identify the rule, (2) compute the gradient, (3) verify the shape matches the variable. Problems shuffle on each page load. Shared objects where numbers appear: $E = \begin{pmatrix}1&1&0\\1&0&1\\0&1&1\end{pmatrix}$, $X = \begin{pmatrix}1&2\\0&1\\3&-1\end{pmatrix}$, $w = \begin{pmatrix}2\\1\end{pmatrix}$, so $Xw = (4,1,5)^\top$.

1

Compute $\nabla_w (a^\top w)$ for $a = (3, -2)^\top$, and state the shape.

Vector-variable law

Linear scalar: the gradient is the other factor, as a column. $\nabla_w (a^\top w) = a = (3,-2)^\top$, shape $2 \times 1$ = shape of $w$. ✓

2

Compute $\nabla_A (u^\top A v)$ for $u = (1,2)^\top$, $v = (3,-1)^\top$, entry by entry.

Left/right law

Left neighbor $u$ becomes the column, right neighbor $v$ becomes the row:

$$\nabla_A f = u v^\top = \begin{pmatrix}1\\2\end{pmatrix}\begin{pmatrix}3 & -1\end{pmatrix} = \begin{pmatrix} 3 & -1 \\ 6 & -2 \end{pmatrix}.$$

Shape $2\times 2$ = shape of $A$. ✓ Entry check: $\partial f/\partial A_{21} = u_2 v_1 = 6$. ✓

3

Compute $\nabla_w (w^\top A w)$ at $w = (1,2)^\top$ for $A = \begin{pmatrix} 2 & 1 \\ 0 & 3\end{pmatrix}$. Careful: $A$ is not symmetric.

Quadratic form — symmetrize

$$\nabla_w (w^\top A w) = (A + A^\top)w = \begin{pmatrix} 4 & 1 \\ 1 & 6 \end{pmatrix}\begin{pmatrix}1\\2\end{pmatrix} = \begin{pmatrix} 6 \\ 13 \end{pmatrix}.$$

Writing $2Aw$ here would be wrong — that shortcut needs $A = A^\top$. Shape $2\times 1$. ✓

4

Least squares: compute $\nabla_w \|Xw - y\|^2$ for $X = \begin{pmatrix}1 & 0\\ 1 & 1\end{pmatrix}$, $w = (1,1)^\top$, $y = (0,1)^\top$.

Chain rule + shape test

Residual first: $r = Xw - y = (1,2)^\top - (0,1)^\top = (1,1)^\top$. Then

$$\nabla_w \|Xw-y\|^2 = 2X^\top r = 2\begin{pmatrix}1 & 1\\ 0 & 1\end{pmatrix}\begin{pmatrix}1\\1\end{pmatrix} = \begin{pmatrix}4\\2\end{pmatrix}.$$

$X^\top$ ($2\times 2$ here, generally $d \times b$) carries the $b$-space residual back to $d$-space — the shape test forces the transpose. ✓

5

Exam replay: for $Y = E(Xw)$ with the shared numbers, write out $\nabla_E Y_2$ as a full $3\times 3$ matrix.

Column-born, row-filed

$Y_2$ reads row 2 of $E$ only, and $Xw = (4,1,5)^\top$, so the sensitivities file into row 2:

$$\nabla_E Y_2 = e_2 (Xw)^\top = \begin{pmatrix} 0 & 0 & 0 \\ 4 & 1 & 5 \\ 0 & 0 & 0 \end{pmatrix}.$$

Shape $3 \times 3$ = shape of $E$. ✓

6

Backprop: with upstream gradient $g = \nabla_Y L = (1, 0, -1)^\top$ and the shared numbers, compute $\nabla_E L$ as a full matrix.

Rank-one outer product

$$\nabla_E L = g\,(Xw)^\top = \begin{pmatrix}1\\0\\-1\end{pmatrix}\begin{pmatrix}4 & 1 & 5\end{pmatrix} = \begin{pmatrix} 4 & 1 & 5 \\ 0 & 0 & 0 \\ -4 & -1 & -5 \end{pmatrix}.$$

Shape check: $(3\times 1)(1\times 3) = 3\times 3$. ✓ Un-transposed, $(3\times1)(3\times1)$ does not even multiply.

7

Backprop continued: same $g = (1,0,-1)^\top$; compute $\nabla_X L = (E^\top g)\, w^\top$ with the shared numbers.

Compose the shapes

$E$ is symmetric here, so $E^\top g = Eg = (1, 0, -1)^\top$ (compute: row 1: $1{\cdot}1 + 1{\cdot}0 + 0{\cdot}(-1) = 1$; row 2: $1 + 0 - 1 = 0$; row 3: $0 + 0 - 1 = -1$). Then

$$\nabla_X L = (E^\top g)\,w^\top = \begin{pmatrix}1\\0\\-1\end{pmatrix}\begin{pmatrix}2 & 1\end{pmatrix} = \begin{pmatrix} 2 & 1 \\ 0 & 0 \\ -2 & -1 \end{pmatrix}.$$

Shape $(3\times1)(1\times2) = 3 \times 2$ = shape of $X$. ✓

8

Transpose swap: state $\nabla_E (u^\top E^\top a)$ using the left/right law, and explain in one sentence why the sides swap.

Transpose on the variable

Rewrite the scalar so the variable appears un-transposed: $u^\top E^\top a = (a^\top E u)^\top = a^\top E u$ (a scalar equals its own transpose). Now $a$ is the left neighbor and $u$ the right:

$$\nabla_E (u^\top E^\top a) = a\, u^\top.$$

The sides swap because transposing $E$ swaps which factor multiplies it from which side. Shape $b\times b$. ✓
