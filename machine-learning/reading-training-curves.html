Formulas to know cold

Steps per epoch

$$\text{steps/epoch} = \Big\lceil\frac{\text{train size}}{\text{batch size}}\Big\rceil$$ $$\text{total steps} = \text{epochs}\times\text{steps/epoch}$$

The x-axis is epochs but the optimizer counts steps. $\lceil20000/256\rceil = 79$, $\lceil20000/65536\rceil = 1$, $\lceil200000/256\rceil = 782$.

Noise floor

$$y = f(x)+\varepsilon,\qquad \text{Var}(\varepsilon) = \sigma^2$$ $$\min_{\text{any model}}\ \mathbb{E}\big[(\hat y - y)^2\big] = \sigma^2$$

No test MSE can beat $\sigma^2$. A training MSE below it means the model is memorizing noise.

Generalization gap

$$\text{gap}(t) = \mathcal{L}_{\text{test}}(t) - \mathcal{L}_{\text{train}}(t)$$

Grows with capacity, shrinks with data and regularization. Overfitting = gap growing while test loss rises.

Parameter count (MLP)

$$\#\text{params} = \sum_{l}(n_{l-1}+1)\,n_l$$

$50\to100\to100\to1$: $5100+10100+101 = 15{,}301$. Width 500: $\approx275$k. Capacity scales with the biggest $n_l^2$ term.

Gradient noise and batch size

$$\text{Var}\big(\hat g_B\big) \approx \frac{\text{Var}(g_1)}{B}$$

Batch GD: smooth, monotone. Mini-batch: mildly noisy. SGD ($B=1$): jagged. Noise scales like $1/\sqrt{B}$.

Weight decay as a per-step shrink

$$W \leftarrow (1-\alpha\lambda)\,W - \alpha\,\nabla J_0$$

Regularizers trade training fit for a smaller gap: train loss ends higher than the unregularized run, test loss stops rising.

Traps that cost points

  • Reading epochs as steps. A huge batch makes each epoch one gradient step; the plot looks frozen for the same reason a tiny learning rate does. Compute steps/epoch before judging speed.
  • Calling every small gap "good." Dropout, weight decay and more data all shrink the gap. Split them by speed: more data is faster than default, regularizers are slower.
  • Expecting vanishing gradients from 4 layers of ReLU. Three extra ReLU layers with Adam cost a factor near $0.9^3$, a dent, not a collapse. Depth degradation needs dozens of saturating layers; at 4 layers the extra capacity simply overfits faster.
  • Reading dropout's train line as the model's true training loss. It is measured with the mask on, so it can sit near or above the test line.
  • Forgetting that a test minimum is the early-stopping point. Training longer past it only widens the gap.
  • Treating a low training loss as success. Below the noise floor, it is evidence of memorization.
5

One-liners that earn the point

  • The optimizer sees steps, the plot shows epochs; convert before comparing speeds.
  • Capacity lowers train loss and raises the test upturn; regularization does the reverse; data does both favors at once.
  • Spiky means the learning rate; frozen means too few effective steps.
  • A test loss that bottoms out and rises is overfitting, and its minimum is where early stopping would stop.
  • Regularizers make training slower and worse so that testing is better.
  • A deep stack of saturating activations multiplies small slopes; the early layers stop learning and the loss crawls.

1

Anatomy of a loss curve

Every training plot has the same parts. Learn to name them before you try to diagnose anything. The plot below is a typical unregularized run with a little too much capacity for its data: it is the "default" that the rest of this sheet compares against.

#FeatureWhat it tells you
1Starting lossLoss at initialization. For MSE on standardized targets it is about the target's variance; for cross-entropy on $K$ classes it is about $\ln K$. A start far from that value means a bug or a bad initialization.
2Initial dropThe fast phase: the easy structure is learned in the first few hundred steps. Its steepness in epochs depends on steps per epoch and the learning rate.
3ElbowWhere the fast phase ends. After it the train loss keeps falling slowly; the test loss usually stops improving here.
4Best epochThe test minimum. Early stopping would halt here. Everything after it is the model fitting noise.
5Test upturnTest loss rising while train loss still falls: overfitting. The steeper and earlier, the more capacity the model has relative to the data.
6Generalization gapVertical distance between the curves. Grows with capacity, shrinks with data and regularization.
7Noise floor$\sigma^2$, the irreducible error. Test loss can never go below it; train loss below it is memorization.
8JitterStep-to-step noise from mini-batch gradients (and dropout masks). Scales like $1/\sqrt{B}$. Not the same as the wild bouncing of a learning rate that is too high.
Why the test loss never looks like the train loss. The train loss is measured on the examples the gradient steps were computed from, so the model can lower it by memorizing them. The test loss is measured on fresh examples, so it only falls while the model is learning structure that transfers. The moment memorization starts paying off on the training set and not on fresh data, the two curves part ways.

The diagnosis method

Exam questions hand you a labeled default run and a set of unlabeled ablations. Four steps turn that into points.

1

Predict before you look. For each listed change, write one phrase: faster or slower than default in epochs; bigger or smaller gap; test rising, flat, or falling; smooth or jagged. Do the steps-per-epoch arithmetic for anything that touches batch size or dataset size.

2

Sort the plots into categories by their most extreme feature. The spiky one. The frozen ones. The ones that overfit harder than the default. The ones with a small gap. Usually every plot lands in exactly one bucket, and the buckets have the same sizes as the groups of changes.

3

Break ties inside a bucket with speed. Among the small-gap plots, more data is faster than default and regularizers are slower. Among the frozen plots, batch $\approx$ dataset still moves a little (full learning rate, few steps) while a tiny learning rate barely moves at all. Among the over-fitters, more parameters usually memorize faster.

4

Write the reason, not just the number. Graders pay for "train falls below default and test turns up by epoch 30, so this adds capacity" over a bare "2".

4

Bonus: when depth itself flattens the curve

One loss-curve pattern has a derivation behind it. A deep stack of saturating activations can leave the training loss crawling just under its starting value, while the same network four layers shallower learns fine. This is the vanishing-gradient problem, and it is a 24-point question on the CS230 midterm (Autumn 2025, Q2). Here it is in the order the exam asks.

8

Left: the stylized training curve (gray = a 2-layer ReLU reference). Right: per-layer factor $\rho = \|D^{[l]}W^{[l]}\|_2$ and the product $\rho^{L-1}$ that scales the gradient reaching layer 1.

(a) One layer's Jacobian

Plain MLP, no biases: $z^{[l]} = W^{[l]}h^{[l-1]}$, $h^{[l]} = \text{ReLU}(z^{[l]})$, mask $D^{[l]} = \text{Diag}(\mathbb{1}\{z^{[l]}>0\})$. Chain rule, outer function on the left: $$\frac{\partial h^{[l]}}{\partial h^{[l-1]}} = \frac{\partial\,\text{ReLU}(z^{[l]})}{\partial z^{[l]}}\cdot\frac{\partial z^{[l]}}{\partial h^{[l-1]}} = D^{[l]}W^{[l]}.$$ For a sigmoid network the mask becomes $\text{Diag}(\sigma'(z^{[l]}))$ with entries at most $\tfrac14$; for tanh, entries at most $1$ but typically well below it.

(b) The product of Jacobians

Gradients are columns, so going back one layer multiplies by the transposed Jacobian. Unrolling from the output logit's gradient $\delta^{[L+1]}$ down to $h^{[1]}$: $$\frac{\partial\mathcal{L}}{\partial h^{[l-1]}} = \big(D^{[l]}W^{[l]}\big)^{\!\top}\frac{\partial\mathcal{L}}{\partial h^{[l]}}\qquad\Longrightarrow\qquad \frac{\partial\mathcal{L}}{\partial h^{[1]}} = \Big(\prod_{l=2}^{L}\big(D^{[l]}W^{[l]}\big)^{\!\top}\Big)(W^{[L+1]})^\top\delta^{[L+1]}.$$

(c) Why it vanishes

Two inequalities. $\|D^{[l]}\|_2\le1$ because its diagonal entries are in $[0,1]$, and the spectral norm is submultiplicative: $$\Big\|\prod_{l=2}^{L}(D^{[l]}W^{[l]})^\top\Big\|_2\le\prod_{l=2}^{L}\|D^{[l]}\|_2\|W^{[l]}\|_2\le\rho^{\,L-1}\quad\text{if every }\|D^{[l]}W^{[l]}\|_2\le\rho.$$ With $\rho<1$ the bound goes to zero exponentially in depth. The gradient reaching the early layers is a vector of length at most $\rho^{L-1}$ times the top gradient, so those layers barely move, and the loss curve shows it: a crawl from the starting value instead of the fast initial drop. For sigmoid, $\rho\le\tfrac14\|W\|_2$, which is why the widget's curve flattens so quickly as $L$ grows. (With $\rho>1$ the same product explodes.)

(d) The residual fix

Replace the block by $h^{[l]} = \text{ReLU}\big((I+W^{[l]})h^{[l-1]}\big)$. Same chain rule: $$\frac{\partial h^{[l]}}{\partial h^{[l-1]}} = D^{[l]}(I+W^{[l]}),\qquad \frac{\partial\mathcal{L}}{\partial h^{[1]}} = \Big(\prod_{l=2}^{L}\big(D^{[l]}(I+W^{[l]})\big)^{\!\top}\Big)(W^{[L+1]})^\top\delta^{[L+1]}.$$ Under small-norm initialization $\|W^{[l]}\|_2\le\varepsilon\ll1$ with most gates active, each factor is within $\varepsilon$ of the identity, and $$\prod_{l=2}^{L}(I+W^{[l]})\approx I+\sum_{l=2}^{L}W^{[l]}+O(\varepsilon^2L),$$ a near-identity matrix rather than a contraction. The gradient stays $\Theta(1)$ at every depth, and the training curve looks like the shallow network's again. The $I$ is a path along which the gradient passes through every block unchanged.

What the rubric pays for. Chain rule written out (2) and the right order $DW$ (2) in (a); the recursion (3) and the unrolled product (3) in (b); the two inequalities named (4) in (c); the residual Jacobian, its product, and the near-identity argument (4+4+2) in (d).
Reading the curve correctly. On the exam's own ablation question, the 4-hidden-layer ReLU network did not show this pattern: it overfit faster, because three extra ReLU layers cost a factor near $0.9^3$ and Adam keeps gradients healthy. Vanishing gradients show up as a higher training loss than the shallow baseline, with saturating activations and many layers. Capacity shows up as a lower one.

The exam problem: match eight ablations to their plots

CS230 Autumn 2025 · Q3 · 18 pts Setup. A regression task on 50 standard-normal inputs with a noisy target. The default run: Linear(50→H) + ReLU + Dropout, Linear(H→H) + ReLU + Dropout, Linear(H→1), with $H = 100$, $p_{\text{dropout}} = 0$, weight decay $0$, learning rate $10^{-4}$, Adam, MSE loss, batch size 256, 20,000 training points, 20,000 test points, 250 epochs. Eight ablations each change exactly one setting:

#Ablation#Ablation
1Hidden dimension $H = 100 \to 500$5Learning rate $10^{-4}\to0.1$
2Hidden layers $2\to4$ (the middle block repeated 2 more times)6Learning rate $10^{-4}\to10^{-6}$
3Dropout $0\to0.3$7Batch size $256\to65{,}536$
4Weight decay $0\to0.1$8Training set $20{,}000\to200{,}000$ points

The nine plots are redrawn to the same axes. Plot (a) is the default. Assign an ablation number to each of the other eight; (b), (d) and (f) are pairs, accepted in either order.

PlotAnswerWhy
(b), (b)1 and 2Both train losses fall faster and further than the default and the test loss turns upward much earlier: harder overfitting. The only changes that add capacity to an already-overfitting model with no regularization are more width and more depth.
(c)5Train loss bouncing by more than 1 between epochs, test loss spiking off the chart: the optimizer is overshooting. Only a 1000× larger learning rate does that.
(d), (d)6 and 7Barely moving. A $100\times$ smaller learning rate takes tiny steps. Batch size 65,536 takes one step per epoch, so 250 epochs is 250 steps, about three default epochs' worth, and the default is still near its starting loss after three epochs.
(e)8Two features. The test loss never turns up and sits close to the train loss, so the change fights overfitting: that leaves 3, 4 and 8. And the loss reaches 1.5 in about 5 epochs where the default needed 50: ten times more gradient steps per epoch (782 vs. 79). Only more data does both.
(f), (f)3 and 4Overfitting is contained (test loss flat, small gap) but the train loss drops slower than the default and plateaus higher: regularization that costs training fit. Dropout and weight decay. Not 8, which would have been faster than default.

Telling the pairs apart (not required for credit). Within (f), dropout draws a fresh random mask every step, so its training curve is slightly jittery and can nearly touch the test curve (train is measured with dropout on, test with it off); weight decay's is smooth. Within (d), the big-batch run still moves a little because its 250 steps use the full learning rate; the $10^{-6}$ run is flatter. Within (b), the wider net has far more parameters ($50\cdot500+500\cdot500\approx275$k vs. $50\cdot100+3\cdot100\cdot100 = 35$k) and tends to memorize faster.

Bonus: batch size and curve noise

A one-point cousin from Practice midterm 1 (Q3d): label three training-loss curves as batch, mini-batch, or stochastic gradient descent. Batch GD uses the exact gradient, so its curve is smooth and monotone; mini-batch adds some noise; SGD (batch size 1) is the noisiest, trending down but jumping around every step.
