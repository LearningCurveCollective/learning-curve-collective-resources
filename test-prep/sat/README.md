# SAT Resources

Interactive SAT practice sheets developed by Learning Curve Collective: Reading (student notes), Grammar (transitions, sentence boundaries), Words in Context sets, Math topic sheets, the three-part SAT Desmos series (Core Moves, Next Steps and Mixed Practice), a full-length practice test, and a test-day playbook.

`SAT-Desmos-Strategies.html` is a forwarding page: that sheet was retired on 2026-11-12 and replaced by the SAT Desmos series. The original is kept in `retired-sheets/`.
