Next steps

SAT Desmos 1 covered what a graph can show you. This guide is built around one symbol that works differently: the tilde. Type an equation with a tilde ($\sim$) where the equals sign would go, and Desmos looks for values of the unknown constants that make the two sides match as closely as possible. That can shorten several kinds of later-module questions (a function through given points, a system written in other letters, an identity that holds for all values of $x$) to two or three lines of typing. These skills also have limits, so this guide shows what to check under each tilde line before you use a result, and when algebra is the simpler choice. The outputs shown here were read from the College Board version of Desmos. As you practice, start by identifying the question type. Then decide whether Desmos or algebra makes more sense, and check that your answer addresses what the question asks.

★ Essential: the tilde skills you will use most often. Start here.Unstarred: comes up less often. Come back to these after you feel comfortable with the starred skills.
★Move 1Use a tilde to find the constants: a function through given points

An equals sign states that two expressions are equal. With a tilde, Desmos looks for values of the unknown constants that make the expressions match as closely as possible. Define your function with letters for the constants, then enter known inputs and outputs as matching lists in square brackets.

Example AA line with $f(2) = 5$ and $f(6) = 17$: define $f(x) = mx + b$ and type $f([2, 6]) \sim [5, 17]$. Desmos reports $m = 3$ and $b = -1$, and a new line $f(10)$ shows $29$.

After a fit, the letters keep their fitted values. Type $f(8)$, or $a + b$, or $3m - b$ on a new line and Desmos evaluates it.
★Move 2Read the report before you use the values

After a tilde calculation, check the fitted values and the error information underneath. RMSE measures how far the model is from the data; an RMSE of zero (or very close to zero from rounding) indicates an exact match. If the error is larger, the result may be only an approximation. A table fit may show $R^2$ instead, which needs to be interpreted differently.

Example AIn our check, $2p + 3 \sim 2p + 5$ reported $p = 0$ with RMSE $= 2$. No value of $p$ makes those two sides equal: the equation has no solution.
Example BIn our check, $p^2 - p - 12 \sim 0$ reported $p = 4$ with RMSE $= 0$. That value is correct, but it is not the whole answer: $p = -3$ works too. For “the sum of the solutions,” type $x^2 - x - 12 = 0$ and read both vertical lines.

★Move 4Match two expressions for every $x$

“Equivalent to,” “true for all values of $x$,” and “can be rewritten in the form” all say the same thing: two expressions agree at every input. Give Desmos a short list of inputs, write both expressions with that list in place of $x$, and use a tilde to look for constants that make them agree at those inputs.

★Move 5One solution, no solution: the touching condition

“Exactly one solution,” “intersect at exactly one point,” and “no real solutions” are all statements about a discriminant, $b^2 - 4ac$. A slider can help you estimate where the answer is. The tilde may give a more precise value: type the discriminant with the unknown constant still in it, set it to zero with a tilde, and read the constant.

Example A$x^2 + kx + 16 = 0$ has exactly one solution when $k^2 - 64 = 0$, so $k = 8$ or $k = -8$. Read the question for which one it wants.
Example B$kx - 3y = 4$ and $4x - 5y = 7$ have no solution when the slopes match. $\dfrac{k}{3} \sim \dfrac{4}{5}$ reports $k = 2.4$, a value that a slider moving in whole steps would skip.
Example C$2x^2 - 4x + c = 0$ has no real solutions when $16 - 8c < 0$, so $c > 2$. Slide $c$ and watch the parabola lift off the $x$-axis as it passes $2$.
The slider and the tilde answer different questions. The slider helps you see how the graph changes; the tilde helps you calculate a candidate value. Use the picture to choose the condition and the tilde to finish.

Common mistakes and what to check

These common mistakes can produce results that look reasonable at first. Practice spotting these now so they are easier to catch on test day.

Common mistake 1naming a constant $e$, or solving for $x$
Desmos reads $e$ as $2.718\ldots$ and does not fit it. It also does not accept $x$ as the unknown in a tilde line. Use letters such as $a$, $b$, $k$, $m$, $p$.
Common mistake 2taking the tilde’s one answer when there are two
In our check, $p^2 - p - 12 \sim 0$ reported only $p = 4$. When an equation could have two solutions, graph it and count.
Common mistake 3trusting a fit whose RMSE is not zero
$2p + 3 \sim 2p + 5$ still prints a value, $p = 0$. An RMSE of $2$ shows that the displayed value does not satisfy the equation.
Common mistake 4leaving out a condition
$(ax + 2)(bx + 5) = 12x^2 + cx + 10$ with $a + b = 7$: in our check, a list fit without $a + b = 7$ reported $a = 12$, $b = 1$, $c = 62$. Those values satisfy the identity but not the condition. Include each condition the question gives.
Common mistake 5radians when the question is in degrees
$\sin(30)$ is $0.5$ in degrees and $-0.988$ in radians. Check the mode in the wrench menu before you enter a trig expression.
Common mistake 6typing $=$ where the tilde belongs
$f([2, 5]) = [12, 96]$ with an equals sign answers “Too many variables.” Use the tilde to ask Desmos to fit the unknown constants.
Common mistake 7using Desmos when a short algebra solution is simpler
$3x + 7 = 22$ is two steps by hand. And no calculator move can say what a number means: “what does $1.04$ represent in $P = 250(1.04)^t$” is answered by reading the structure.

Worked examples & practice

The central idea for these skills is: a tilde asks Desmos to find the constants, and the report underneath tells you whether to believe them. A function through given points, a system in any letters, an identity, a discriminant: each is the same request with different lines above it.

The walkthrough covers each skill with a worked example, a common mistake to watch for, and a short check for understanding. Load into Desmos loads the example into the calculator so you can see what Desmos displays. Start with the starred skills, and practice entering each one on your own.
