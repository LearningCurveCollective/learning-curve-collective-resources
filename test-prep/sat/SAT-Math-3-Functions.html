Function rules

A function is a rule that turns each input into exactly one output, and the SAT asks the same handful of questions about one: evaluate it, read it off a graph or a table, say where it is undefined, feed one function into another, decide when an equation holds for every $x$, and recognize a graph that has been shifted. Below, $f$ and $g$ are functions, $x$ is the input, and $f(x)$ is the output. Work every question the same way: recognize the type, choose the most efficient route, and sidestep the predictable trap.

★ Essential: the rules behind most SAT function questions. Start here.Unstarred: shows up less often. Add it once the starred rules are automatic.
★Rule 1Function notation: input, output, point

$f(x)$ is a name for the output that goes with the input $x$. Read $f(4) = 2$ as “put in $4$, get out $2$,” which is the point $(4, 2)$ on the graph. Everything else about functions is built on that one translation.

evaluate
replace every $x$: for $f(x) = x^2 - 4x$, $f(-2) = (-2)^2 - 4(-2) = 12$
solve
$f(a) = c$ is an equation in $a$: $a^2 - 4a = 12$ gives $a = 6$ or $a = -2$
on a graph
$f(a) = c$ means the point $(a, c)$ is on the graph;   $f(x) = c$ has one solution for each time the graph meets the line $y = c$
in a table
each column is one point $(x, f(x))$; the input row and the output row are never interchangeable
Example A$f(x) = 3x^2 - 2$: $f(-2) = 3(4) - 2 = 10$. Square first, then multiply: $(-2)^2$ is $4$, not $-4$
Example B$f(x + 1)$ means replace every $x$ with $x + 1$: for $f(x) = x^2 - 4x$, $f(x + 1) = (x + 1)^2 - 4(x + 1) = x^2 - 2x - 3$. It is not $f(x) + 1$
Example Creading the graph below: $f(x) = 1$ has three solutions because the graph meets the line $y = 1$ three times (near $x = -3.2$, near $x = 0.3$, and at $x = 2$), and $f(3) = 0$ because $(3, 0)$ is on the graph
In Desmos, type $f(x) = x^2 - 4x$ on one line and $f(-2)$ on the next: it evaluates. Add $y = 1$ to see every solution of $f(x) = 1$ as an intersection you can click.
★Rule 2Domain: where a function is undefined

The domain is every input the rule can accept. Two things break a rule on the SAT: dividing by zero and taking the square root of a negative number. Set the denominator equal to zero and solve; set the radicand greater than or equal to zero and solve.

FormRestrictionHow to find itExample
Fraction  $\dfrac{P(x)}{Q(x)}$$Q(x) \neq 0$set $Q(x) = 0$, factor, solve; every solution is a value where the function is undefined$\dfrac{x + 5}{x^2 - 5x + 6}$: $(x - 2)(x - 3) = 0$, undefined at $x = 2$ and $x = 3$
Square root  $\sqrt{R(x)}$$R(x) \geq 0$solve the inequality; the domain starts at the value that makes the radicand zero$\sqrt{2x - 6}$: $2x - 6 \geq 0$, so $x \geq 3$
Root underneath  $\dfrac{1}{\sqrt{R(x)}}$$R(x) > 0$both rules at once, so zero is excluded too and the inequality turns strict$\dfrac{4}{\sqrt{x - 3}}$: $x > 3$
Root over a fraction  $\dfrac{\sqrt{R(x)}}{Q(x)}$$R(x) \geq 0$,  $Q(x) \neq 0$the answer choice that states both conditions$\dfrac{\sqrt{x + 4}}{x - 1}$: $x \geq -4$ and $x \neq 1$
Example Aa repeated chunk: $h(x) = \dfrac{3}{(x - 2)^2 - 3(x - 2) - 10}$. Let $u = x - 2$: $u^2 - 3u - 10 = (u - 5)(u + 2) = 0$, so $u = 5$ or $u = -2$, which is $x = 7$ or $x = 0$. The substitution saves expanding
Example Bdo not cancel first: $g(x) = \dfrac{x^2 - 9}{x^2 - x - 6} = \dfrac{(x - 3)(x + 3)}{(x - 3)(x + 2)}$ is undefined at $x = 3$ and at $x = -2$. Canceling the $(x - 3)$ hides one of the two answers
Example Ca polynomial has no restrictions: $f(x) = x^2 - 4x$ accepts every real number. “All real numbers” is a legitimate answer when nothing divides and nothing sits under a root
In Desmos, graph the function and look for the gap: a vertical asymptote or a hole for a fraction, a left or right edge for a root. Then confirm with the algebra; the test wants the exact value.
★Rule 3Composition: one function feeds another

$g(f(x))$ means evaluate $f$ first, then send its output into $g$. Work from the inside out. The SAT writes composition three ways: as nested parentheses, as a new function defined from an old one ($g(x) = 3f(x) - 2$), and as a graph of $f$ with a question about $g$.

inside first
$g(f(2))$: find $f(2)$, then plug that number into $g$
with a formula
$g(f(x))$ is $g$ with every $x$ replaced by $f(x)$
defined from another
$g(x) = 3f(x) - 2$ means $g(5) = 3f(5) - 2$: the input passes straight through to $f$
order matters
$g(f(x))$ and $f(g(x))$ are usually different functions
Example A$f(x) = 2x + 1$ and $g(x) = x^2 - 3$: $g(f(2)) = g(5) = 22$, but $f(g(2)) = f(1) = 3$
Example B$f(x) = 4x - 3$ and $g(x) = 2f(x) + 5$. If $g(k) = 0$: $2(4k - 3) + 5 = 8k - 1 = 0$, so $k = \tfrac{1}{8}$. Write $g$ out in terms of $x$ first: $g(x) = 8x - 1$
Example Cfrom a graph: if $g(x) = 2f(x) - 1$ and the question asks how many $k$ have $g(k) = 5$, translate it into $f(k) = 3$ and count how many times the graph of $f$ meets the line $y = 3$
The trap is direction: $g(f(2))$ starts with $f$. Say it as “$g$ of $f$ of $2$,” and do the innermost thing first, every time.
★Rule 4Equations that are true for every $x$

Most equations are true for one or two values of $x$. An identity is true for all of them, which means the two sides are the same expression in disguise. Match the coefficients term by term: the $x^2$ terms agree, the $x$ terms agree, the constants agree. Each match is a small equation in the unknown constants.

What the question saysWhat it meansThe move
“true for all values of $x$”the two sides are identical expressionsmatch the coefficients
“infinitely many solutions”the same thing, phrased as a solution count (Rule 5 of the linear sheet)match the coefficients, constants included
“for what value of $x$”an ordinary equation, true for one inputsolve for $x$; this is not an identity
linear identity
$ax + b = cx + d$ for all $x$  means  $a = c$ and $b = d$
quadratic identity
$ax^2 + bx + c = 0$ for all $x$  means  $a = b = c = 0$
expand first
$a(x + 2) + b(x - 1) = (a + b)\,x + (2a - b)$
shortcut
plug in two easy values of $x$ (the ones that zero out a factor) to get two equations in the constants
Example A$(k - 3)x + 2 = 4x + m$ for all $x$: $k - 3 = 4$ and $2 = m$, so $k = 7$ and $m = 2$
Example B$a(x + 2) + b(x - 1) = 5x + 1$ for all $x$: expand to $(a + b)x + (2a - b) = 5x + 1$. Then $a + b = 5$ and $2a - b = 1$; add them: $3a = 6$, so $a = 2$ and $b = 3$
Example Cthe shortcut on Example B: $x = 1$ makes the $b$ term vanish and gives $3a = 6$ at once; $x = -2$ makes the $a$ term vanish and gives $-3b = -9$
If a question says “true for all $x$” and you find yourself solving for $x$, stop. $x$ is not the unknown; the constants are.
★Rule 5Shifting a graph: translations

Adding outside the function moves the graph up or down. Adding inside the parentheses moves it left or right, and the direction runs backwards from the sign: $f(x - 3)$ is the graph of $f$ moved $3$ to the right. The shape never changes; every point slides by the same amount.

MoveNew functionEffect on a point $(a, b)$From $f(x) = x^2$
up $k$$f(x) + k$$(a, b + k)$$x^2 + 2$
down $k$$f(x) - k$$(a, b - k)$$x^2 - 2$
right $h$$f(x - h)$$(a + h, b)$$(x - 3)^2$
left $h$$f(x + h)$$(a - h, b)$$(x + 3)^2$
both$f(x - h) + k$$(a + h, b + k)$$(x - 3)^2 + 2$: right $3$, up $2$
Example A$y = 4x - 1$ shifted $2$ left and $3$ up: replace $x$ with $x + 2$, then add $3$: $y = 4(x + 2) - 1 + 3 = 4x + 10$. The slope never changes; a shifted line is a parallel line
Example B“Which transformation turns $y = x^2$ into $y = x^2 + 6x + 2$?” Complete the square: $(x + 3)^2 - 7$. Left $3$, down $7$
Example Cif $(3, 7)$ is on the graph of $f$, then $(5, 8)$ is on the graph of $f(x - 2) + 1$: add $2$ to the input and $1$ to the output. A table of $f$ shifts the same way, one column at a time
Desmos checks this directly: define $f(x) = x^2$ on one line, type $g(x) = f(x - 3) + 2$ on the next, and compare the two graphs. Function notation works in Desmos exactly as it does on paper.
Rule 6Range: the outputs a function can reach

The domain is the set of inputs; the range is the set of outputs, read up the $y$-axis. Find the lowest or highest value the rule can produce. A square root starts at zero, a square starts at zero, and whatever is added afterward shifts the whole range by that much.

FunctionRangeWhy
$f(x) = mx + b$,  $m \neq 0$all real numbersa line keeps going in both directions
$f(x) = a(x - h)^2 + k$,  $a > 0$$y \geq k$the vertex is the lowest point
$f(x) = a(x - h)^2 + k$,  $a < 0$$y \leq k$the vertex is the highest point
$f(x) = \sqrt{x - h} + k$$y \geq k$the root is $0$ or more, so the output is $k$ or more
Example A$f(x) = \sqrt{x + 1} - 4$: domain $x \geq -1$ (the radicand), range $y \geq -4$ (the smallest root is $0$, at $x = -1$). The $1$ belongs to the domain and the $4$ to the range
Example B$f(x) = -(x - 1)^2 + 4$ opens down with vertex $(1, 4)$: range $y \leq 4$. The maximum value is $4$ (the $k$), and it occurs at $x = 1$ (the $h$)
Example Cfrom a graph with endpoints, the range runs from the lowest point drawn to the highest, ends included: the graph in Rule 1 runs from $y = -2$ up to $y = 3$, so its range is $-2 \leq y \leq 3$
Rare as a question on its own, but it hides inside others: “the minimum value of $f$” and “$f(x) = c$ has no solution” are both range questions.
Common SAT traps and how to avoid them

Each move below looks reasonable, is wrong, and produces a wrong answer that sits waiting in the choices. Learn to recognize these now, so you can sidestep them under time pressure.

Trap 1canceling a common factor before reading the domain
$\dfrac{(x - 3)(x + 3)}{(x - 3)(x + 2)}$ is undefined at $3$ and at $-2$. List the restrictions first; cancel afterward, never before.
Trap 2composing in the wrong order
$g(f(2))$ means $f$ first. With $f(x) = 2x + 1$ and $g(x) = x^2 - 3$, $g(f(2)) = 22$ and $f(g(2)) = 3$. Both numbers are in the choices.
Trap 3shifting left by writing $(x - 3)$
Left $3$ is $f(x + 3)$. Check with one point: $(x + 3)^2$ is zero at $x = -3$, which is where the vertex of $x^2$ lands after a move to the left.
Trap 4solving an identity for $x$
“True for all values of $x$” means match the coefficients. A single value of $x$ is never the answer to that question; the constants are.
Trap 5reading the domain off the numerator only
$\dfrac{\sqrt{x}}{x - 7}$ needs $x \geq 0$ from the root and $x \neq 7$ from the denominator. The choice that states only one of the two conditions is the trap.
Trap 6$f(x + 1)$ is not $f(x) + 1$
Inside the parentheses means replace every $x$. For $f(x) = x^2$, $f(x + 1) = x^2 + 2x + 1$ while $f(x) + 1 = x^2 + 1$.
Trap 7putting the horizontal shift into the range
$\sqrt{x - 6} - 3$ has range $y \geq -3$. The $6$ sets where the domain starts; the $-3$ sets where the range starts.

Worked examples & practice

Everything on the rules tab runs on one idea: a function is a rule that turns an input into an output, and $f(a) = b$ is the point $(a, b)$. Evaluating, reading a graph, composing two rules, matching an identity, and shifting a graph are all that one translation, applied in a different direction each time.

The walkthrough below takes the rules one at a time, each with a worked example, the trap it pairs with, and a quick check. The starred steps are the essentials. Reading a rule isn't knowing it; the check is the point.
